Співбесіди з JavaScript зазвичай починаються з основ, адже кожен баг, який вам доведеться шукати, зрештою зводиться до них.

## Значення та типи

У мові сім примітивних типів: `string`, `number`, `bigint`, `boolean`, `undefined`, `symbol` і `null`. Усе інше є **об'єктами**, зокрема масиви, функції, дати й Map.

- Примітиви незмінні й порівнюються **за значенням**.
- Об'єкти порівнюються **за посиланням**: `{} === {}` дає `false`, бо це два різні об'єкти.

```js
const a = { n: 1 };
const b = a;      // те саме посилання
b.n = 2;
console.log(a.n); // 2
```

`typeof null === "object"` є історичною помилкою мови. Перевіряйте `value === null` явно, а для масивів використовуйте `Array.isArray`.

## Рівність і приведення типів

`===` порівнює тип і значення без перетворень. `==` спершу приводить обидва боки за складним алгоритмом:

```js
0 == "";        // true
null == undefined; // true (і більше ніщо не дорівнює null через ==)
[] == false;    // true
NaN === NaN;    // false: використовуйте Number.isNaN або Object.is
```

Використовуйте `===` скрізь. Єдиний поширений виняток: `value == null`, що перевіряє і `null`, і `undefined`.

**Хибні значення (falsy)**: лише `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined` і `NaN`. `[]` і `{}` є істинними.

## `let`, `const` і `var`

- `var` має область видимості функції й піднімається (hoisting) зі значенням `undefined`.
- `let` і `const` мають блокову область видимості. Звернення до них до оголошення кидає помилку (*temporal dead zone*).
- `const` забороняє перевизначення, але не зміну: `const arr = []; arr.push(1)` працює.

## Як визначається `this`

`this` залежить від того, **як функцію викликано**, а не де її оголошено:

| Виклик | `this` |
| --- | --- |
| `obj.method()` | `obj` |
| `fn()` | `undefined` у strict mode (інакше глобальний об'єкт) |
| `fn.call(x)` / `fn.apply(x)` / `fn.bind(x)()` | `x` |
| `new Fn()` | новий об'єкт |
| стрілкова функція | `this` зовнішньої області (лексичний) |

Класична помилка: передати метод як колбек. `setTimeout(obj.method)` втрачає `obj`. Виправлення: `obj.method.bind(obj)` або стрілкова функція.

## Прототипи

Кожен об'єкт має приховане посилання (`[[Prototype]]`) на інший об'єкт. Пошук властивостей іде цим ланцюжком:

```js
const animal = { speak() { return `${this.name} makes a sound`; } };
const dog = Object.create(animal);
dog.name = "Rex";
dog.speak(); // "Rex makes a sound": знайдено в прототипі, this === dog
```

Синтаксис `class` є «цукром» над тим самим механізмом: методи живуть у `Class.prototype`, а `extends` з'єднує два ланцюжки прототипів.

## Чек-лист для співбесіди

- Поясніть різницю між примітивами й посилальними значеннями на прикладі мутації.
- Не покладайтеся на приведення в `==`; знайте `== null` як єдину ідіому.
- Визначайте `this` за місцем виклику й пам'ятайте, чим відрізняються стрілкові функції.
- Намалюйте ланцюжок прототипів для класу, що наслідує інший клас.
