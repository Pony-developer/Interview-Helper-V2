Питання з CSS перевіряють, чи вмієте ви передбачити поведінку браузера, а не чи пам'ятаєте властивості напам'ять.

## Каскад і специфічність

Коли кілька правил задають ту саму властивість, браузер обирає переможця за:

1. **Походженням і важливістю**: правила `!important` (браузера, користувача, автора), потім звичайні.
2. **Каскадними шарами** (`@layer`): пізніші шари перемагають раніші.
3. **Специфічністю**: `(id, класи/атрибути/псевдокласи, елементи)`.
4. **Порядком у коді**: перемагає останнє оголошення.

| Селектор | Специфічність |
| --- | --- |
| `p` | (0,0,1) |
| `.card p` | (0,1,1) |
| `#main .card p` | (1,1,1) |
| `a:hover` | (0,1,1) |
| `:where(.x) p` | (0,0,1): `:where` нічого не додає |

Вбудовані стилі (inline) перемагають усі селектори. Тримайте специфічність низькою й пласкою (окремі класи), щоб перевизначення лишалися передбачуваними.

## Блокова модель

Кожен елемент складається з вмісту, padding, рамки та margin. З типовим `box-sizing: content-box` властивість `width` задає лише вміст, тож padding і рамка роблять елемент ширшим. Більшість скидань стилів використовує:

```css
*, *::before, *::after { box-sizing: border-box; }
```

Вертикальні відступи сусідніх блоків **схлопуються** (перемагає більший). У flex- і grid-елементів відступи не схлопуються.

## Позиціювання й накладання

- `relative`: зсув від звичайного місця; стає контейнером для абсолютно позиціонованих нащадків.
- `absolute`: вилучений з потоку, розміщується відносно найближчого позиціонованого предка.
- `fixed`: відносно вікна перегляду. `sticky`: «прилипає» в межах свого контейнера прокрутки.
- `z-index` порівнює лише елементи в межах одного **контексту накладання**. `opacity < 1`, `transform`, `filter` і `position` разом із z-index створюють нові контексти, що пояснює класичне «мій z-index: 9999 не працює».

## Flexbox: один вимір

```css
.toolbar { display: flex; justify-content: space-between; align-items: center; gap: 1rem; }
```

`justify-content` працює на головній осі, `align-items` на поперечній. `flex: 1` дозволяє елементам ділити вільне місце. Flexbox підходить для рядків елементів керування, навігаційних панелей і центрування.

## Grid: два виміри

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr));
  gap: 1rem;
}
```

Grid керує рядками й колонками одночасно. `auto-fill` + `minmax` дає адаптивні колонки без медіазапитів. Grid підходить для макетів сторінок і галерей карток.

## Адаптивний і сучасний CSS

- Медіазапити mobile-first (`min-width`), відносні одиниці (`rem`, `%`, `vw`) і `clamp()` для плавної типографіки.
- Запити до контейнера (`@container`) підлаштовують компоненти під власну ширину.
- Користувацькі властивості (`--brand: #0b5a43`) успадковуються каскадом і можуть змінюватися під час роботи.
- Візуально прихований текст для зчитувачів екрана: обріжте його через `position: absolute; width: 1px; height: 1px; overflow: hidden; clip: rect(0 0 0 0)`. Ніколи не використовуйте `display: none`, бо це приховує текст і від допоміжних технологій.

## Чек-лист для співбесіди

- Обчисліть специфічність і поясніть, чому правило не застосовується.
- Поясніть `border-box`, схлопування відступів і контексти накладання.
- Оберіть між Flexbox і Grid та відцентруйте будь-що обома способами.
- Приховайте вміст візуально, не приховуючи його від зчитувачів екрана.
