Рекурсивна функція розв'язує задачу через розв'язання менших версій **тієї самої** задачі. Це природний інструмент для дерев, вкладених даних і пошуку «перебрати всі варіанти».

## Рецепт

1. **Базовий випадок**: найменший вхід, на який можна відповісти одразу.
2. **Рекурсивний крок**: зменшити задачу й викликати себе.
3. **Поєднання**: зібрати відповідь із підрезультатів.

```js
function sum(list) {
  if (list.length === 0) return 0;          // базовий випадок
  return list[0] + sum(list.slice(1));      // менша задача + поєднання
}
```

Якщо якийсь шлях ніколи не доходить до базового випадку, рекурсія стає нескінченною, і зрештою ви отримаєте `RangeError: Maximum call stack size exceeded`.

## Рекурсія для вкладених даних

```js
function flatten(value, depth = Infinity) {
  if (!Array.isArray(value)) return [value];
  if (depth === 0) return [value];
  return value.flatMap((item) => (Array.isArray(item) ? flatten(item, depth - 1) : [item]));
}
```

Дерева (вузли DOM, JSON, файлові системи, меню) рекурсивні за природою: обробіть вузол, потім рекурсивно його дочірні вузли.

## Експоненційні пастки й мемоізація

Наївне Фібоначчі обчислює ті самі значення знову й знову:

```js
const fib = (n) => (n < 2 ? n : fib(n - 1) + fib(n - 2)); // O(2^n)
```

Кешуйте результати (**мемоізація**), щоб отримати O(n). Або переверніть рекурсію в цикл «знизу вгору», тобто динамічне програмування:

```js
function fibMemo(n, memo = new Map()) {
  if (n < 2) return n;
  if (!memo.has(n)) memo.set(n, fibMemo(n - 1, memo) + fibMemo(n - 2, memo));
  return memo.get(n);
}
```

## Пошук із поверненням (backtracking)

Спробуйте варіант, зробіть рекурсивний виклик, потім **скасуйте** вибір. Так генерують перестановки й підмножини та розв'язують головоломки:

```js
function permutations(items) {
  const out = [], current = [], used = new Array(items.length).fill(false);
  (function go() {
    if (current.length === items.length) return void out.push([...current]);
    for (let i = 0; i < items.length; i++) {
      if (used[i]) continue;
      used[i] = true; current.push(items[i]);
      go();
      current.pop(); used[i] = false;            // скасування
    }
  })();
  return out;
}
```

## Глибина стеку

Кожен виклик займає кадр стеку. У рушіях JavaScript немає загальної оптимізації хвостових викликів, тож глибина рекурсії обмежена (часто близько 10 тис. кадрів). Для дуже глибоких входів, як-от зв'язного списку довжиною 100 тис., перетворіть рекурсію на цикл з явним стеком.

## Чек-лист для співбесіди

- Спершу назвіть базовий випадок і доведіть, що вхід зменшується.
- Помічайте підзадачі, що перекриваються, і додавайте мемоізацію.
- Пояснюйте складність, рахуючи кількість викликів.
- Знайте, коли перейти до ітерації, щоб уникнути переповнення стеку.
