Вибір структури даних зазвичай визначає складність ще до того, як ви напишете перший рядок коду. Вивчіть, які операції кожна структура робить дешевими.

## Шпаргалка

| Структура | Доступ | Пошук | Вставка/видалення | Типове використання |
| --- | --- | --- | --- | --- |
| Масив | O(1) за індексом | O(n) | O(n) у середині, амортизовано O(1) в кінці | упорядковані списки, стеки |
| Хеш-таблиця / `Map` | — | O(1) у середньому | O(1) у середньому | пошук за ключем, підрахунок, кеш |
| Множина (Set) | — | O(1) у середньому | O(1) у середньому | перевірка наявності, усунення дублікатів |
| Стек | вершина O(1) | — | push/pop O(1) | скасування дій, розбір, DFS |
| Черга | початок O(1) | — | додати/взяти O(1)* | BFS, планування задач |
| Зв'язний список | O(n) | O(n) | O(1) за посиланням на вузол | LRU-кеші, часте вирізання |
| Бінарне дерево пошуку (збалансоване) | O(log n) | O(log n) | O(log n) | упорядковані дані, діапазони |
| Купа (heap) | min/max O(1) | — | O(log n) | черги з пріоритетом, top-k |

*`array.shift()` має складність O(n). Справжня черга потребує індексу голови або зв'язного списку.

## Хеш-таблиці

`Map` у JavaScript зберігає порядок вставки, приймає ключі будь-якого типу й має `size`. Використовуйте його замість звичайних об'єктів для динамічних ключів. Типові патерни:

- **Підрахунок**: `count.set(x, (count.get(x) ?? 0) + 1)`.
- **Two-sum**: зберігайте `значення → індекс` під час проходу, тож кожен пошук коштує O(1).
- **Групування**: ключ → масив елементів.

## Стеки й черги

Стек працює за принципом «останнім прийшов, першим вийшов». Він допомагає перевіряти дужки, обчислювати вирази й виконувати DFS ітеративно.

```ts
function balanced(s: string) {
  const pairs: Record<string, string> = { ")": "(", "]": "[", "}": "{" };
  const stack: string[] = [];
  for (const ch of s) {
    if ("([{".includes(ch)) stack.push(ch);
    else if (ch in pairs && stack.pop() !== pairs[ch]) return false;
  }
  return stack.length === 0;
}
```

Черга працює за принципом «першим прийшов, першим вийшов». Пошук ушир (BFS) використовує чергу, щоб обходити вузли рівень за рівнем.

## Зв'язні списки та LRU-кеш

Двозв'язний список дозволяє видалити відомий вузол за O(1). Поєднайте його з Map (ключ → вузол) і отримаєте **LRU-кеш** з `get` і `put` за O(1). У JavaScript можна елегантно «схитрувати»: `Map` зберігає порядок вставки, тож видаліть і знову вставте ключ, щоб позначити його найсвіжішим, а витісняйте `map.keys().next().value`.

## Дерева

- **Бінарне дерево пошуку** тримає ліве < вузол < праве. Воно швидке лише тоді, коли збалансоване (AVL, червоно-чорне).
- Обходи: in-order (відсортований вивід для BST), pre-order (копіювання), post-order (видалення), level-order (BFS).
- DOM, JSON і файлові системи є деревами. Рекурсія для них природний інструмент.

## Купи

Бінарна купа, що зберігається в масиві, дає перегляд вершини за O(1) і push/pop за O(log n). Використовуйте її для «k найбільших», злиття відсортованих списків і алгоритму Дейкстри. У JavaScript немає вбудованої купи, тож будьте готові накидати її реалізацію.

## Графи

Представляйте граф списком суміжності (`Map<вузол, вузол[]>`). BFS знаходить найкоротші шляхи в незважених графах, DFS перевіряє зв'язність і шукає цикли. Тримайте Set `visited`, щоб уникнути нескінченних циклів.

## Чек-лист для співбесіди

- Назвіть потрібні операції та їхню частоту, потім обирайте структуру.
- Використовуйте Map/Set, щоб позбутися вкладених циклів.
- Знайте, як реалізувати чергу без `shift`, LRU-кеш і перевірку дужок.
- Згадайте про збалансованість дерев і купу на масиві.
