Метапрограмування означає код, що досліджує чи змінює поведінку іншого коду: як читаються й записуються властивості, як об'єкти перетворюються на рядки, як `instanceof` чи `for…of` з ними поводяться. JavaScript відкриває це через дескриптори властивостей, символи, `Proxy` і `Reflect`. Фреймворки активно на цьому спираються (реактивність Vue, MobX, Immer, ORM, моки в тестах).

## Дескриптори властивостей

Кожна властивість має атрибути:

| Атрибут | Значення | За замовчуванням у літералі | За замовчуванням у `defineProperty` |
| --- | --- | --- | --- |
| `value` / `get` + `set` | властивість-дані чи аксесор | – | – |
| `writable` | чи можна присвоювати | `true` | `false` |
| `enumerable` | чи видно в `Object.keys`, `for…in`, spread, `JSON.stringify` | `true` | `false` |
| `configurable` | чи можна видалити чи перевизначити | `true` | `false` |

```js
const user = {};
Object.defineProperty(user, "id", { value: 42 });   // лише для читання, прихована, постійна
Object.defineProperty(user, "name", {
  get() { return this._name; },
  set(v) { if (!v) throw new TypeError("name is required"); this._name = v; },
  enumerable: true,
});
```

Гетери й сетери (у літералах і класах їх також пишуть як `get x() {}`) виконують код під час доступу: обчислювані значення, валідація, ліниве завантаження. `Object.getOwnPropertyDescriptor(s)` читає атрибути назад.

## Блокування об'єктів

- `Object.preventExtensions(o)`: нових властивостей не додати.
- `Object.seal(o)`: ще й не видалити й не переналаштувати.
- `Object.freeze(o)`: ще й не записати.

Усі три **поверхневі**: вкладені об'єкти лишаються змінними, якщо їх теж не заморозити. Порушення мовчки ігноруються в нестрогих скриптах і кидають `TypeError` у строгому режимі (модулі й класи).

## Символи

`Symbol("description")` створює унікальний примітив, який можна використати як ключ властивості, що не конфліктує з жодним рядковим ключем чи іншим символом. Властивості з ключами-символами пропускають `Object.keys`, `for…in` і `JSON.stringify` (але `Object.getOwnPropertySymbols` і `Reflect.ownKeys` їх бачать), тож вони підходять для метаданих і «майже приватних» ключів. `Symbol.for("key")` використовує глобальний реєстр, тож той самий рядок повертає той самий символ будь-де, навіть між iframe.

**Загальновідомі символи** дають вашим об'єктам вбудуватися в поведінку мови:

| Символ | Що налаштовує |
| --- | --- |
| `Symbol.iterator` / `Symbol.asyncIterator` | `for…of`, spread / `for await…of` |
| `Symbol.toPrimitive` | перетворення на число й рядок |
| `Symbol.toStringTag` | `Object.prototype.toString` → `[object Name]` |
| `Symbol.hasInstance` | результат `instanceof` |
| `Symbol.species`, `Symbol.isConcatSpreadable` | похідні колекції, `concat` |

## Proxy

`Proxy` обгортає цільовий об'єкт і перехоплює базові операції **пастками** (traps):

```js
const withDefault = (target, fallback) =>
  new Proxy(target, {
    get(t, key, receiver) {
      return key in t ? Reflect.get(t, key, receiver) : fallback;
    },
  });
const counts = withDefault({}, 0);
counts.apples++; // 1, а не undefined + 1 = NaN
```

Поширені пастки: `get`, `set`, `has` (`in`), `deleteProperty`, `ownKeys` (`Object.keys`, spread), `getOwnPropertyDescriptor`, `defineProperty`, `apply` і `construct` (для цільових функцій). Використання: валідація, спостережуваний стан, значення за замовчуванням, від'ємні індекси масивів, журнал доступу й API-клієнти, що перетворюють `api.users.get(1)` на запити.

Proxy має дотримуватися **інваріантів**: пастка не може брехати про неналаштовувану властивість, недоступну для запису (повідомляти інше значення чи ховати її), інакше рушій кидає `TypeError`. Перехоплюються лише операції, що йдуть крізь проксі; початковий об'єкт усе ще можна змінювати напряму. Proxy має ціну для продуктивності, тож тримайте його поза гарячими шляхами.

## Reflect

`Reflect` має по методу на кожну пастку (`Reflect.get`, `Reflect.set`, `Reflect.has`, `Reflect.ownKeys`, `Reflect.apply`, …), що виконує **типову** поведінку. Усередині пасток перенаправляйте через `Reflect` і передавайте `receiver`: якщо в цільовому об'єкті є гетери, що використовують `this`, `Reflect.get(t, key, receiver)` виконує їх з `this` = проксі, тож вкладені читання теж проходять через ваші пастки, а `t[key]` їх оминув би. `Reflect.ownKeys` повертає і рядкові, **і** символьні ключі, а `Reflect.set` повертає `true`/`false` замість того, щоб кидати помилку.

## Інші інструменти метапрограмування

- `new.target` каже функції, чи її викликали з `new` (корисно для абстрактних базових класів).
- `name` функції виводиться з присвоєння (`const add = () => {}` має `name` `"add"`).
- Теговані шаблони отримують літеральні рядки (зокрема `strings.raw`) і значення окремо.
- `structuredClone`, `Object.groupBy`, `WeakMap` і `WeakRef` доповнюють сучасний набір для роботи з об'єктами: `WeakMap` прикріплює дані до об'єктів, не заважаючи збирачу сміття.

## Що перевірити перед співбесідою

- Поясніть атрибути дескриптора та їхні різні значення за замовчуванням.
- Поясніть freeze/seal і чому вони поверхневі.
- Поясніть, що робить символи унікальними, як вони ховаються від перебору, і `Symbol.for`.
- Використайте щонайменше три загальновідомі символи.
- Напишіть Proxy з пастками `get`/`set`, що перенаправляють через `Reflect` з receiver, і поясніть інваріанти.
