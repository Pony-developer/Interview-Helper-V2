**Замикання** є функцією разом зі змінними, які вона захопила з області, де її створено. На замиканнях тримаються колбеки, хуки React, приватність модулів і мемоізація.

## Лексична область видимості

Область видимості визначається тим, **де код написано**, а не де він виконується. Внутрішня функція бачить змінні всіх зовнішніх функцій:

```js
function makeCounter() {
  let count = 0;                 // приватна: доступна лише через замикання
  return {
    inc: () => ++count,
    get: () => count,
  };
}
const c = makeCounter();
c.inc(); c.inc();
c.get(); // 2
```

Кожен виклик `makeCounter` створює **новий** `count`. Замикання захоплюють змінні (живі прив'язки), а не знімки значень.

## Підняття та temporal dead zone

- Оголошення `function` піднімаються повністю, і їх можна викликати до рядка оголошення.
- `var` піднімається зі значенням `undefined`.
- `let`, `const` і `class` піднімаються, але не ініціалізуються. Звернення до них до оголошення кидає `ReferenceError`: це вікно називається *temporal dead zone*.

## Класична помилка з циклом

```js
for (var i = 0; i < 3; i++) setTimeout(() => console.log(i));
// 3 3 3: один спільний `i`

for (let i = 0; i < 3; i++) setTimeout(() => console.log(i));
// 0 1 2: `let` створює нову прив'язку на кожній ітерації
```

## Практичні замикання

```js
function once(fn) {
  let called = false, result;
  return function (...args) {
    if (!called) { called = true; result = fn.apply(this, args); }
    return result;
  };
}

function memoize(fn) {
  const cache = new Map();
  return (arg) => {
    if (!cache.has(arg)) cache.set(arg, fn(arg));
    return cache.get(arg);
  };
}
```

Використовуйте `cache.has`, а не перевірку на істинність, щоб закешовані `0`, `""` чи `undefined` теж вважалися влученнями. Для кількох аргументів потрібна стратегія ключа, наприклад вкладені Map або серіалізований ключ.

## Застарілі замикання

Замикання й далі бачить змінні з того рендеру чи виклику, що його створив. У React інтервал, створений один раз із залежностями `[]`, вічно читатиме початковий стан. Виправлення: функції-оновлювачі, ref або правильні залежності.

## Пам'ять

Захоплені змінні живуть, поки замикання досяжне. Прибирайте непотрібні слухачі подій і таймери, інакше їхні замикання (і все захоплене) не зможе зібрати збирач сміття.

## Чек-лист для співбесіди

- Поясніть, чому цикл із `var` друкує `3 3 3`.
- Реалізуйте `once`, `memoize`, `debounce` або приватний лічильник.
- Опишіть TDZ і що робить підняття з кожним типом оголошення.
- Помічайте застарілі замикання й пояснюйте виправлення.
