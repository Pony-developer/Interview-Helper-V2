A list of questions on authentication and frontend security. Only the ones the earlier modules don't cover are here: the common auth mechanisms, XSS vs CSRF, CORS with cookies, HTTPS and TLS, secrets in the bundle and the security checklist are already in the Junior and Senior modules. Try to answer each one out loud, then check yourself in the quizzes after this slide: each question here has one matching quiz question.

## Authentication

1. How do you design an OAuth 2.0 sign-in in a React app with a third-party provider such as Google or Auth0?
2. How do you store JWTs and refresh them in a React app?
3. How do you handle authentication errors such as expired tokens or invalid credentials?
4. How do you handle multi-factor authentication (MFA) in the frontend, and what matters for UX?
5. How do you manage user sessions in a single-page application, and how do you connect auth with Redux or Zustand?
6. How do you implement role-based access control (RBAC) in a React app?
7. How do you design a logout that securely clears all client-side state and tokens?
8. How do you handle authentication in a server-side rendered React app?
9. How do you support authentication across domains or origins, for example in micro-frontends?

## Frontend security

10. How do you protect a React app from XSS? Where can it still happen, and how do you sanitize input?
11. How do you protect API calls from man-in-the-middle attacks?
12. How do you keep sensitive data from leaking in the browser (the DOM, the console, error reports)?
13. How do you secure third-party scripts and libraries?
14. How do you design a Content Security Policy for a React app?
15. How do you approach security in a zero-trust environment?
16. How do you build a frontend that complies with GDPR or HIPAA?
