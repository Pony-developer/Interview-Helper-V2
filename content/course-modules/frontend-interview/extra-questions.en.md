One more popular list of frontend interview questions, split into three levels. Only the questions that the Junior, Middle and Senior modules don't already cover are here: mostly HTML, CSS and JavaScript basics that interviewers often ask as a warm-up, plus Angular, Vue and React. Try to answer each one out loud, then check yourself in the quizzes after this slide: each question here has one matching quiz question.

3. What are meta tags in HTML?
4. What is CSS?
5. How can you include CSS in a web page?
6. What is JavaScript?
7. What is React?

9. What is JSX?
10. What is Angular?
11. How is AngularJS different from Angular?

16. What is Vue.js?
17. What are props in Vue.js?
18. What is Vue Router?
19. What is the difference between Git and GitHub?
20. What is a repository in Git?
