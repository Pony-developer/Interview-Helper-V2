Питання про Tailwind CSS. Повтори одного питання об'єднано, а дрібні питання на кшталт «який клас робить X» зібрано разом. Відповіді в квізах — для поточної версії Tailwind CSS v4, з поясненнями, що змінилося порівняно з v3. Спробуйте відповісти на кожне вголос, а потім перевірте себе у квізах після цього слайда: кожному питанню там відповідає одне запитання.

## Основи

1. Навіщо використовують Tailwind CSS? Що означає підхід utility-first? Чи він безкоштовний?
2. Як підключити Tailwind CSS до проєкту?
3. Чим Tailwind CSS відрізняється від Bootstrap та інших CSS-фреймворків?
4. Які переваги й недоліки Tailwind CSS?
5. Для чого клас `container`?
6. Як вирівняти елемент по центру і як розмістити два елементи ліворуч і праворуч?
7. Як задати відступи між елементами: `space-x-*`/`space-y-*` чи `gap-*`?
8. Як будувати CSS Grid за допомогою Tailwind?
9. Як працювати з Flexbox у Tailwind: напрямок, порядок, розміри елементів?
10. Як стилізувати текст: жирність, шрифти, міжлітерний інтервал?
11. Як додати тінь: `shadow-*` чи `drop-shadow-*`?
12. Як працює прозорість в Tailwind?
13. Як обертати й зсувати елементи?
14. Які класи керують таблицями, курсором, зміною розміру елемента, SVG і заповненням батька?
