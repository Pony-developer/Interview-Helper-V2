A list of questions on design patterns in JavaScript and React. Only the ones the earlier modules don't cover are here: Observer, Adapter, what a higher-order component is and when to use React Context are already in the Middle, Senior and "Additional questions" modules. Try to answer each one out loud, then check yourself in the quizzes after this slide: each question here has one matching quiz question.

1. How do you implement the Singleton pattern in a React app, and when would you use it?
2. How do you use the Factory pattern to create React components dynamically?
3. How do you apply the Builder pattern to construct complex objects or UI?
4. How do you implement the Decorator pattern to enhance a component?
5. How do you apply the Composite pattern to hierarchical structures such as a tree view?
6. How do you use the Facade pattern to simplify work with complex subsystems?
7. How do you implement the Proxy pattern in JavaScript to control access to resources?
8. How do you use the Module pattern to encapsulate logic?
