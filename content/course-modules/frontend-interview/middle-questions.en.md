Questions for a Middle Front-end Developer interview. There is less "what is" here and more "how do you do it and why": try to answer each one out loud, drawing on your own experience, then check yourself in the quizzes after this slide. Each question here has one matching quiz question.

## General questions

1. Name the principles of OOP.
2. Explain each part of SOLID.
3. Why should you pay attention to an algorithm's complexity?
4. Into which entities do you split the file structure at the start of a project?
5. How do you know it is time to extract a separate entity in a project?
6. Briefly describe how a project build works.
7. What is your favorite technology, tool or tag in development?
8. What do you do to make code easier to maintain?
9. What is refactoring and how do you carry it out?

## HTML/CSS

10. What is structured data markup (microdata)?
11. What is SEO? What should a developer pay attention to so that the site has good SEO in the future?
12. Which techniques for organizing icons on a site do you know? Name the pros and cons of each.
13. How can you optimize CSS for better performance?
14. What is "modern CSS" to you? What from modern CSS do you use in your daily work?
15. How do SCSS variables differ from CSS custom properties? What are the advantages of each?
16. How do you resolve or prevent style conflicts when several frontend developers work on a project?
17. What is the difference between `transition` and `animation`? When do you use each?
18. You need custom styles for a scrollbar. How would you do it?
19. Which methods of style isolation do you know?
20. Why do we need CSS logical properties? Do you use them?
21. Tell us about your experience with CSS Grid Layout.
22. How does the CSS `clamp()` function work? Give useful examples of its use.
23. How do you optimize styles for printing?
24. Which CSS frameworks do you know? Which have you used on projects? What were their pros and cons?
25. How do you work with adaptive and fluid layouts? How do you approach problems caused by different screen resolutions and devices?
26. How do you organize CSS in large projects? Do you use any methodologies?
27. How do you decide whether to use a CSS preprocessor such as Sass or Less in your projects? What advantages do you see?
28. How do you apply the component approach in your CSS? Which strategies do you use to make style components reusable and easy to modify?
29. How does semantic markup affect the accessibility of a page?
30. What does the doctype affect?
31. Which CSS preprocessors do you know, and what are their advantages?
32. How do you make a link that downloads an attached file?
33. Why is `translate` sometimes better than `position: absolute` when writing styles?
34. Name the features of and differences between flex and grid. Which do you prefer?
35. Duplicating HTML/CSS for responsive design: pros, cons and pitfalls.

## Performance

36. Which main metrics measure the performance of a site?
37. What is Cumulative Layout Shift and how do you improve it?
38. What is critical CSS?
39. How do you build animations with performance in mind, using CSS or JavaScript?
40. Which image formats are best for the web? Which methods do you use to optimize images for the web?
41. How do you integrate third-party libraries or plugins while reducing their impact on performance?
42. How do you implement lazy loading of images and other resources to speed up loading?
43. How do you use prefetching and preloading to speed up navigation between pages?
44. A gallery page has to show many YouTube videos. How would you build it so that the page loads quickly?
45. You need to display a table with several thousand rows. How would you build it so that the page loads quickly and responds quickly to the user?
46. How would you load a large amount of CSS on a page so that the user can interact with it as soon as possible, while avoiding layout shifts?
