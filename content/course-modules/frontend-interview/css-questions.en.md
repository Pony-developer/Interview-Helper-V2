A list of questions on CSS itself. Only the ones the earlier modules don't cover are here: mostly specific properties and selectors that interviewers like to ask as a warm-up. Try to answer each one out loud, then check yourself in the quiz after this slide: each question here has one matching quiz question.

1. What is the latest version of CSS? How is CSS3 different from earlier versions?
2. What is the syntax of a CSS rule, and how do you write comments?
3. What is the priority of inline, internal (`<style>`) and external styles?
4. How do you make an accessible "Skip to content" link that stays hidden until it gets focus? Which ways of hiding content are safe for accessibility?
5. How does a CSS reset differ from a normalizer (Normalize.css)?
6. What are the background properties?
7. What are the border properties?
8. What does `margin: 40px 100px 120px 80px` mean?
9. How does `border` differ from `outline`?
10. How do you format text with CSS?
11. What are the link states, and how do you style them?
12. Can you use an image as a list item marker?
13. What is `overflow`, and which values does it have?
14. What are combinators in CSS?
15. How do you create a gradient in CSS?
16. How do 2D and 3D transforms work?
17. How case-sensitive is CSS?
18. What are CSS counters?
19. How do you build pagination with HTML and CSS?
20. How do you create an image reflection in CSS?
21. How do you split text into several columns, like a newspaper?
22. How do you add a shadow to text?
23. What are attribute selectors?
24. How do you split layout responsibilities between React components: who sets the Grid, Flexbox and spacing?
25. How do you build themes (including dark mode) on CSS custom properties without a flash of the wrong theme on load?
