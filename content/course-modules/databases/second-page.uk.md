Очікуваний вивід:

```text
 id |      name       | price
----+-----------------+-------
  3 | Mongo in Action | 39.90
  7 | Chess Set       | 35.00
  1 | SQL Basics      | 25.00
(3 rows)
```

Зробіть порядок унікальним, додавши після ціни `id` для розв'язання нічиїх, як радить лекція про пагінацію. Додаткове питання для роздумів: як отримати сторінку 3 пагінацією за ключем замість `OFFSET`?
