These are the Junior-level questions from the DOU list "[.NET interview: 150+ questions for Junior, Middle, Senior](https://dou.ua/lenta/articles/interview-questions-net-developer/)". Try to answer each one out loud first, in your own words. The lectures after this slide give short model answers, and each section ends with a quiz.

## General

1. What are the main principles of OOP?
2. Explain inheritance, encapsulation, abstraction and polymorphism with examples, ideally from your experience. Which class do all .NET classes implicitly inherit from? Is multiple inheritance allowed in C#?
3. What is recursion?
4. What is a lambda expression?
5. What is parallel programming (multithreading), what is it for, and which classes do you use for it?
6. What is JSON?
7. How do you understand REST?
8. Describe the SPA concept.
9. Which GoF design patterns have you used?
10. What is the difference between GET and POST?
11. What problem does Docker solve? What are its pros and cons?
12. How do unit tests fundamentally differ from integration tests?

## Exception handling

13. What is an exception?
14. What are `try`, `catch` and `finally` for? In which case might `finally` not run?
15. What is the call stack? Which related keywords do you know?

## The .NET platform

16. What is ASP.NET?
17. Which types of action filters exist?
18. What is a web service?
19. What is the CLR?
20. What is the garbage collector, at a basic level?
21. What is a delegate?
22. Does `Delegate` differ from `Action`?
23. What is LINQ and what is it used for? Give examples.
24. What is a namespace and why is it needed?

## Data types, collections, data structures

25. Which data types do you know?
26. Which primitive types do you know?
27. What is a nullable type?
28. What are value types and reference types? Which is a class and which is a struct? Where is each stored in memory?
29. What is the difference between value and reference types? Is `string` a reference type or a value type?
30. What is the difference between `StringBuilder` and `string`?
31. What are generics and which problems do they solve?
32. What is boxing and unboxing?
33. What are `Array`, `List`, `HashSet` and `Dictionary`? Give usage examples. What is the complexity of search, insert and delete for each?
34. Which collections do you know?
35. What does the `yield` operator do?

## Classes, structs, interfaces

36. What is a class?
37. What is the difference between a class and an abstract class?
38. What is the difference between an abstract class and an interface? What are interfaces for?
39. Which access modifiers do you know?
40. What is the difference between a regular class and a static class?
41. What is the difference between `new` and `override` when redefining a method?
42. What is the difference between `const` and `readonly`?
43. What is the difference between a struct and a class? Give examples of structs.
44. Can a struct instance be stored on the heap? How?

## Asynchrony

45. What is asynchrony and how does it differ from multithreading?
46. Which keywords are used for asynchrony in code?
47. What do `async` and `await` mean?

## Databases

48. Relational vs non-relational databases: pros and cons of each.
49. What are indexes in a relational database?
50. Which types of SQL JOIN exist?

## Testing

51. Why do we need unit tests?
52. What are the pros and cons of unit tests?
53. Which three logical blocks make up a unit test?
