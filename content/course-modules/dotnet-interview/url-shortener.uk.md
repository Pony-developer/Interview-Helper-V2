## Завдання

Ядро скорочувача посилань із лекції. Допишіть:

1. **`Base62.Encode(n)`** — запишіть `n` у системі числення з основою 62 з абеткою `0-9a-zA-Z`: беріть `n % 62` як останню цифру, діліть на 62, повторюйте, потім розверніть. `0` → `"0"`, `61` → `"Z"`, `62` → `"10"`.
2. **`Base62.Decode(s)`** — зворотне (`n = n * 62 + digit`); символ поза абеткою → `FormatException`.
3. **`Shortener.Shorten(url)`** — нормалізуйте URL (обріжте пробіли, приберіть один кінцевий `/`). Якщо цей URL уже скорочували, поверніть **той самий** код (ідемпотентність); інакше візьміть `nextId++`, запам'ятайте URL в обох словниках і поверніть Base62-код id.
4. **`Shortener.Resolve(code)`** — початковий URL або `null` для невідомого й для некоректного коду (перехопіть `FormatException`).

Очікуваний вивід:

```
0 Z 10 ZZ 100
61 62 123456789
q0U q0V True
https://dou.ua/lenta/articles/interview-questions-net-developer
https://learn.microsoft.com/dotnet
unknown
invalid
```
