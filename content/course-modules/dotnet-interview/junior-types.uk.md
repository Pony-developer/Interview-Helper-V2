## Типи (П25–29)

Типи C# бувають **типами значень** (`struct`, `enum`, усі числові типи, `bool`, `char`, `DateTime`, `Guid`, кортежі-значення) і **типами посилань** (`class`, `interface`, `delegate`, `record`, масиви, `string`, `object`).

Примітивні типи: `bool`, `byte/sbyte`, `short/ushort`, `int/uint`, `long/ulong`, `char`, `float`, `double`, а також `decimal` (128 біт, десятковий, для грошей) і `nint/nuint`.

| | Тип значення | Тип посилання |
|---|---|---|
| Змінна містить | самі дані | посилання на об'єкт у купі |
| Присвоєння | копіює значення | копіює посилання (обидві змінні вказують на один об'єкт) |
| Може бути null | лише як `Nullable<T>` (`int?`) | так |
| Успадкування | ні (sealed, походить від `ValueType`) | так |

«Типи значень живуть у стеку» — це спрощення: **локальна** змінна типу значення живе в стеку (або в регістрі), але **поле класу** типу значення чи **елемент масиву** живе в купі всередині цього об'єкта.

**`string` — тип посилання**, але незмінний і з перевантаженим `==`, що порівнює символи, тому він *поводиться* як значення.

**Nullable-тип значення** `int?` — це `Nullable<int>`: структура з `HasValue` і `Value`. Корисні оператори: `x ?? 0`, `x?.ToString()`, `x.GetValueOrDefault()`.

## string і StringBuilder, generics, упакування (П30–32)

`string` незмінний: `s += "a"` створює новий рядок і копіює старий, тож збирання рядка в циклі — це O(n²). `StringBuilder` дописує в буфер, що росте, а потім один раз викликається `ToString()`. Для двох-трьох конкатенацій звичайний `+` чи інтерполяція цілком годяться.

**Generics** (`List<T>`, `Dictionary<TKey, TValue>`, `T Max<T>(T a, T b) where T : IComparable<T>`) дають типобезпеку й перевикористання без приведень типів і без **упакування** типів значень.

**Упакування** копіює значення в новий об'єкт у купі, коли його перетворюють на `object` чи інтерфейс: `object o = 42;`. **Розпакування** копіює його назад явним приведенням до точного типу: `int i = (int)o;` (`(long)o` кине `InvalidCastException`). Упакування коштує виділень пам'яті й роботи GC; старий неузагальнений `ArrayList` пакував кожен `int`.

## Колекції (П33–35)

| Колекція | Що це | Пошук | Вставлення | Видалення |
|---|---|---|---|---|
| `T[]` | блок фіксованого розміру | O(n) за значенням, O(1) за індексом | — | — |
| `List<T>` | масив, що росте | O(n) за значенням, O(1) за індексом | амортизовано O(1) у кінець, O(n) у середину | O(n) |
| `HashSet<T>` | унікальні елементи, хеш-таблиця | O(1) | O(1) | O(1) |
| `Dictionary<K, V>` | хеш-таблиця ключ → значення | O(1) за ключем | O(1) | O(1) |
| `SortedDictionary<K, V>` | червоно-чорне дерево | O(log n) | O(log n) | O(log n) |
| `LinkedList<T>` | двозв'язний список | O(n) | O(1) біля відомого вузла | O(1) біля відомого вузла |

Інші: `Queue<T>` (FIFO), `Stack<T>` (LIFO), `SortedSet<T>`, `PriorityQueue<T, P>`, конкурентні колекції (`ConcurrentDictionary`, `ConcurrentQueue`, `BlockingCollection`) і незмінні (`ImmutableList`).

`yield return` перетворює метод на **ітератор**: компілятор генерує скінченний автомат, що реалізує `IEnumerable<T>`, а тіло виконується **ліниво**, по одному елементу на кожен `MoveNext()`. `yield break` завершує послідовність.

```csharp
static IEnumerable<int> Evens(int max)
{
    for (int i = 0; i <= max; i += 2) yield return i;
}
```

## Класи, структури, інтерфейси (П36–44)

- **Клас** — тип посилання: креслення з полями, властивостями, методами, подіями й конструкторами.
- **Абстрактний клас** не можна створити; він може містити абстрактні члени (без тіла), які похідні класи мусять перевизначити, а також звичайні члени, поля й конструктори.
- **Інтерфейс** — чистий контракт. Клас має один базовий клас, але багато інтерфейсів. Починаючи з C# 8 інтерфейси можуть мати реалізації методів за замовчуванням, але полів екземпляра й досі не мають. Інтерфейс — для здатності (`IComparable`, `IDisposable`, репозиторій, який ви замокаєте), абстрактний клас — щоб ділити код між близькими типами.
- **Модифікатори доступу**: `public`, `private` (за замовчуванням для членів), `protected`, `internal` (за замовчуванням для типів верхнього рівня; видимий у межах збірки), `protected internal` (та сама збірка АБО нащадок), `private protected` (нащадок І та сама збірка), `file` (C# 11).
- **Статичний клас** не можна створити чи успадкувати, і він має лише статичні члени (`Math`, класи з методами розширення).
- **`override`** замінює `virtual` чи `abstract` член: виклик диспетчеризується за типом під час виконання. **`new`** *приховує* член базового класу: що виконається, залежить від типу змінної під час компіляції. `Base b = new Derived(); b.M();` виконає `Derived.M` з `override` і `Base.M` з `new`.
- **`const`** — константа часу компіляції (лише примітиви й рядки), неявно статична, копіюється в кожну збірку, яка її використовує, тож після зміни треба перекомпілювати викликачів. Поля **`readonly`** присвоюються в оголошенні чи конструкторі під час виконання й можуть мати будь-який тип.
- **Структура** — тип значення: копіюється під час присвоєння, без успадкування, найкраща для невеликих незмінних даних (`DateTime`, `TimeSpan`, `Guid`, `KeyValuePair`, `Point`). **Клас** — тип посилання з ідентичністю та успадкуванням.
- Структура **таки** потрапляє в купу, коли вона є полем класу, елементом масиву, упакована або захоплена лямбдою чи збережена між `await` / `yield`.
