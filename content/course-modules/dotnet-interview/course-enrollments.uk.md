## Завдання

Питання 48–50: реляційні бази даних і JOIN-и. Скрипт підготовки створює `students`, `courses` і `enrollments` (з `grade`, що може бути NULL). Напишіть **два запити**:

1. Кожен курс із кількістю записаних студентів і їхньою середньою оцінкою, округленою до одного знака:
   - колонки `title`, `students`, `avg_grade`;
   - курси без студентів мають з'явитися з `0` і порожнім (NULL) середнім — використайте `LEFT JOIN` і `count(e.student_id)`;
   - `avg` автоматично пропускає NULL-оцінки;
   - відсортовано за `students` за спаданням, потім за `title`.
2. Імена студентів, які ніде не записані, відсортовані за ім'ям (`NOT EXISTS` або `LEFT JOIN … WHERE … IS NULL`).

Очікуваний результат:

```
   title   | students | avg_grade
-----------+----------+-----------
 C# Basics |        3 |      85.0
 SQL       |        3 |      72.5
 Docker    |        1 |      80.0
 Azure     |        0 | NULL
(4 rows)

 name
------
 Ivan
(1 row)
```
