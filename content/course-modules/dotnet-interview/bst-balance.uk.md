## Завдання

Питання 89: «Що таке балансування дерева?» Двійкове дерево пошуку швидке, лише поки воно низьке. Вставте 1, 2, …, 7 по порядку — і отримаєте «дерево», що насправді є зв'язним списком висотою 7. Допишіть `Bst`:

1. **`Insert(value)`** — менші значення йдуть ліворуч, більші — праворуч, дублікати ігноруються.
2. **`Height()`** — 0 для порожнього дерева, 1 для одного вузла, інакше 1 + висота вищого піддерева.
3. **`IsBalanced()`** — true, коли для **кожного** вузла висоти лівого й правого піддерев відрізняються щонайбільше на 1 (умова АВЛ). Перевірити лише корінь недостатньо. Ефективний підхід: одна рекурсивна функція, що повертає висоту збалансованого піддерева або −1, щойно знайде незбалансований вузол — O(n) замість перерахунку висот у кожному вузлі.
4. **`InOrder()`** — значення в порядку зростання (ліве піддерево, вузол, праве піддерево).
5. **`Rebalance()`** — перебудуйте ідеально збалансоване дерево з відсортованих значень: середній елемент стає коренем, ліва половина будує ліве піддерево, права — праве, рекурсивно.

Самобалансовані дерева (АВЛ, червоно-чорні — `SortedDictionary`, `SortedSet`) після кожного вставлення роблять невеликі повороти (ротації) замість повної перебудови, весь час тримаючи висоту O(log n).

Очікуваний вивід:

```
1 2 3 4 5 6 7
height 7, balanced False
height 3, balanced True, root 4
1 2 3 4 5 6 7
height 3, balanced True
height 5, balanced False
empty: height 0, balanced True
```
