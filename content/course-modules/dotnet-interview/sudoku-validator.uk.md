## Завдання

«Напишіть програму, що перевіряє, чи правильно заповнена сітка судоку 9×9.»

Допишіть **`Sudoku.IsValid(int[,] grid)`**. Сітка коректна, коли:

- кожен **рядок** містить кожну цифру 1..9 рівно один раз;
- кожен **стовпець** містить кожну цифру 1..9 рівно один раз;
- кожен із дев'яти **блоків 3×3** містить кожну цифру 1..9 рівно один раз.

Будь-яке значення поза 1..9 (наприклад, порожня клітинка, збережена як `0`) робить сітку некоректною.

Спробуйте пройти сітку один раз із позначкою «бачили» для кожного рядка, стовпця й блоку (`bool[10]` або бітова маска). Зручний трюк: на `i`-й ітерації можна одночасно перевіряти рядок `i`, стовпець `i` і блок `i` — `j`-та клітинка блоку `i` лежить у рядку `(i / 3) * 3 + j / 3`, стовпці `(i % 3) * 3 + j % 3`.

Остання тестова сітка — латинський квадрат: усі рядки й стовпці в порядку, а блоки — ні, тож не забудьте про блоки.

Очікуваний вивід:

```
valid: True
swapped in a row: False
with a zero: False
rows and columns only: False
```
