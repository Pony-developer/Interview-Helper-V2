## Завдання

«Організуйте структуру папок файлової системи» — задача на проєктування зі списку Junior, перетворена на код. Це патерн **Composite**: файли й папки мають спільний базовий тип `Entry`, а папка містить записи, які самі можуть бути папками. Кожна операція над папкою природно **рекурсивна**.

`FileEntry` уже готовий. Допишіть `Folder`:

1. **`Size`** — загальний розмір усього вмісту, рекурсивно (порожня папка — 0).
2. **`Print(lines, depth)`** — додайте рядок `"<відступ>Name/ (Size)"` (по два пробіли відступу на рівень), потім надрукуйте кожну дитину на рівень глибше в порядку додавання.
3. **`CountFiles()`** — кількість файлів (не папок) усередині, рекурсивно.
4. **`Find(path)`** — знайдіть запис за відносним шляхом на кшталт `"src/Models/User.cs"`; поверніть `null`, якщо якоїсь частини шляху немає. Підказка: відокремте перший сегмент, знайдіть дитину з такою назвою й викличте на ній `Find` для решти.

Очікуваний вивід:

```
root/ (3448)
  readme.md (120)
  src/ (3328)
    Program.cs (2048)
    Models/ (1280)
      User.cs (512)
      Order.cs (768)
  empty/ (0)
total: 3448
files: 4
Order.cs 768
not found
Models 1280
```
