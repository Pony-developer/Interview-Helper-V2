Клас `Counter` рахує, скільки разів викликали `Increment`. Додайте до нього подію `Changed` типу `Action` і піднімайте її з `Increment` після кожної зміни. Піднесення не має падати, коли ніхто не підписався.

`Main` не змінюйте. Очікуваний вивід:

```text
changed
changed
2
quiet ok
```

Рядки по порядку: перший інкремент піднімає подію, яка друкує `changed`; другий інкремент робить те саме; значення дорівнює `2`; а потім лічильник без підписників інкрементують без помилки, що друкує `quiet ok`.

Підказка: `public event Action Changed;` оголошує подію. Піднімайте її через `Changed?.Invoke();`, що нічого не робить, коли підписників немає.
