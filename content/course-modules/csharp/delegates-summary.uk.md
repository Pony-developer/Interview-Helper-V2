## Підсумок модуля

- **Делегат** — тип для методу з певною сигнатурою. Змінна цього типу тримає метод, а виклик змінної викликає метод. Делегати дозволяють передавати поведінку як значення.
- Делегат — **об'єкт** у купі з методом і ціллю. Присвоєння копіює посилання. Поєднаний делегат — новий об'єкт.
- **Узагальнені делегати** (`Func`, `Action`, `Predicate`, `Comparison`) покривають більшість випадків, тож власний тип оголошувати рідко доводиться.
- **Лямбда-вирази** (`x => x * 2`) — короткий спосіб написати делегат, і більшість коду використовує їх. Анонімні методи (`delegate { }`) — старша форма.
- Лямбда, що використовує зовнішню локальну змінну, — **замикання**. Змінна захоплюється за посиланням і живе, доки живе делегат.
- Найпоширеніша помилка — захоплення змінної циклу `for`. Скопіюйте значення в нову локальну змінну всередині циклу.

## Вибір інструмента

| Потреба | Інструмент |
|---|---|
| Передати правило в метод | параметр-делегат, зазвичай `Func` або `Action` |
| Коротке правило, що використовується раз | лямбда-вираз |
| Іменоване правило, що використовується в багатьох місцях | метод, перетворений на делегат |
| Таблиця іменованих дій | `Dictionary` з делегатами |
| Правило, що пам'ятає деякі дані | замикання або метод об'єкта |
| Правило, яке має перевірити компілятор | іменований тип делегата, наприклад `Operation` |
