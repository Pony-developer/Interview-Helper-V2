У C# є звичні арифметичні оператори. Вони беруть числа й повертають число.

| Оператор | Значення | Приклад | Результат |
| --- | --- | --- | --- |
| `+` | додавання | `7 + 2` | `9` |
| `-` | віднімання | `7 - 2` | `5` |
| `*` | множення | `7 * 2` | `14` |
| `/` | ділення | `7 / 2` | `3` (обидва `int`) |
| `%` | остача | `7 % 2` | `1` |

## Пріоритет

`*`, `/` і `%` виконуються раніше за `+` та `-`. Оператори одного рівня виконуються зліва направо, а дужки завжди йдуть першими:

```csharp
Console.WriteLine(10 + 2 * 3);     // 16
Console.WriteLine((10 + 2) * 3);   // 36
Console.WriteLine(100 / 10 / 5);   // 2, бо (100 / 10) / 5
Console.WriteLine(100 / (10 / 5)); // 50
```

Якщо сумніваєтеся, ставте дужки: вони нічого не коштують і роблять намір очевидним.

## Тип результату

`int` з `int` дає `int`. Якщо хоч одна сторона — `double`, результат теж `double`:

```csharp
Console.WriteLine(7 / 2);     // 3
Console.WriteLine(7 / 2.0);   // 3.5
Console.WriteLine(7.0 / 2);   // 3.5
```

Типова пастка: ділення виконується **до** того, як результат потрапляє в змінну:

```csharp
double half = 1 / 2;     // 0, спершу виконується цілочисельне ділення
double right = 1 / 2.0;  // 0.5
```

## Оператор остачі

`%` повертає те, що лишається після цілочисельного ділення. Знак береться з лівого операнда:

```csharp
Console.WriteLine(17 % 5);   // 2
Console.WriteLine(-7 % 3);   // -1
```

Він стає в пригоді в трьох ситуаціях:

- парність: `n % 2 == 0` істинне для парних чисел;
- остання цифра: `n % 10`, а `n / 10` її відкидає;
- «ходіння по колу»: `(hour + 5) % 24`.

Та сама пара працює і для часу: якщо `seconds` — ціле число, то `seconds / 60` — це повні хвилини, а `seconds % 60` — залишок секунд.

## Скорочене присвоєння

`x += 5` означає `x = x + 5`. Так само працюють інші оператори:

```csharp
int n = 10;
n += 5;    // 15
n -= 3;    // 12
n *= 2;    // 24
n /= 5;    // 4
n %= 3;    // 1
```

Зверніть увагу: `n *= 2 + 1` означає `n = n * (2 + 1)`, тобто спершу обчислюється вся права частина.

`++` та `--` додають або віднімають одиницю:

```csharp
int i = 5;
i++;              // i дорівнює 6
int a = i++;      // a = 6, потім i стає 7
int b = ++i;      // i стає 8, потім b = 8
```

Записане після змінної, `i++` повертає старе значення; записане перед нею, `++i` — нове. Пишіть їх окремими інструкціями, і різниця вас не зачепить.

## Клас Math

```csharp
Math.Abs(-4)          // 4
Math.Max(3, 9)        // 9
Math.Min(3, 9)        // 3
Math.Pow(2, 10)       // 1024, double
Math.Sqrt(81)         // 9, double
Math.Floor(2.7)       // 2, округлення вниз
Math.Ceiling(2.1)     // 3, округлення вгору
Math.Round(2.567, 2)  // 2.57
Math.PI               // 3.14159...
```

`Math.Pow` і `Math.Sqrt` повертають `double`; коли потрібне ціле число, приводьте через `(int)`.

`Math.Round` округлює половини до найближчого **парного** числа: `Math.Round(2.5)` дає `2`, а `Math.Round(3.5)` — `4`. Для шкільного правила беріть `Math.Round(2.5, MidpointRounding.AwayFromZero)`, що дає `3`.

## Ділення на нуль

```csharp
int zero = 0;
Console.WriteLine(5 / zero);     // помилка виконання: DivideByZeroException
Console.WriteLine(5.0 / zero);   // Infinity
```

Цілочисельне ділення на нуль аварійно завершує програму. Для `double` результатом буде `Infinity` (або `NaN` для `0.0 / 0`).

## Порівняння повертають bool

Оператори порівняння створюють значення типу `bool`, яке друкується як `True` або `False`:

```csharp
Console.WriteLine(5 > 3);         // True
Console.WriteLine(5 == 5);        // True
Console.WriteLine(5 != 5);        // False
Console.WriteLine(10 % 3 == 1);   // True
```

Оператори: `==`, `!=`, `<`, `>`, `<=` та `>=`. Не плутайте `==` (порівняння) з `=` (присвоєння). Значення `bool` можна поєднувати через `&&` (і), `||` (або) та `!` (ні). Найкорисніші вони разом з `if`, до якого ми дійдемо в одному з наступних модулів.
