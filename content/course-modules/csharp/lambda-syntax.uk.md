Напишіть лямбда-вирази, яких потребує `Main`. Кожна змінна оголошена як `Func` або `Action` і поки що дорівнює `null`. Замініть кожен `null` лямбдою:

- `square`: приймає `x` і повертає `x * x`;
- `add`: приймає `a` і `b` і повертає їх суму;
- `isEven`: приймає `n` і повертає `true`, якщо число парне. Напишіть її як лямбду-блок з `return`;
- `answer`: без параметрів, повертає `42`;
- `shout`: приймає текст і друкує його великими літерами (використайте `ToUpper()`).

`Main` не змінюйте. Очікуваний вивід:

```text
49
7
True
False
42
HI
```

Рядки по порядку: `square(7)`; `add(2, 5)`; `isEven(10)`; `isEven(7)`; `answer()`; і `shout("hi")`, що друкує `HI`.

Підказка: `() => 42` — лямбда без параметрів. Для лямбди-блоку напишіть `n => { ... return n % 2 == 0; }`.
