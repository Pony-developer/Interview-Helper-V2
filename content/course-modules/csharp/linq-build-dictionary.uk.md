Напишіть два методи, що працюють зі словником від кожного слова до його довжини:

- `LengthIndex(string[] words)`: повертає `Dictionary<string, int>`, що зіставляє кожне **різне** слово з його довжиною. Слово, що трапляється двічі, потрапляє до словника один раз (словник не може містити один ключ двічі);
- `HasWord(Dictionary<string, int> index, string word)`: повертає `true`, якщо слово є ключем словника.

`Main` не змінюйте. Очікуваний вивід:

```text
3
5
3
True
False
```

Рядки по порядку: кількість записів (`pear`, `fig`, `apple`; другий `pear` ігнорується); довжина `apple`; довжина `fig`; чи є `pear` в індексі; і чи є `kiwi`.

Підказка: `words.Distinct().ToDictionary(w => w, w => w.Length)` робить усе в одному рядку. Цикл з `if (!dict.ContainsKey(w))` теж підходить.
