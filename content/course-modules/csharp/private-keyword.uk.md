Інструмент приховування — **модифікатор доступу**: ключове слово перед членом, що каже, хто може його використовувати.

| Модифікатор | Хто може використовувати член |
|---|---|
| `public` | Усі: будь-який код, що бачить клас |
| `private` | Лише код **всередині того самого класу** |
| `protected` | Клас і його **похідні** класи |
| `internal` | Будь-який код того самого проєкту (збірки) |

Якщо в члена класу **модифікатора немає**, він **`private`**. Для самого класу (не вкладеного) типовий — `internal`.

## private у дії

```csharp
class BankAccount
{
    private decimal balance;                     // приховано

    public void Deposit(decimal amount)          // публічна операція
    {
        if (amount <= 0) return;                 // правило дотримується тут
        balance += amount;
    }

    public decimal GetBalance()                  // публічний спосіб прочитати
    {
        return balance;
    }
}

var account = new BankAccount();
account.Deposit(100);
Console.WriteLine(account.GetBalance());         // 100
// account.balance = 1000000;                    // помилка CS0122: 'BankAccount.balance' is inaccessible due to its protection level
```

Компілятор **забороняє** останній рядок, тож ніхто не зламає правило `amount > 0`, записавши в `balance` напряму. Єдиний шлях досередини — `Deposit`, і він дотримується правила.

Усередині класу `private` члени повністю доступні, навіть для **іншого об'єкта того самого класу**:

```csharp
public bool HasMoreThan(BankAccount other)
{
    return balance > other.balance;              // добре: ми всередині BankAccount
}
```

## Що робити приватним

Робіть **приватним** усе, що **не потрібне ззовні**:

- **усі поля** (майже завжди). Стан об'єкта — його таємниця;
- **допоміжні методи**, що лише розбивають довгий метод на частини;
- будь-яку деталь, яку ви **захочете змінити пізніше**.

Робіть **публічним** лише малий набір операцій, що становлять **призначення** класу. Цей набір називають **публічним інтерфейсом** (або API) класу. Що він менший, то легше клас зрозуміти, вживати й змінювати.

## Свобода змін

Є друга, тихіша перевага. Якщо баланс приватний, клас може змінити, **як** він його зберігає (як `decimal` чи в копійках як `long`), і ззовні нічого не постраждає. Якби поле було публічним, кожен рядок, що його вживав, довелося б оновлювати. Те, що приховано, можна змінювати вільно, а те, що публічне, — це **обіцянка**, яку треба дотримуватися.

```csharp
class Temperature
{
    private double celsius;                      // сьогодні: Цельсій
    // завтра всередині можуть бути кельвіни; публічні методи й далі працюватимуть
    public double InFahrenheit() { return celsius * 9 / 5 + 32; }
}
```

## Типова помилка: публічне поле

```csharp
class Player
{
    public int Health;                           // будь-хто може записати -100 чи 1000000
}
```

Пам'ятайте правило першої лекції: якщо правило існує, **хтось** має його охороняти, а в публічного поля охоронця немає. Практичне правило: **поля — `private`, поведінка — `public`**.
