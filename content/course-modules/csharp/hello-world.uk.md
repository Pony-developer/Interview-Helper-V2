Ось найменша корисна програма на C#:

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, world!");
    }
}
```

Рядок за рядком:

- `using System;` дозволяє писати `Console` замість повного імені `System.Console`. Простори імен групують пов'язані типи, а `using` імпортує простір імен.
- `class Program { ... }` оголошує клас. У C# увесь код живе всередині типів, навіть якщо програма — це один метод.
- `static void Main()` — це **точка входу**: середовище виконання викликає `Main`, коли програма стартує. `void` означає, що метод нічого не повертає.
- `Console.WriteLine("Hello, world!");` друкує текст і переходить на новий рядок. Кожна інструкція закінчується крапкою з комою.

## Write і WriteLine

```csharp
Console.Write("Hello, ");
Console.Write("world");
Console.WriteLine("!");
Console.WriteLine("Next line");
```

надрукує

```text
Hello, world!
Next line
```

`Write` лишається на тому ж рядку, а `WriteLine` додає перенесення рядка після тексту.

## На чому часто спотикаються

- C# **чутливий до регістру**: `console.writeline` — це не те саме, що `Console.WriteLine`, і такий код не скомпілюється.
- Текст береться в подвійні лапки. Одинарні — для одного символу: `'a'`.
- `//` починає коментар до кінця рядка. `/* ... */` може охоплювати кілька рядків.

## Від вихідного коду до запущеної програми

**Компілятор** читає ваш вихідний код, перевіряє його й перетворює на проміжну мову (IL). Потім **середовище виконання** (.NET або Mono) виконує цей IL. Якщо компілятор знайде помилку, він повідомить про неї з номером рядка, і нічого не запуститься.
