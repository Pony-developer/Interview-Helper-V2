Підрахунок — найпростіше, що роблять із масивом: пройти по ньому й збільшувати лічильник щоразу, коли елемент підходить.

Реалізуйте три методи:

- `CountNegative(numbers)` повертає, скільки елементів менші за нуль.
- `CountValue(numbers, value)` повертає, скільки елементів дорівнюють `value`.
- `CountInRange(numbers, low, high)` повертає, скільки елементів лежать між `low` та `high`, **включно з обома кінцями**.

Для порожнього масиву всі три повертають `0`.

Для масиву `{ 5, -3, 8, 5, 0, -1, 5, 12 }`, який використовує `Main`, відповіді такі:

- два від'ємні числа (`-3` та `-1`);
- значення `5` трапляється тричі, а `7` не трапляється;
- діапазон від 0 до 8 містить `5, 8, 5, 0, 5`, тобто п'ять чисел.

`Main` не змінюйте. Очікуваний вивід:

```text
2
3
0
5
0
```

Підказка: один цикл `for` чи `foreach` і один лічильник `int` у кожному методі. Умова для діапазону: `numbers[i] >= low && numbers[i] <= high`.
