## Фільтри винятків: `when`

Блок `catch` може мати умову. Блок перехоплює виняток, лише якщо умова дорівнює `true`:

```csharp
try
{
    response = await client.GetAsync(url);
}
catch (HttpRequestException e) when (e.StatusCode == HttpStatusCode.ServiceUnavailable)
{
    // лише 503: спробувати пізніше
}
```

Якщо фільтр дав `false`, усе відбувається так, ніби цього `catch` не було: середовище виконання дивиться на наступні блоки `catch`, а потім на викликаючих. Це краще, ніж перехопити, перевірити й кинути знову:

- код каже, що він обробляє, просто в рядку `catch`;
- фільтр виконується **до** розгортання стека, тож дамп аварії чи налагоджувач показують точний стан у місці, де виняток кинуто.

Відомий трюк використовує фільтр лише заради побічного ефекту:

```csharp
catch (Exception e) when (Log(e))   // Log записує виняток і повертає false
{
    // ніколи не виконується: виняток іде далі вгору, але його вже записано в лог
}
```

## `finally`: код, що виконується завжди

```csharp
var file = File.OpenRead(path);
try
{
    return Parse(file);
}
finally
{
    file.Dispose();   // виконується після звичайного return, після винятку, після break чи continue
}
```

`finally` виконується, коли керування з будь-якої причини залишає блок `try`. Він **не** виконується, якщо процес помирає: `Environment.FailFast`, `StackOverflowException`, примусове завершення процесу або блок `try`, що ніколи не закінчується.

Інструкція `using` — це рівно `try`/`finally`, що викликає `Dispose`.

## Порядок і дві пастки

Порядок такий: `try` → фільтри → відповідний `catch` → `finally`.

**Пастка 1: значення для повернення обчислюється до `finally`.**

```csharp
static int GetValue()
{
    int x = 1;
    try { return x; }      // значення 1 збережено тут
    finally { x = 2; }     // змінює змінну, а не збережений результат
}
// GetValue() повертає 1
```

**Пастка 2: виняток у `finally` заміняє початковий.** Якщо `try` кинув виняток, а потім `finally` теж кинув, перший виняток утрачено назавжди. Тримайте блоки `finally` простими і ніколи навмисно не кидайте з них винятків.

## Правило

Використовуйте `when`, щоб перехоплювати лише ті випадки, які справді обробляєте, а `finally` (або `using`) — для прибирання, яке має статися незалежно від того, як закінчився блок.
