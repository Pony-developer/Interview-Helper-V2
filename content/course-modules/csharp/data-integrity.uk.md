Погляньте на клас, що зберігає коло:

```csharp
class Circle
{
    public double Radius;
}

var c = new Circle();
c.Radius = -5;                               // компілюється, і ніхто не скаржиться
Console.WriteLine(Math.PI * c.Radius * c.Radius);    // 78.5...: площа кола, якого не існує
```

Радіус не може бути від'ємним. Клас це знає, але **не має способу захистити** правило: будь-який код програми може записати в поле будь-яке число, з будь-якого місця й будь-коли. Об'єкт тепер **зламаний**, і він про це не знає.

## Інваріанти

Більшість об'єктів мають правила, які мусять виконуватися **завжди**. Їх називають **інваріантами**:

- радіус кола не від'ємний;
- баланс рахунку не нижчий за кредитний ліміт;
- знаменник дробу не дорівнює нулю;
- кінець відрізка не раніший за початок;
- кількість елементів у списку дорівнює значенню його лічильника.

**Цілісність** даних означає, що ці правила виконуються для **кожного об'єкта в кожну мить**. Програма коректна лише тоді, коли жоден об'єкт ніколи не опиняється в стані, що порушує його інваріанти.

## Чому це важко

Коли будь-який код може змінювати поля, інваріант захищає **кожне місце програми одночасно**. Кожен новий рядок, що пише в `Radius`, мусить пам'ятати правило. Одна забута перевірка, і об'єкт зламано. Питання не «чи», а «коли»: у програмі з тисячами рядків хтось забуде.

Гірше те, що симптом з'являється **далеко** від причини. Від'ємний радіус записали в одному місці, а дивний результат проявляється пізніше в зовсім іншій частині програми. Пошук помилки починається не з того кінця.

## Ідея інкапсуляції

Рішення — **віддати відповідальність класові**:

1. Поля **приховано** всередині класу, і зовнішній код не може їх торкнутися.
2. Клас пропонує **операції** (методи й властивості), через які дані можна змінювати.
3. Кожна операція **перевіряє правила** й відмовляється їх порушувати.

Тоді інваріант охороняється в **одному** місці: всередині класу. Увесь код програми може користуватися об'єктом, не знаючи правил, а об'єкт ніколи не потрапить у поганий стан.

```csharp
class Circle
{
    private double radius;                   // приховано

    public Circle(double radius)             // єдиний спосіб створити коло
    {
        if (radius < 0) throw new ArgumentOutOfRangeException("radius");
        this.radius = radius;
    }

    public double Area() { return Math.PI * radius * radius; }
}
```

Це й є **інкапсуляція**: дані й код, що їх охороняє, упаковані разом у класі, а середина прихована. Наступні лекції показують інструменти: `private`, властивості, конструктори та `readonly`.

## Картина з життя

Автомобіль має двигун, і водій не торкається поршнів. Водій користується **педалями** та **кермом**: малим безпечним інтерфейсом. Двигун не дозволить водієві виставити швидкість 500 км/год, покрутивши гвинт. Деталі приховано, а правила машини дотримано.
