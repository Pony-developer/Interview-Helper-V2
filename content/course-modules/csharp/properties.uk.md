Публічні поля прості, але дозволяють будь-кому привести об'єкт у безглуздий стан:

```csharp
book.Pages = -500;       // книжка з від'ємною кількістю сторінок
```

**Властивість** для коду, що її використовує, виглядає як поле, а всередині це пара невеликих методів, тож клас зберігає контроль.

## Властивість із полем-сховищем

```csharp
class Book
{
    private int pages;                     // поле-сховище, приховане

    public int Pages
    {
        get { return pages; }              // виконується, коли ви ЧИТАЄТЕ book.Pages
        set                                // виконується, коли ви ЗАПИСУЄТЕ book.Pages = ...
        {
            if (value < 0) throw new ArgumentException("Pages cannot be negative");
            pages = value;                 // "value" — те, що присвоїли
        }
    }
}

var book = new Book();
book.Pages = 310;                          // викликає метод доступу set
Console.WriteLine(book.Pages);             // викликає метод доступу get
book.Pages = -5;                           // ArgumentException
```

Зовнішній код користується тим самим синтаксисом, що й для поля. Клас може **перевіряти**, **журналювати**, **обчислювати** чи **сповіщати** щоразу, коли значення читають або записують, і може пізніше змінити внутрішній устрій, нікого не зламавши.

## Автовластивості

Більшість властивостей не роблять нічого особливого. Для них C# сам пише поле-сховище:

```csharp
public string Title { get; set; }          // автовластивість: приховане поле й тривіальні методи доступу
```

Це коротше й усе одно дозволяє пізніше додати перевірку, не змінюючи тих, хто викликає. Тому **публічні дані завжди мають бути властивістю, ніколи не полем**.

## Контроль того, хто може записувати

Методи доступу можуть мати різні рівні доступу, або одного з них може не бути:

```csharp
public string Title { get; set; }              // читання й запис для всіх
public int Id { get; }                         // лише читання: можна задати тільки в конструкторі
public int Pages { get; private set; }         // усі читають, пише лише клас
```

Властивість **лише для читання** — ключ до **незмінних** об'єктів, які не можуть змінитися після створення. Про них легко міркувати, і їх безпечно ділити:

```csharp
class Point
{
    public double X { get; }
    public double Y { get; }

    public Point(double x, double y)
    {
        X = x;
        Y = y;
    }
}
```

## Обчислювані властивості

Властивість не мусить нічого зберігати. Вона може обчислювати значення за кожним читанням:

```csharp
public double Area => Width * Height;                        // лише читання, у вигляді виразу
public string FullName => FirstName + " " + LastName;
public bool IsLong => Pages >= 300;
```

`=>` після назви — скорочена форма для `{ get { return ...; } }`. Вона добре підходить для значень, що **випливають** з інших даних: вони не можуть застаріти, бо не зберігаються.

## Початкові значення та ініціалізатори об'єктів

Автовластивість може отримати значення прямо в оголошенні:

```csharp
public int Level { get; set; } = 1;
public List<string> Tags { get; } = new List<string>();
```

**Ініціалізатор об'єкта** задає властивості одразу після `new`, у фігурних дужках:

```csharp
var book = new Book { Title = "The Hobbit", Pages = 310 };
```

Він викликає конструктор без параметрів, а потім сеттери. Це добре читається, особливо для класів з багатьма необов'язковими властивостями.

## Поля чи властивості?

| | Поле | Властивість |
| --- | --- | --- |
| Перевірка під час запису | ні | так |
| Обчислюване значення | ні | так |
| Різний доступ для читання/запису | ні | так |
| Можна пізніше замінити на щось розумніше, не зламавши тих, хто викликає | ні | так |
| Добре для | **приватного** внутрішнього стану | усього **публічного** |

Домовленість: **приватне поле** починається з малої літери (або `_`), а **публічна властивість** — з великої.

## Поля readonly

Приватне поле можна позначити `readonly`: йому можна присвоювати лише в оголошенні чи в конструкторі й ніколи потім.

```csharp
private readonly string id;

public Book(string id)
{
    this.id = id;          // дозволено тут і більше ніде
}
```

Використовуйте `readonly` і властивості лише для читання максимально: менше того, що може змінитися, означає менше помилок.

## Підсумок

- Властивість — це поле з **дверима**, і клас вирішує, що відбувається біля дверей.
- `{ get; set; }` — найкоротша форма, і вона вже краща за публічне поле.
- `{ get; }` та `private set` захищають від зовнішніх змін.
- `=>` робить обчислювану властивість лише для читання.
- Ініціалізатор об'єкта задає властивості одразу після `new`.
