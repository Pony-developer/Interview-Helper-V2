**Ступінчастий масив** (масив масивів) — це масив, елементами якого є самі масиви. Внутрішні масиви можуть мати різну довжину, звідси й назва.

```csharp
int[][] rows = new int[3][];   // масив із 3 посилань, поки що всі null
rows[0] = new int[] { 1 };
rows[1] = new int[] { 2, 3 };
rows[2] = new int[] { 4, 5, 6 };
```

```text
rows ──▶ [ ● ● ● ]
           │ │ └──▶ [ 4, 5, 6 ]
           │ └────▶ [ 2, 3 ]
           └──────▶ [ 1 ]
```

## Створення

```csharp
int[][] a = new int[3][];                     // рядків ще не існує
a[0] = new int[2];                            // кожен рядок створюється окремо

int[][] b =                                   // зі значеннями
{
    new[] { 1 },
    new[] { 2, 3 },
    new[] { 4, 5, 6 },
};
```

Зверніть увагу на другу пару дужок у типі, `int[][]`, і **порожні** дужки в `new int[3][]`: вказано лише перший розмір.

## Індексація

Дві окремі операції індексації, по одній у кожній парі дужок:

```csharp
Console.WriteLine(b[2][1]);        // 5: рядок 2, потім елемент 1
Console.WriteLine(b[1].Length);    // 2: довжина одного рядка
Console.WriteLine(b.Length);       // 3: кількість рядків
```

Порівняйте `b[2][1]` із прямокутним `grid[2, 1]`.

Якщо рядок ще не створено, `a[0]` дорівнює `null`, а `a[0][1]` кидає `NullReferenceException`.

## Обхід

```csharp
for (int i = 0; i < b.Length; i++)
{
    for (int j = 0; j < b[i].Length; j++)
    {
        Console.Write(b[i][j] + " ");
    }
    Console.WriteLine();
}
```

```text
1 
2 3 
4 5 6 
```

Внутрішній цикл використовує довжину **цього** рядка, `b[i].Length`, бо рядки різні. З `foreach`:

```csharp
foreach (int[] row in b)
{
    foreach (int value in row)
    {
        Console.Write(value + " ");
    }
    Console.WriteLine();
}
```

## Приклад: трикутник Паскаля

Кожне число — сума двох над ним, тож рядок `i` має `i + 1` чисел. Така форма природна для ступінчастого масиву:

```csharp
int[][] triangle = new int[5][];
for (int i = 0; i < triangle.Length; i++)
{
    triangle[i] = new int[i + 1];
    triangle[i][0] = 1;
    triangle[i][i] = 1;
    for (int j = 1; j < i; j++)
    {
        triangle[i][j] = triangle[i - 1][j - 1] + triangle[i - 1][j];
    }
}
```

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

## Ступінчастий чи прямокутний?

| | Прямокутний `int[,]` | Ступінчастий `int[][]` |
| --- | --- | --- |
| Довжини рядків | усі однакові | у кожного своя |
| Індексація | `a[r, c]` | `a[r][c]` |
| Пам'ять | один блок | один масив посилань і по масиву на рядок |
| Створення | `new int[3, 4]` | `new int[3][]`, потім кожен рядок |
| Довжина рядка | `GetLength(1)` | `a[r].Length` |
| Добре для | дощок, зображень, матриць | трикутників, списків списків, таблиці рядків різного розміру |

Якщо всі рядки мають однакову довжину, прямокутний масив простіший. Якщо ні, або ви хочете **замінювати чи міняти місцями цілі рядки**, обирайте ступінчастий:

```csharp
int[] temp = b[0];
b[0] = b[2];
b[2] = temp;    // обмін двох рядків без копіювання елементів
```

## Пастки

- **Забути створити рядки.** `new int[3][]` дає три `null`, а не три масиви.
- **Випадково поділити рядок.** Якщо написати `a[0] = a[1]`, обидва рядки — один масив, і зміна через один видна в іншому (див. лекцію про посилальні типи).
- **Використати `GetLength` для ступінчастого масиву.** Він описує лише зовнішній масив. Внутрішні довжини — це `a[i].Length`.
- **Копіювання через `Clone`.** Воно копіює лише зовнішній масив. Самі рядки спільні для копії та оригіналу.
