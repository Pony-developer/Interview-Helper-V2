Brainfuck — маленька мова програмування з вісьма командами, і це добра перевірка циклів і масивів. Програма працює з **стрічкою** (tape) з 30000 байтових комірок, а вказівник починається з комірки 0:

| Команда | Значення |
|---|---|
| `>` | перемістити вказівник на одну комірку праворуч |
| `<` | перемістити вказівник на одну комірку ліворуч |
| `+` | додати 1 до поточної комірки (255 + 1 стає 0) |
| `-` | відняти 1 від поточної комірки (0 - 1 стає 255) |
| `.` | вивести поточну комірку як символ |
| `,` | прочитати наступний символ введення в поточну комірку (0 наприкінці введення) |
| `[` | якщо поточна комірка дорівнює 0, перейти вперед до парної `]` |
| `]` | якщо поточна комірка не 0, перейти назад до парної `[` |

Напишіть метод `static string Run(string program, string input)`. Він інтерпретує програму й повертає текст, який вона виводить. `Main` не змінюйте. Очікуваний вивід:

```text
Hello World!
A
B
```

Рядки: програма `++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.` виводить `Hello World!` і перенос рядка; програма `++++++++[>++++++++<-]>+.` виводить `A`; а програма `,+.` з введенням `A` виводить `B`.

Підказки:
- Використовуйте `byte[] tape = new byte[30000];`. Байтова арифметика сама переповнюється, тож `255 + 1` дає `0`.
- Перед запуском один раз зіставте дужки: пройдіть програму зі `Stack<int>` і запишіть у масив позицію парної для кожної дужки. Тоді `[` і `]` стрибають за сталий час.
- Для виводу використовуйте `StringBuilder`, а всередині циклу `for` по програмі — `switch` за символом команди.
