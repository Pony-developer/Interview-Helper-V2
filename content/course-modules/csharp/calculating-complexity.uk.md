Щоб знайти складність шматка коду, ви рахуєте, скільки разів виконуються його операції, як функцію від `n`. Кілька правил охоплюють майже кожен випадок.

## Правила

**1. Проста інструкція — один крок.**

```csharp
int x = a + b;       // 1
```

**2. Інструкції одна за одною: додавайте.**

```csharp
x = 1;               // 1
y = 2;               // 1
z = x + y;           // 1       разом: 3
```

**3. Цикл: помножте кількість проходів на вартість тіла.**

```csharp
for (int i = 0; i < n; i++)     // n проходів
{
    sum += a[i];                // по 1 кроку       разом: n
}
```

**4. Цикли всередині циклів: множте.**

```csharp
for (int i = 0; i < n; i++)         // n проходів
    for (int j = 0; j < n; j++)     // по n проходів
        count++;                    // разом: n · n = n²
```

**5. Цикли з різними межами лишаються різними.**

```csharp
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        count++;                    // n · m   (а не n²!)
```

**6. Умова: беріть дорожчу гілку (найгірший випадок).**

```csharp
if (a[0] > 0)
    DoCheap();           // 1
else
    DoExpensive();       // n          вартість: n
```

**7. Виклик: додайте вартість методу, що викликається.**

## Цикли, лічильник яких змінюється інакше

| Цикл | Проходів |
| --- | --- |
| `for (i = 0; i < n; i++)` | n |
| `for (i = 0; i < n; i += 2)` | n / 2 |
| `for (i = 0; i < n; i += k)` | n / k |
| `for (i = n; i > 0; i--)` | n |
| `for (i = 1; i < n; i *= 2)` | log₂ n |
| `for (i = n; i > 1; i /= 2)` | log₂ n |
| `for (i = 1; i * i <= n; i++)` | √n |

Цикл, що **множить чи ділить** лічильник, виконується **логарифмічну** кількість разів: скільки разів можна подвоїти 1, перш ніж досягти `n`? Для `n = 1024` — рівно 10 разів.

## Трикутник: залежний внутрішній цикл

```csharp
for (int i = 0; i < n; i++)
    for (int j = 0; j < i; j++)     // межа внутрішнього залежить від i
        count++;
```

Тіло внутрішнього виконується 0 разів для `i = 0`, потім 1, 2, ..., `n − 1`. Загальна кількість —

```text
0 + 1 + 2 + ... + (n − 1) = n · (n − 1) / 2
```

Для `n = 5`: 0 + 1 + 2 + 3 + 4 = 10, і 5 · 4 / 2 = 10. Це приблизно **n² / 2**: половина квадрата, але все одно **квадратична**. Та сама сума з'являється щоразу, коли код розглядає кожну пару елементів один раз.

Корисна сума, яку варто пам'ятати: `1 + 2 + ... + n = n · (n + 1) / 2`.

## Логарифм на n

```csharp
for (int i = 0; i < n; i++)             // n проходів
    for (int j = 1; j < n; j *= 2)      // по log₂ n проходів
        count++;                        // n · log₂ n
```

Така форма, лінійний цикл із циклом ділення чи подвоєння всередині, типова для ефективних сортувань.

## Розібраний приклад

```csharp
static int Example(int[] a)
{
    int n = a.Length;
    int count = 0;                              // 1

    for (int i = 0; i < n; i++)                 // A: n проходів
        count += a[i];                          //    по 1 кроку

    for (int i = 0; i < n; i++)                 // B: n проходів
        for (int j = 0; j < n; j++)             //    по n проходів
            if (a[i] == a[j]) count++;          //    по 1 кроку

    return count;                               // 1
}
```

Вартість — `T(n) = 1 + n + n² + 1 = n² + n + 2`. Для великих `n` домінує доданок `n²`: для `n = 1000` це 1 000 000 проти 1 000 для доданка `n`. Отже, код квадратичний, тобто **O(n²)**. (Наступні лекції пояснюють, чому ми відкидаємо менші доданки та сталі.)

## Що рахувати

- Рахуйте **домінантну** операцію, ту, що у найглибшому циклі, і ігноруйте службову роботу.
- Для **рекурсії** запишіть, скільки викликів робиться і скільки роботи виконує кожен. Метод, що викликає себе двічі з `n − 1` щоразу, робить близько 2ⁿ викликів. Метод, що викликає себе раз з `n / 2`, робить близько log₂ n викликів.
- Не забувайте про **приховані цикли**: `Contains`, `IndexOf`, `Substring`, `string +`, `Insert(0, x)` — усі беруть час пропорційно даним, яких торкаються.
- Кажіть, який **випадок** аналізуєте: найгірший, найкращий чи середній.

## Перевірка експериментом

Підрахунок можна перевірити, запустивши код і порахувавши:

```csharp
long count = 0;
for (int i = 0; i < n; i++)
    for (int j = 0; j < i; j++)
        count++;
Console.WriteLine(count);    // n = 1000 дає 499500 = 1000 · 999 / 2
```

Подвоєння `n` і спостереження за підрахунком — швидка перевірка зростання: якщо підрахунок збільшився приблизно вчетверо, алгоритм квадратичний.
