Кожне поле структури отримує типове значення, але локальна змінна структури має правило, якого немає в змінної класу: **її поля мають бути присвоєні, перш ніж їх читають**.

```csharp
struct Point
{
    public int X;
    public int Y;
}

Point p;
// Console.WriteLine(p.X);         // помилка CS0170: use of unassigned field
p.X = 1;
p.Y = 2;
Console.WriteLine(p.X + p.Y);      // 3, тепер добре
```

Компілятор перевіряє це для кожної локальної структури. Прості способи переконатися, що всі поля задані:

```csharp
Point a = new Point();                  // усі поля дорівнюють 0
Point b = new Point { X = 3, Y = 4 };   // ініціалізатор об'єкта
```

## Конструктор структури

У структури може бути конструктор з параметрами. У C# 7 такий конструктор **мусить присвоїти кожне поле**, інакше він не компілюється:

```csharp
struct Point
{
    public int X;
    public int Y;

    public Point(int x, int y)
    {
        X = x;
        Y = y;
    }
}

Point p = new Point(3, 4);
```

У C# 7 структура не може мати **конструктора без параметрів**, написаного вами (типовий завжди існує). Коли потрібне інше початкове значення, вживайте ініціалізатор об'єкта або фабричний метод.

## Ініціалізатори полів

У C# 7 структура не може мати ініціалізаторів полів на кшталт `public int X = 5;`. Поля отримують значення з конструктора або з коду, що використовує структуру. Це ще одна причина тримати структури малими й простими.
