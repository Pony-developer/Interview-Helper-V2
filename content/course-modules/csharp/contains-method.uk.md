`Contains(item)` відповідає на одне питання: чи є елемент, що дорівнює `item`? Щоб відповісти, список перевіряє елементи по одному, з початку:

```csharp
var numbers = new List<int> { 4, 8, 15 };
Console.WriteLine(numbers.Contains(8));    // True
Console.WriteLine(numbers.Contains(9));    // False
```

Пошук у незсортованому списку коштує **O(n)**: у найгіршому випадку перевіряють кожен елемент. `IndexOf` повертає позицію першого збігу, а `Remove` видаляє перший збіг.

## Що означає «рівні»

Для чисел і рядків рівні означає рівні за значенням. Для вашого класу список використовує метод `Equals` через типовий компаратор. Якщо `Equals` не перевизначено, два різні об'єкти з однаковими даними **не** рівні:

```csharp
class Point
{
    public int X;
    public int Y;
}

var points = new List<Point> { new Point { X = 1, Y = 2 } };
Console.WriteLine(points.Contains(new Point { X = 1, Y = 2 }));   // False!
```

Дві точки мають однакові дані, але це різні об'єкти, а типовий `Equals` порівнює посилання. Виправлення — перевизначити `Equals`, що показано в наступній лекції.

## Те саме для Remove і IndexOf

`Remove(item)` і `IndexOf(item)` використовують те саме порівняння. Якщо клас не визначає рівність, його об'єкти не можна знайти чи видалити за значенням. Пам'ятайте про це, проєктуючи клас, який зберігатимуть у списках.
