The list on the left shows every module of the course. Open a module to see its slides; the icon next to each slide tells you what it is:

- **Lecture.** Read it and try the examples. A lecture counts as done once you open it.
- **Quiz.** Answer the questions. Every fully correct answer is worth one point, and you can try again: your best score is kept.
- **Practice.** Write C# right in the browser. We compile and run your program and compare what it prints with the expected output, character for character.

The gold line in the sidebar fills in as you go. Sign in and your scores and code are saved, so you can stop at any slide and pick up later.

## About running code

Practice code runs on [Wandbox](https://wandbox.org), a free online compiler, with Mono's C# compiler (C# 7). A run takes a few seconds. Newer language features, such as records or nullable reference types, are not available there, and none of the tasks need them.

## A few rules

- When a task looks unclear or a check seems wrong, re-read the statement: the expected output is always exact, down to spaces and capital letters.
- Please don't publish your solutions. The tasks are only useful if everyone solves them on their own.
