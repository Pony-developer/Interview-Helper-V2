**Задача** (`System.Threading.Tasks.Task`) — це операція, яка завершиться в майбутньому. Це обіцянка: «робота виконується, і ти можеш запросити результат, коли він буде готовий». Задача, що дає значення, — `Task<T>`; задача, що нічого не дає, — `Task`.

```csharp
using System.Threading.Tasks;

Task<int> sumTask = Task.Run(() =>
{
    int sum = 0;
    for (int i = 1; i <= 100; i++) sum += i;
    return sum;                                // значення задачі
});

Console.WriteLine("робота виконується у фоні...");
Console.WriteLine(sumTask.Result);             // 5050: чекає тут, якщо робота не завершена
```

## Стан задачі

Задача проходить стани: створена, виконується, потім завершена (з результатом), із помилкою (сталося виключення) або скасована. `IsCompleted`, `IsFaulted` і `IsCanceled` показують, у якому вона стані.

## Очікування задачі

- `Wait()` блокує поточний потік, доки задача не завершиться.
- `Result` робить те саме і повертає значення `Task<T>`.

Обидва блокують викликаючий потік. Блокування прийнятне в `Main` консольної програми, але **ніколи** не чекайте задачі в потоці UI: вікно завмре, а це та проблема, яку розв'язав попередній модуль. Наступні лекції показують, як `await` чекає, не блокуючи.

## Навіщо задачі, а не потоки

Потік — ресурс, яким керує програміст. Задача описує **що** зробити, а середовище вибирає потік, зазвичай з пулу, який повторно використовується. Задачі дешево створювати, і вони можуть повертати результати та винятки, чого простий потік не вміє.
