**Метод** — це іменований блок коду, який можна запускати щоразу, коли він потрібен. Ви вже користувалися методами, які написали інші (`Console.WriteLine`, `Math.Sqrt`, `ToUpper`), і одним власним: `Main`. Власні методи дають змогу назвати шматок логіки, використовувати його повторно та перевіряти окремо.

## Будова методу

```csharp
static int Add(int a, int b)
{
    return a + b;
}
```

- `static` поки що пишіть це слово в кожному методі; його пояснять у модулях про об'єктно-орієнтоване програмування.
- `int` — **тип значення, що повертається**: тип того, що метод віддає назад.
- `Add` — ім'я. Методи пишуть у **PascalCase**, а ім'я зазвичай є дієсловом або питанням: `Add`, `PrintReport`, `IsEven`.
- `(int a, int b)` — **параметри**: змінні, які отримують вхідні дані.
- `return` завершує метод і передає значення тому, хто його викликав.

## Виклик методу

Значення, які ви передаєте під час виклику, називаються **аргументами**. Вони зіставляються з параметрами за позицією:

```csharp
static void Main()
{
    int sum = Add(2, 3);                    // 5
    Console.WriteLine(Add(sum, 10));        // 15
    Console.WriteLine(Add(Add(1, 2), 4));   // 7, виклик може бути аргументом
}
```

Компілятор перевіряє виклик: кількість аргументів має збігатися, а кожен аргумент — підходити за типом до свого параметра. `Add("2", 3)` не скомпілюється.

## void

Метод, який щось робить, але нічого не повертає, має тип `void`:

```csharp
static void Greet(string name)
{
    Console.WriteLine("Hello, " + name + "!");
}

Greet("Ann");   // Hello, Ann!
```

Метод `void` викликають як окрему інструкцію. Зберегти його результат не можна, бо результату немає.

## return

`return` одразу зупиняє метод, тож код під ним не виконується. Метод, тип якого не `void`, мусить повернути значення на **кожному** шляху виконання, інакше він не скомпілюється:

```csharp
static int Twice(int x)
{
    int result = x * 2;
    // помилка CS0161: 'Twice(int)': not all code paths return a value
}
```

Виправити можна, завершивши метод рядком `return result;`.

## Короткий запис

Метод, що складається з одного виразу, можна записати через `=>`:

```csharp
static int Square(int x) => x * x;
```

## Аргументи — це копії

Коли ви передаєте змінну, метод отримує **копію** її значення, тож зміна параметра не змінює змінну того, хто викликав:

```csharp
static void AddOne(int x)
{
    x = x + 1;
}

int n = 5;
AddOne(n);
Console.WriteLine(n);   // 5
```

Якщо потрібен результат, поверніть його й присвойте: `n = AddOne(n);`.

## Необов'язкові параметри та перевантаження

Параметр може мати значення за замовчуванням, а аргументам під час виклику можна давати імена:

```csharp
static string Greeting(string name, string word = "Hello")
{
    return word + ", " + name + "!";
}

Console.WriteLine(Greeting("Ann"));                 // Hello, Ann!
Console.WriteLine(Greeting("Ann", "Welcome"));      // Welcome, Ann!
Console.WriteLine(Greeting(word: "Hi", name: "Bo")); // Hi, Bo!
```

Кілька методів можуть мати одне ім'я, якщо їхні списки параметрів різні. Це **перевантаження**, і саме завдяки йому `Console.WriteLine` приймає стільки видів значень:

```csharp
static int Twice(int x) => x * 2;
static double Twice(double x) => x * 2;
static string Twice(string s) => s + s;
```

## Змінні всередині методу

Змінні, оголошені всередині методу, зокрема його параметри, існують лише там. Два методи можуть мати по змінній `total` без жодного конфлікту. Методи можуть викликати один одного, а `Main` — лише той, який середовище виконання викликає першим.

## Навіщо це все

- Ім'я пояснює намір краще, ніж п'ять рядків арифметики.
- Помилку виправляєте в одному місці, а не в кожній копії.
- Малі методи легко тестувати: викликаєте з відомими даними й порівнюєте результат із очікуваним.
