Кожен тип у C# є або **значеннєвим**, або **посилальним**. Від цього залежить, що станеться, коли ви копіюєте змінну, порівнюєте дві чи передаєте одну в метод.

## Значеннєві типи

Змінна значеннєвого типу **містить саме значення**.

Значеннєві типи — це числа (`int`, `long`, `double`, `decimal`, ...), `bool`, `char`, переліки (enum) та структури.

```csharp
int a = 5;
int b = a;       // b отримує власну копію 5
b = 10;
Console.WriteLine(a);   // 5
```

## Посилальні типи

Змінна посилального типу **містить посилання**: адресу об'єкта десь в іншому місці пам'яті. Масиви, `string` та класи — посилальні типи.

```csharp
int[] x = { 1, 2, 3 };
int[] y = x;            // y посилається на ТОЙ САМИЙ масив
y[0] = 100;
Console.WriteLine(x[0]);   // 100
```

```text
x ──┐
    ├──▶ [ 100, 2, 3 ]
y ──┘
```

`int[] y = x;` копіює посилання, а не масив. Масив один, а імен у нього два.

## null

Посилання може вказувати в нікуди. Це `null`, який також є значенням за замовчуванням для непризначеного посилального поля чи елемента масиву посилального типу:

```csharp
int[] data = null;
Console.WriteLine(data.Length);   // NullReferenceException: немає масиву, у якого спитати
```

Змінна значеннєвого типу ніколи не може бути `null`.

## Порівняння

`==` для значеннєвих типів порівнює **значення**. Для масивів він порівнює **посилання**, тобто чи це той самий масив:

```csharp
int[] p = { 1, 2 };
int[] q = { 1, 2 };
int[] r = p;
Console.WriteLine(p == q);   // False: два різні масиви з однаковим умістом
Console.WriteLine(p == r);   // True: той самий масив
```

Щоб порівняти вміст, елементи треба пройти самостійно.

## string — особливий

`string` — посилальний тип, але **незмінний**: жоден метод не змінює наявний рядок, а `==` визначено так, що воно порівнює текст. Тому в повсякденному використанні він поводиться як значеннєвий:

```csharp
string s = "hi";
string t = s;
t = t + "!";            // створює новий рядок; s не змінюється
Console.WriteLine(s);   // hi
```

## Що містить масив

- `int[]` — масив значень: числа зберігаються в самому масиві.
- `string[]` — масив **посилань**: кожен елемент посилається на рядок або дорівнює `null`.
- Сама змінна масиву — це посилання, який би не був тип елементів.

## Копіювання масиву

Щоб отримати незалежний масив, створіть новий і скопіюйте елементи:

```csharp
int[] original = { 1, 2, 3 };

int[] copy1 = (int[])original.Clone();        // поверхнева копія
int[] copy2 = new int[original.Length];
Array.Copy(original, copy2, original.Length);

int[] copy3 = new int[original.Length];       // або вручну
for (int i = 0; i < original.Length; i++) copy3[i] = original[i];
```

«Поверхнева» означає, що самі елементи копіюються як є. Для масиву чисел цього достатньо. Для масиву посилань копія містить ті самі об'єкти, що й оригінал.

## Чому це важливо

- Зміна через одне посилання видима через усі інші.
- Передача масиву в метод дає методу доступ до **тих самих** даних (див. наступну лекцію).
- Якщо зберегти отриманий масив замість копіювання, ваші дані зв'яжуться з даними того, хто викликав.
- Порівнювати масиви через `==` майже ніколи не потрібно.
