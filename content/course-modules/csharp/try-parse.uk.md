Напишіть метод `DoubleIt(text)`. Він отримує текст із форми та:

- якщо текст — коректне ціле число (`int`), повертає це число, **подвоєне**, як текст;
- інакше повертає текст `invalid`.

Метод не повинен аварійно завершуватися на жодних даних, зокрема на `"abc"`, порожньому рядку, `"3.5"` та `"99999999999"` (завелике для `int`). Використайте `int.TryParse` за шаблоном із лекції:

```csharp
if (int.TryParse(text, out int number))
{
    // тут number містить розпізнане значення
}
```

`Main` не змінюйте. Очікуваний вивід:

```text
84
invalid
invalid
-30
invalid
invalid
```

Підказка: `(number * 2).ToString()` перетворює результат назад на текст.
