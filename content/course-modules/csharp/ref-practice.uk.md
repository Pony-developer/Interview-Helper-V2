Структура `Counter` готова, а `Main` уже вживає три методи, яких ще немає. Напишіть їх у класі `Program` вище за `Main`:

- `Swap(ref int a, ref int b)`: обмінює значення двох змінних;
- `Double(ref int x)`: подвоює значення;
- `Reset(ref Counter counter)`: встановлює поле `Value` лічильника в `0`.

Кожен метод мусить **змінити змінну викликаючого**, тому вживайте `ref`. `Main` і структуру `Counter` не змінюйте. Очікуваний вивід:

```text
7 3
14
0
2
8
8
```

Рядки по порядку: обмін `3` і `7`; подвоєння `7` (після обміну `a` тримає `7`) дає `14`; `Reset` робить лічильник `0`; додавання `2` після скидання дає `2`; три подвоєння `1` дають `8`; а `Swap(ref x, ref x)` залишає `8` без змін, бо обидва параметри — та сама змінна.

Підказка: `Swap` потребує тимчасової змінної: `int t = a; a = b; b = t;`. `Double` — це `x = x * 2;`. `Reset` змінює поле структури, на яку вказує параметр: `counter.Value = 0;`.
