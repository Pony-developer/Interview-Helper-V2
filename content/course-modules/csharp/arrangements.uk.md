Попередні лекції рахували способи обрати й упорядкувати **всі** елементи. **Розміщення** та **комбінації** обирають лише **деякі** з них. Чотири питання визначають, яка формула вам потрібна:

1. Ви беретеся за **всі** елементи чи лише за `k`?
2. Чи має значення **порядок**? (`ab` та `ba` різні чи однакові.)
3. Чи можуть елементи **повторюватися**?

## Чотири випадки

Для `n` елементів, беручи `k`:

| Назва | Порядок важливий? | Повтори? | Кількість | `n = 3, k = 2` з `a, b, c` |
| --- | --- | --- | --- | --- |
| **Розміщення з повтореннями** | так | так | nᵏ | 9: `aa ab ac ba bb bc ca cb cc` |
| **Розміщення** (без повторень) | так | ні | n! / (n − k)! | 6: `ab ac ba bc ca cb` |
| **Комбінації** | ні | ні | n! / (k! · (n − k)!) | 3: `ab ac bc` |
| **Перестановки** (усіх) | так | ні | n! | 6 з 3 елементів: `abc acb ...` |

Перестановка — особливий випадок розміщення з `k = n`.

Життєві приклади:

- **Пароль** із 4 цифр: порядок важливий, цифри повторюються: 10⁴ = **10 000**.
- **П'єдестал**: золото, срібло й бронза серед 5 бігунів: порядок важливий, повторів немає: 5 · 4 · 3 = **60**.
- **Команда** з 3 людей із 5: порядок не важливий: C(5, 3) = **10**.

## Розміщення з повтореннями: n^k

На кожній із `k` позицій може стояти будь-який із `n` елементів. Уявіть замок із `k` колесами по `n` символів. Саме це перебирає **атака на пароль перебором**:

```csharp
static void Passwords(string alphabet, int length, string prefix, List<string> result)
{
    if (prefix.Length == length)
    {
        result.Add(prefix);
        return;
    }
    foreach (char c in alphabet)
        Passwords(alphabet, length, prefix + c, result);
}
```

З `alphabet = "ab"` та `length = 3` порядок такий: `aaa, aab, aba, abb, baa, bab, bba, bbb`, як лічба в двійковій системі. Дерево має `length` рівнів, у кожному вузлі `n` дітей, тож `n^length` листків.

Для паролів із 8 символів, узятих із 62 літер і цифр, це 62⁸ ≈ 2 · 10¹⁴ спроб: ось чому довгий пароль — добрий захист, і ось чому програма перевіряє перші символи й рано здається (відсікання), коли може.

## Розміщення без повторень: n! / (n − k)!

Те саме, що перестановка, але ми зупиняємося після `k` позицій:

```csharp
static void Arrange(string items, int k, bool[] used, string prefix, List<string> result)
{
    if (prefix.Length == k)                       // k позицій заповнено
    {
        result.Add(prefix);
        return;
    }
    for (int i = 0; i < items.Length; i++)
    {
        if (used[i]) continue;
        used[i] = true;
        Arrange(items, k, used, prefix + items[i], result);
        used[i] = false;                          // повернення назад
    }
}
```

`Arrange("abc", 2, ...)` дає `ab, ac, ba, bc, ca, cb`: 6 результатів = 3 · 2. Єдина відмінність від перестановок — базовий випадок: `k` замість `n`.

Формула походить із того самого добутку, що й раніше, але обірваного: `n · (n − 1) · ... · (n − k + 1)`. Для п'єдесталу `5 · 4 · 3 = 60`.

## Комбінації: n! / (k! · (n − k)!)

Коли порядок не важливий, розміщення рахують кожну групу `k!` разів (усі порядки тих самих `k` елементів), тож ми ділимо на `k!`.

Щоб згенерувати кожну групу **один раз**, накладіть порядок самі: завжди обирайте елементи **зі зростанням індексу**, щоб `ba` ніколи не генерувалося після `ab`:

```csharp
static void Combine(string items, int k, int start, string prefix, List<string> result)
{
    if (prefix.Length == k)
    {
        result.Add(prefix);
        return;
    }
    for (int i = start; i < items.Length; i++)
        Combine(items, k, i + 1, prefix + items[i], result);     // продовжуємо ПІСЛЯ i
}
```

`Combine("abcd", 2, 0, "", r)` дає `ab, ac, ad, bc, bd, cd`: 6 = «4 по 2».

## Числа C(n, k)

Біноміальні коефіцієнти утворюють **трикутник Паскаля**, у якому кожне число — сума двох над ним. Це теж рекурсія:

```text
C(n, k) = C(n − 1, k − 1) + C(n − 1, k)       останній елемент обрано або не обрано
C(n, 0) = C(n, n) = 1
```

```csharp
static long C(int n, int k)
{
    if (k == 0 || k == n) return 1;
    return C(n - 1, k - 1) + C(n - 1, k);
}
```

Дерево має перекривні підзадачі (як Фібоначчі), тож для більших значень застосуйте мемоїзацію або обчислюйте добуток напряму. Кілька значень: C(5, 2) = 10, C(10, 5) = 252, C(20, 10) = 184 756, C(32, 16) = 601 080 390.

Числа в рядку трикутника в сумі дають **2ⁿ**: C(n, 0) + C(n, 1) + ... + C(n, n) = 2ⁿ. Це кількість підмножин `n`-елементної множини, згрупованих за розміром.

## Вибір правильного інструмента

| Завдання | Інструмент |
| --- | --- |
| усі підмножини | включити чи пропустити, 2ⁿ |
| усі підмножини заданого розміру `k` | комбінації |
| усі порядки всіх елементів | перестановки |
| усі впорядковані вибірки з `k` | розміщення |
| усі слова заданої довжини над алфавітом | розміщення з повтореннями |

## Межі та відсікання

Усе це зростає вибухово. Перш ніж писати код, **порахуйте, скільки буде результатів**. Якщо це мільярд, потрібна розумніша ідея або сильніше відсікання: припиняйте будувати часткову відповідь, щойно вона вже не може бути коректною (правило про сусідів, сума, що стала завеликою), замість того щоб будувати її всю й перевіряти наприкінці.
