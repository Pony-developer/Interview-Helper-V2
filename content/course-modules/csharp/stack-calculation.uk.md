Запис `2 + 3 * 4` так, як пишуть люди, потребує правил пріоритету. Значно простіша нотація — **зворотний польський запис** (ЗПЗ, RPN): оператор ставиться **після** своїх операндів. `3 4 + 2 *` означає `(3 + 4) * 2`. Дужок немає, пріоритетів пам'ятати не треба, і стек обчислює такий вираз напряму:

- число кладеться в стек;
- оператор знімає два числа, виконує дію й кладе результат назад.

```csharp
static int EvaluateRpn(string expression)
{
    var stack = new Stack<int>();
    foreach (string token in expression.Split(' '))
    {
        if (token == "+" || token == "-" || token == "*")
        {
            int right = stack.Pop();          // другий операнд зверху
            int left = stack.Pop();
            if (token == "+") stack.Push(left + right);
            else if (token == "-") stack.Push(left - right);
            else stack.Push(left * right);
        }
        else
        {
            stack.Push(int.Parse(token));
        }
    }
    return stack.Pop();
}

Console.WriteLine(EvaluateRpn("3 4 + 2 *"));    // 14
Console.WriteLine(EvaluateRpn("10 2 8 * + 3 -")); // 23
```

Розгляньмо `3 4 + 2 *`:

| Токен | Стек після |
|---|---|
| `3` | `3` |
| `4` | `3 4` |
| `+` | `7` (знімає 4 і 3, кладе 7) |
| `2` | `7 2` |
| `*` | `14` |

## Порядок двох знімань

`right` знімається **першим**, бо був покладений останнім. Для віднімання це важливо: у `10 4 -` лівий операнд — `10`, тож `left - right` дає `10 - 4 = 6`. Якщо поміняти знімання місцями, відповідь буде неправильною.

## Чому це важливо

Компілятори й калькулятори переводять звичайну нотацію в ЗПЗ (алгоритм сортувальної станції) і потім обчислюють її стеком. Стеки — основа обчислення виразів.
