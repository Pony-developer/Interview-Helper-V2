Клас `Person` нижче написано довгим способом: приватні поля, конструктор і окремі методи `Get`. `Main` використовує його **сучасним** способом: через **ініціалізатор об'єкта** (`new Person { Name = "Ann", BirthYear = 1990 }`) і властивості, тому програма не компілюється.

Перепишіть `Person` зі скороченим синтаксисом:

- `Name` та `BirthYear` — **автовластивості** з `get` і `set`;
- `Greeting` — **обчислювана властивість лише для читання**, записана через `=>`: вона повертає `"Hello, " + Name + "!"`;
- `AgeIn(year)` — метод, записаний через `=>`: рік мінус рік народження.

Конструктор не потрібен: C# надає порожній, а ініціалізатор об'єкта заповнює властивості. Увесь клас має бути лише кількома рядками. `Main` не змінюйте. Очікуваний вивід:

```text
Hello, Ann!
36
Hello, Anna!
0
2000
```

Рядки по порядку: привітання для Ann; її вік у 2026 році; привітання після зміни імені на `Anna`; рік народження людини, для якої його не задано (незадана властивість `int` дорівнює 0); і «вік» у 2000 році для цієї людини.

Підказка: `public string Name { get; set; }`, `public string Greeting => "Hello, " + Name + "!";`. Оскільки `Greeting` обчислюється під час кожного читання, вона сама відстежує зміну `Name`.
