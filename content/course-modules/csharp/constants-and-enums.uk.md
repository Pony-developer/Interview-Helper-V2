Числа та рядки з прихованим змістом роблять код крихким. Чи `2` — це статус, місяць, кількість повторних спроб? Константи й перелічення (enum) дають таким значенням ім'я, яке перевіряє компілятор.

## Константи

З `const` ви познайомилися в лекції про змінні. Константа фіксується під час компіляції й ніколи не може отримати нове значення:

```csharp
const int MaxAttempts = 3;
const double Pi = 3.14159;
const string AppName = "Assay";
```

- Значення має бути відоме під час компіляції: літерал або вираз із констант.
- Константи називають у **PascalCase**.
- Константу можна оголосити всередині методу або на рівні класу, де нею користуватимуться всі методи:

```csharp
class Program
{
    const int VatPercent = 20;

    static int WithVat(int price)
    {
        return price + price * VatPercent / 100;
    }
    // ...
}
```

Змінити значення — це правка в одному рядку, а будь-яку спробу присвоєння компілятор відхилить.

## Enum

**Enum** (перелічення) — це тип із фіксованим набором іменованих значень:

```csharp
enum Level
{
    Low,
    Medium,
    High
}
```

Користуйтеся ним як типом:

```csharp
Level level = Level.High;
Console.WriteLine(level);   // High
```

Порівняйте з числами `0`, `1`, `2` або рядками `"low"`, `"medium"`, `"high"`: з enum одруківка не скомпілюється, редактор підказує можливі значення, а зміст міститься в імені.

## Числа за іменами

За кожним іменем стоїть `int`. За замовчуванням перше дорівнює `0`, а кожне наступне більше на одиницю. Числа можна задати самому:

```csharp
enum Weekday
{
    Monday = 1,
    Tuesday,      // 2
    Wednesday,    // 3
    Thursday,     // 4
    Friday,       // 5
    Saturday,     // 6
    Sunday        // 7
}
```

**Приведення типу** перетворює enum на число й навпаки:

```csharp
Console.WriteLine((int)Weekday.Friday);   // 5
Weekday day = (Weekday)3;
Console.WriteLine(day);                   // Wednesday
```

Приведення не перевіряє, чи число коректне: `(Weekday)42` компілюється й дає значення без імені, яке друкується як `42`.

## Де оголошувати

Enum оголошують на рівні класу, поруч із методами (як вкладений тип), або поза будь-яким класом. Усередині методу його оголосити не можна. Назви enum — іменники в однині в **PascalCase**, як-от `Level` чи `OrderStatus`, і назви їхніх членів так само.

## Що коли обирати

- **`const`** для одного значення, яке не повинно змінюватися: ставка, ліміт, заголовок.
- **`enum`**, коли значення має бути одним із невеликого відомого набору: день, рівень, стан замовлення.

З enum ви ще працюватимете в інструкції `switch` у модулі про розгалуження, де зручно обробити кожен випадок.
