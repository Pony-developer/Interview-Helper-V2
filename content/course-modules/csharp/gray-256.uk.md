Зображення в градаціях сірого має пікселі з **256 відтінками**: від 0 (чорний) до 255 (білий). Дамо йому клас, щоб пікселі й операції над ними жили разом.

Напишіть клас `GrayImage` (над `Program`):

- конструктор `GrayImage(width, height)`: усі пікселі дорівнюють 0 (чорні);
- `Set(x, y, value)`: задає піксель. Значення нижче 0 стає **0**, а вище 255 — **255** (воно **обмежується**). `x` — стовпчик, `y` — рядок;
- `Get(x, y)`: читає піксель;
- `Row(y)`: пікселі рядка `y` як текст, розділені одинарними пробілами, наприклад `0 128 255`;
- `Invert()`: повертає **нове** зображення, у якому кожен піксель дорівнює `255 − value`. Початкове не змінюється;
- `Histogram()`: `int[256]`, де елемент `v` — це **кількість пікселів** зі значенням `v`;
- `Average()`: середня яскравість усіх пікселів, `double`.

Пікселі мають бути **приватними**: зовнішній код користується лише методами. `Main` не змінюйте. Очікуваний вивід:

```text
0 128 255
255 0 128
255 127 0
0 128 255
2 2 2 256
127.67
```

Рядки по порядку, для зображення 3 × 2 пікселі: перший рядок; другий рядок (піксель, заданий як 300, став 255, а заданий як −5 став 0); перший рядок **інвертованого** зображення; перший рядок **початкового**, що показує, що його не змінено; кількості пікселів зі значеннями 0, 128 і 255 та довжина гістограми; і середня яскравість, округлена до двох знаків після коми: (0 + 128 + 255 + 255 + 0 + 128) / 6.

Підказка: зберігайте пікселі в `int[,]` або в одновимірному масиві розміру `width · height`. `Math.Clamp` у старих версіях .NET немає, тож використайте `Math.Max(0, Math.Min(255, value))`.
