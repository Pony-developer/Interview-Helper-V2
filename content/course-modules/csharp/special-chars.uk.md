Деякі символи не можна ввести в рядковий літерал звичайним способом: перенесення рядка, табуляцію, лапку. А `char` — це більше, ніж літера: це ще й число. Ця лекція про обидва аспекти.

## Escape-послідовності

Зворотна скісна риска починає спеціальний символ:

| Запис | Символ |
| --- | --- |
| `\n` | новий рядок (line feed) |
| `\r` | повернення каретки (закінчення рядків у Windows — `\r\n`) |
| `\t` | табуляція |
| `\\` | зворотна скісна риска |
| `\"` | подвійна лапка всередині рядка |
| `\'` | одинарна лапка всередині `char` |
| `\0` | нульовий символ (код 0) |
| `\u0436` | символ із кодом Unicode 0436 hex (тут — кирилична ж) |
| `\x41` | символ із шістнадцятковим кодом 41 (A) |

```csharp
Console.WriteLine("Name:\tAnn\nAge:\t31");
```

```text
Name:   Ann
Age:    31
```

```csharp
Console.WriteLine("She said \"hi\"");   // She said "hi"
Console.WriteLine("C:\\temp\\file.txt"); // C:\temp\file.txt
```

**Дослівний рядок** `@"..."` сприймає зворотні скісні риски буквально, а перенесення рядка в коді стає перенесенням у рядку. Лапка всередині нього подвоюється:

```csharp
string path = @"C:\temp\file.txt";
string poem = @"roses are red
violets are blue";
string quoted = @"She said ""hi""";
```

## Перенесення рядка, незалежне від платформи

У більшості систем вистачає `\n`, але текстові файли Windows використовують `\r\n`. Коли важливо точно дотриматися домовленості платформи, користуйтеся `Environment.NewLine`. `Console.WriteLine` робить це за вас.

## char — це число

`char` містить **кодову одиницю UTF-16**, число від 0 до 65535, яке відображається як символ. Між ними можна перетворювати:

```csharp
char letter = 'A';
int code = letter;                 // 65
char next = (char)(letter + 1);    // 'B'
Console.WriteLine((int)'a');       // 97
Console.WriteLine((char)100);      // d
```

Арифметика над `char` дає `int`, тож потрібне зворотне приведення: `letter + 1` — це `66`, а не `'B'`.

Усередині алфавіту коди літер послідовні, і це дозволяє хитрощі:

```csharp
int position = 'e' - 'a';                  // 4: 'e' — п'ята літера
char third = (char)('a' + 2);              // 'c'
bool isLower = c >= 'a' && c <= 'z';       // перевірка діапазону
```

Великі літери `'A'`–`'Z'` мають коди 65–90, малі `'a'`–`'z'` — 97–122, а цифри `'0'`–`'9'` — 48–57. Тому `'7' - '0'` — це число `7`, а різниця між малою літерою та її великою — 32.

## Допоміжні методи char

```csharp
char.IsLetter('x')         // True
char.IsDigit('7')          // True
char.IsLetterOrDigit('_')  // False
char.IsUpper('Q')          // True
char.IsLower('Q')          // False
char.IsWhiteSpace(' ')     // True (також табуляція й новий рядок)
char.IsPunctuation('!')    // True
char.ToUpper('a')          // 'A'
char.ToLower('Z')          // 'z'
```

Вони розуміють усі алфавіти, а не лише англійські літери: `char.IsLetter('ж')` — це `True`.

## Unicode і консоль

Рядки C# — це Unicode, тож `"Привіт"` та `"こんにちは"` цілком коректні. Чи **відображаються** вони правильно, залежить від консолі та її кодування. Якщо ви бачите `?` або квадратики, з даними все гаразд, а проблема у відображенні.

Кілька деталей:

- `Length` рахує кодові одиниці UTF-16. Більшість символів займає одну. Деякі, як-от багато емодзі, займають **дві**, що називається сурогатною парою, тож `"😀".Length` — це `2`.
- `ToUpper` та `ToLower` залежать від правил мови. Наприклад, у турецькій є особливі `İ` та `ı`. Для порівнянь, що не повинні залежати від мови, користуйтеся `ToUpperInvariant()` та `ToLowerInvariant()`.

## Типове застосування

**Чи складається слово лише з літер?**

```csharp
static bool IsWord(string s)
{
    foreach (char c in s)
    {
        if (!char.IsLetter(c)) return false;
    }
    return s.Length > 0;
}
```

**Символи-цифри в число**

```csharp
int value = 0;
foreach (char c in "472")
{
    value = value * 10 + (c - '0');
}
Console.WriteLine(value);   // 472
```
