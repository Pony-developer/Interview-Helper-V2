Досі ваші дані жили в окремих змінних і масивах, а логіка — в окремих методах. Справжні програми моделюють речі зі світу: книжку, клієнта, банківський рахунок, точку на площині. **Об'єктно-орієнтоване програмування (ООП)** групує **дані** такої речі й **операції** над цими даними в одному місці. Креслення — це **клас**. Річ, побудована за кресленням, — **об'єкт** (також його називають **екземпляром**).

## Перший клас

```csharp
class Book
{
    public string Title;          // поля: дані кожної книжки
    public string Author;
    public int Pages;

    public string Describe()      // метод: що книжка вміє
    {
        return Title + " by " + Author + " (" + Pages + " pages)";
    }
}
```

Клас каже, що кожна `Book` **має** (поля) і що вона вміє **робити** (методи). Це опис. Нічого не існує, доки ви не створите об'єкт:

```csharp
Book book = new Book();           // new створює об'єкт
book.Title = "The Hobbit";
book.Author = "J.R.R. Tolkien";
book.Pages = 310;

Console.WriteLine(book.Describe());   // The Hobbit by J.R.R. Tolkien (310 pages)
```

`new Book()` будує об'єкт, а змінна `book` посилається на нього. Крапка дістається до члена **цього** об'єкта. Інший об'єкт має власні поля:

```csharp
Book other = new Book();
other.Title = "Poems";
Console.WriteLine(book.Title);    // The Hobbit: два об'єкти незалежні
```

## Частини класу

| Член | Що це | Приклад |
| --- | --- | --- |
| **Поле** | змінна, що належить об'єкту | `public int Pages;` |
| **Метод** | код, що працює з даними об'єкта | `public string Describe()` |
| **Конструктор** | код, що виконується під час створення об'єкта | `public Book(...)` |
| **Властивість** | поле з контрольованим доступом (наступна лекція) | `public int Pages { get; set; }` |

## Конструктори

**Конструктор** має назву класу, **не має типу значення, що повертається**, і готує новий об'єкт. Клас, об'єкти якого марні без певних даних, має їх запитувати:

```csharp
class Book
{
    public string Title;
    public string Author;
    public int Pages;

    public Book(string title, string author, int pages)
    {
        Title = title;
        Author = author;
        Pages = pages;
    }

    public string Describe() => Title + " by " + Author + " (" + Pages + " pages)";
}

var book = new Book("The Hobbit", "J.R.R. Tolkien", 310);   // об'єкт, одразу готовий до використання
```

Якщо ви не пишете конструктор, C# надає порожній без параметрів. **Щойно ви пишете власний**, порожній зникає, і `new Book()` стає помилкою: тепер кожну книжку треба створювати з трьома значеннями.

## this

Усередині методу чи конструктора **`this`** — це об'єкт, з яким працює метод. Воно потрібне, коли параметр має ту саму назву, що й поле:

```csharp
public Book(string title)
{
    this.Title = title;     // this.Title — поле, title — параметр
}
```

В інших випадках `this.` можна опустити: самотнє `Title` означає `this.Title`.

## Доступ: public і private

`public` означає «будь-хто може це використовувати». `private` означає «лише код **усередині цього класу**»:

```csharp
class Account
{
    private decimal balance;               // сховано від зовнішнього світу

    public void Deposit(decimal amount)
    {
        if (amount > 0) balance += amount;
    }
    public decimal GetBalance() => balance;
}

var account = new Account();
account.Deposit(100);
// account.balance = 1000000;    // помилка: 'balance' недоступне
```

Це **інкапсуляція**: клас захищає власні дані й пропонує кілька безпечних операцій. Ніхто не може привести об'єкт у безглуздий стан, як-от від'ємний баланс, бо єдиний шлях усередину — через код, який написали ви. Члени без модифікатора за замовчуванням `private`, але пишіть це явно.

## Об'єкти — це посилання

Клас — **посилальний тип**, як і масиви. Змінна містить **посилання** на об'єкт, а не сам об'єкт:

```csharp
Book a = new Book("The Hobbit", "Tolkien", 310);
Book b = a;                 // b посилається на ТОЙ САМИЙ об'єкт
b.Pages = 400;
Console.WriteLine(a.Pages); // 400

Book none = null;           // посилається в нікуди
// none.Describe();         // NullReferenceException
```

Присвоєння копіює **посилання**. Передача об'єкта в метод робить те саме, тож метод може змінити об'єкт, який бачить той, хто викликав. Два окремі виклики `new` створюють два окремі об'єкти, навіть коли їхні поля рівні.

## Класи й структури

**Структура** (struct) схожа на клас, але є **значеннєвим типом**: присвоєння копіює все значення, і в неї немає `null`. Малі, прості, незмінні дані, як-от точка чи колір, — типова структура. Усе інше, і все, що має ідентичність або змінюється з часом, — клас. У цьому модулі ми писатимемо класи.

## Як зробити добрий клас

- **Іменник**, у PascalCase: `Book`, `BankAccount`, `Vector`.
- **Одна ідея** на клас. Клас, що робить усе, — тривожний знак.
- **Ховайте дані** (`private`) і публікуйте **операції** (`public`).
- **Запитуйте потрібне** в конструкторі, щоб жоден об'єкт не був напівготовий.
- **Перевизначайте `ToString()`**, щоб сказати, що це за об'єкт. Тоді `Console.WriteLine(book)` друкує щось корисне:

```csharp
public override string ToString() => Title + " (" + Pages + ")";
```

## Де розташовувати класи

Класи оголошують поруч із `Program` або в окремих файлах, на верхньому рівні файлу. За домовленістю **кожен клас живе у файлі зі своєю назвою** (`Book.cs`). У практичних завданнях цього модуля ви пишете класи над `Program`.
