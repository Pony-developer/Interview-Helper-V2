**Структура** (struct) — це тип, який, як `int` чи `double`, є **типом-значенням**. Її оголошують ключовим словом `struct`, і вона схожа на клас:

```csharp
struct Point
{
    public int X;
    public int Y;

    public int Sum()
    {
        return X + Y;
    }
}

Point p = new Point();
p.X = 3;
p.Y = 4;
Console.WriteLine(p.Sum());        // 7
```

Структура може мати поля, властивості, методи, конструктори та реалізовувати інтерфейси. Чого вона **не** може — успадковуватися від класу (або бути базовим класом для іншої структури). Структура завжди походить від `System.ValueType`, і це вся її родовідна.

## Тип-значення і посилальний тип

Важлива різниця — **що тримає змінна**:

- змінна **класу** тримає **посилання** на об'єкт, який живе в іншому місці (у купі);
- змінна **структури** тримає **самі дані**, всередині себе.

```csharp
class PointClass { public int X; }
struct PointStruct { public int X; }

var c1 = new PointClass();
var c2 = c1;                       // c2 — друге посилання на ТОЙ САМИЙ об'єкт
c2.X = 10;
Console.WriteLine(c1.X);           // 10

var s1 = new PointStruct();
var s2 = s1;                       // s2 — КОПІЯ всіх даних
s2.X = 10;
Console.WriteLine(s1.X);           // 0
```

Присвоєння структури **копіює** її. Тепер у кожної змінної свої незалежні значення.

## Типове значення

У кожної структури є вбудований **конструктор без параметрів**, який встановлює всі поля у типові значення (`0`, `false`, `null`). `new Point()` дає `X = 0, Y = 0`. Навіть без `new` змінна структури має типове значення, тому вона не «порожня», як посилання зі значенням `null`.

## Коли структура — правильний вибір?

Вживайте структуру для малого значення, що поводиться як число: точка, колір, сума грошей, проміжок дат. Наступна лекція показує, як дані передають між методами, а лекція «Зачем нужны структуры» порівнює два види детально.
