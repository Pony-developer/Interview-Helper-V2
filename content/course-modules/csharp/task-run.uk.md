`Task.Run` запускає шматок роботи в потоці з пулу і повертає для нього задачу. Вживайте його для **обчислювальної роботи**: розрахунків, що завантажують процесор.

```csharp
Task<long> factorial = Task.Run(() =>
{
    long result = 1;
    for (int i = 2; i <= 20; i++) result *= i;
    return result;
});

Task<string> text = Task.Run(() => "hello");
Console.WriteLine(factorial.Result);           // 2432902008176640000
Console.WriteLine(text.Result);                // hello
```

## Очікування без блокування: Task.Delay

`Task.Delay(ms)` повертає задачу, що завершиться через заданий час. Це неблокуюча версія `Thread.Sleep`: поки триває затримка, жоден потік не зайнятий.

```csharp
Task pause = Task.Delay(500);
pause.Wait();                                 // блокує тут, лише для демонстрації
```

У реальному коді `Delay` використовують з `await` (наступні лекції), де він дозволяє виконувати іншу роботу під час паузи.

## Продовження

Продовження — шматок коду, що виконується, коли задача завершилась. `ContinueWith` — старіший спосіб його написати:

```csharp
Task.Run(() => 21)
    .ContinueWith(t => Console.WriteLine(t.Result * 2));    // 42
```

Ланцюжки `ContinueWith` важко читати. Лекції про `async/await` показують, як той самий потік читається як звичайний метод.

## Коли вживати Task.Run

- для важкої обчислювальної роботи, що інакше заблокувала б UI або головний потік;
- не для вводу-виводу (файли, мережа): для них уже є асинхронні методи, що не потребують потоку під час очікування.
