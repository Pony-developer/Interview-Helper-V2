Файл містить **байти**, а не символи. **Кодування** — це домовленість про те, як символи перетворюються на байти й назад. Якщо той, хто пише, і той, хто читає, не домовилися, текст перетворюється на нісенітницю, як-от `РџСЂРёРІС–С‚` замість `Привіт`.

## Поширені кодування

| Кодування | Байтів на символ | Примітки |
| --- | --- | --- |
| **ASCII** | 1 | лише 128 символів: англійські літери, цифри, розділові знаки |
| **UTF-8** | від 1 до 4 | охоплює весь Unicode; ASCII-текст не змінюється; стандарт в інтернеті та в сучасних файлах |
| **UTF-16** (`Encoding.Unicode`) | 2 або 4 | внутрішня форма `string` у C#; використовується в Windows |
| **UTF-32** | 4 | просте й марнотратне |
| **Windows-1251**, **KOI8-U** | 1 | старі однобайтові кодові сторінки для кирилиці |

Кількість байтів — не кількість символів. В UTF-8 англійська літера займає один байт, кириличні літери — два, а багато емодзі — чотири:

```csharp
using System.Text;

Console.WriteLine(Encoding.UTF8.GetBytes("A").Length);        // 1
Console.WriteLine(Encoding.UTF8.GetBytes("Привіт").Length);   // 12: шість літер по два байти
Console.WriteLine(Encoding.Unicode.GetBytes("Привіт").Length);// 12: UTF-16, по два байти
Console.WriteLine(Encoding.UTF32.GetBytes("Привіт").Length);  // 24
Console.WriteLine(Encoding.ASCII.GetBytes("Привіт").Length);  // 6: кожну літеру замінено на '?'
```

ASCII не може представити кирилицю, тому підставляє `?`. Текст **втрачено**, а не просто показано неправильно.

## Кодування байтів і декодування

```csharp
byte[] bytes = Encoding.UTF8.GetBytes("Hi, Ann");
string text = Encoding.UTF8.GetString(bytes);        // назад до "Hi, Ann"
Console.WriteLine(bytes[0]);                         // 72: код 'H'
```

Круговий шлях через **те саме** кодування повертає той самий текст. Декодування іншим дає інший, хибний текст.

## Кодування у файлових операціях

Методи `File` і потоки за замовчуванням використовують **UTF-8**, тож у повсякденній роботі нічого робити не потрібно. Щоб бути явним або прочитати старий файл, передайте кодування:

```csharp
File.WriteAllText("a.txt", "Привіт", Encoding.UTF8);
string text = File.ReadAllText("a.txt", Encoding.UTF8);

using (var reader = new StreamReader("old.txt", Encoding.GetEncoding(1251)))
{
    Console.WriteLine(reader.ReadToEnd());
}
```

У сучасному .NET кодові сторінки на кшталт 1251 спершу треба зареєструвати через `Encoding.RegisterProvider(CodePagesEncodingProvider.Instance);` у вашому проєкті. Рекомендований шлях — перетворити старі файли на UTF-8 і тримати UTF-8 скрізь.

## BOM

**Маркер порядку байтів** — це кілька байтів на початку файлу, що оголошують кодування (для UTF-8 це `EF BB BF`). Деякі інструменти його записують, а деяким він не потрібен. `File.ReadAllText` його розпізнає й не включає в текст. Якщо на початку ваших даних з'явилося `ï»¿`, BOM прочитали як символи в хибному кодуванні.

## Закінчення рядків

Файли Windows зазвичай завершують рядки через `\r\n`, а Linux та macOS використовують `\n`. Читання через `ReadLine`, `ReadAllLines` чи `ReadLines` упорається з обома. Ручне розбиття тексту через `Split('\n')` лишає зайвий `\r` наприкінці кожного рядка у файлі Windows, тож надавайте перевагу методам читання рядків або викликайте `Trim()`.

## Читання файлу по рядках

Типове завдання — обробити кожен рядок файлу, наприклад порахувати чи зібрати значення:

```csharp
int total = 0;
foreach (string line in File.ReadAllLines("numbers.txt"))
{
    if (int.TryParse(line.Trim(), out int n))
    {
        total += n;
    }
}
Console.WriteLine(total);
```

Він толерантний до порожніх і хибних рядків: `TryParse` їх просто пропускає. Той самий цикл працює з текстом у пам'яті. Із `StringReader` цей код можна запустити на літералі рядка, без жодного файлу:

```csharp
var reader = new StringReader("10\n20\noops\n30");
string line;
int total = 0;
while ((line = reader.ReadLine()) != null)
{
    int n;
    if (int.TryParse(line, out n)) total += n;
}
Console.WriteLine(total);   // 60
```

## Текстові й двійкові файли

**Текстовий** файл містить символи в певному кодуванні, і його читають текстовими методами. **Двійковий** файл (зображення, архів, програма) — це просто байти. Ніколи не читайте його як текст: перетворення зіпсує його. Використовуйте `File.ReadAllBytes` та `File.WriteAllBytes` або `FileStream`:

```csharp
byte[] data = File.ReadAllBytes("photo.jpg");
Console.WriteLine(data.Length + " bytes");
File.WriteAllBytes("copy.jpg", data);
```

## Добрі звички

- Обирайте UTF-8 для всього нового й кажіть про це явно в коді, що має працювати на інших комп'ютерах.
- Ніколи не будуйте шлях через `+`; використовуйте `Path.Combine`.
- Закривайте файли (`using`) і обробляйте винятки, від яких можна відновитися.
- Тримайте читання файлу в одному невеликому методі, а **обробку** тексту — в іншому, що приймає `string`. Другий тоді можна тестувати без жодного файлу, і саме так працює практичне завдання цього модуля.
