`Main` уже викликає чотири методи, які ще не працюють. Їхні тіла — заглушки, що повертають умовне значення. Реалізуйте їх:

- `Square(x)` повертає `x`, помножене на себе.
- `IsEven(n)` повертає `true` для парних чисел і `false` для непарних.
- `Max3(a, b, c)` повертає найбільше з трьох чисел. Метод також має працювати для від'ємних чисел.
- `Greeting(name)` повертає текст `Hello, <name>!`.

`Main` не змінюйте. Очікуваний вивід:

```text
49
True
False
19
-2
Hello, Ann!
```

Підказка: порівняння на кшталт `n % 2 == 0` уже є значенням `bool`, тож його можна повернути напряму. Для максимуму `Math.Max` бере по два числа за раз.
