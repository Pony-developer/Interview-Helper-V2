`List<T>` — це масив, який сам росте. Елементи читаєте й записуєте за індексом, так само як у масиву:

```csharp
var names = new List<string> { "Ann", "Bob" };
names.Add("Cy");                  // росте автоматично
Console.WriteLine(names[0]);      // Ann: доступ за індексом швидкий, O(1)
names[1] = "Bobby";               // запис за індексом теж працює
Console.WriteLine(names.Count);   // 3
```

Індекс починається з `0` і має бути між `0` і `Count - 1`. Індекс поза цим діапазоном кидає `ArgumentOutOfRangeException`:

```csharp
// names[3] = "Dan";              // виняток: у списку лише 3 елементи
```

## Вартість операцій

| Операція | Вартість | Чому |
|---|---|---|
| `names[i]` | O(1) | елемент лежить на відомому місці масиву |
| `Add(x)` | O(1) у середньому | вільне місце — у кінці |
| `Insert(i, x)` | O(n) | усі елементи після `i` зсуваються на одне місце праворуч |
| `RemoveAt(i)` | O(n) | усі елементи після `i` зсуваються на одне місце ліворуч |

Вставка й видалення в середині повільні, бо решта списку зсувається. Якщо часто додаєте й видаляєте на початку, краще підійде черга чи зв'язний список.

## Індекс і позиція

Під час обходу може знадобитися і індекс, і елемент. Вживайте цикл `for` з індексом або `foreach`, коли потрібні лише елементи:

```csharp
for (int i = 0; i < names.Count; i++)
{
    Console.WriteLine(i + ": " + names[i]);
}
```

Наступні лекції розглядають `Contains`, `Equals` і те, як список вирішує, що два елементи однакові.
