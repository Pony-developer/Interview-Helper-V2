**Подія** (event) — це спосіб, у який об'єкт каже «щось сталося», не знаючи, хто відреагує. Кнопка каже «мене натиснули». Термометр каже «температура змінилася». Кожен, кому це цікаво, підписується на подію й виконує свою роботу.

Це шаблон **публікації й підписки** (publish/subscribe):

- **видавець** (кнопка) піднімає подію;
- **підписники** (будь-яка кількість обробників) — методи, що виконуються, коли подію піднято;
- видавець не знає про підписників, а підписники не знають одне про одного.

```csharp
class Button
{
    public event Action Clicked;          // подія

    public void Click()
    {
        Clicked?.Invoke();                // повідомляємо всіх підписників
    }
}

var button = new Button();
button.Clicked += () => Console.WriteLine("saved");     // підписник
button.Clicked += () => Console.WriteLine("logged");    // ще один
button.Click();                                          // saved, logged
```

## Навіщо не викликати методи напряму?

Кнопка могла б просто викликати `Save()` і `Log()`. Для двох методів це працює, але тоді кнопка мусить знати про кожну функцію, що реагує на клік. З подіями кнопка лишається незмінною, коли додають нову функцію: вона лише підписується.

## Події побудовані на делегатах

Подія оголошується з типом делегата, а попередній модуль показав, що делегат тримає метод. Підписка через `+=` додає метод до списку підписників, а піднесення події викликає кожен метод зі списку по черзі. Наступна лекція пояснює саме ключове слово `event`.
