`Split` розрізає рядок на масив частин, а `string.Join` склеює масив назад у рядок. Разом вони розв'язують велику частину текстових завдань.

Щоб розбити за пробілами й **ігнорувати порожні шматки**, які з'являються, коли підряд кілька пробілів або вони на краях, використайте цю форму:

```csharp
string[] words = text.Split(new[] { ' ' }, StringSplitOptions.RemoveEmptyEntries);
```

Реалізуйте три методи:

- `ReverseWords(text)` повертає слова у зворотному порядку, розділені **одинарними** пробілами, без пробілів на краях: `"the quick brown fox"` стає `"fox brown quick the"`.
- `Acronym(phrase)` повертає перші літери слів великими: `"portable network graphics"` стає `"PNG"`.
- `CountWords(text)` повертає кількість слів, скільки б пробілів їх не розділяло.

Для тексту без слів `ReverseWords` повертає порожній рядок, `Acronym` повертає порожній рядок, а `CountWords` повертає 0.

`Main` друкує результати `ReverseWords` у квадратних дужках, щоб було видно пробіли на краях. `Main` не змінюйте. Очікуваний вивід:

```text
[fox brown quick the]
[world hello]
[]
PNG
ASAP
3
0
```

Підказка: `Array.Reverse(words)` обертає масив на місці, а `string.Join(" ", words)` склеює його одинарними пробілами. Для першої літери — `char.ToUpper(word[0])`.
