У практиці з векторами ви вже бачили оператори. Оператор — це **статичний метод** зі спеціальною назвою, і компілятор викликає його, коли вираз використовує цей оператор:

```csharp
class Money
{
    public decimal Amount { get; }

    public Money(decimal amount) { Amount = amount; }

    public static Money operator +(Money a, Money b)
    {
        return new Money(a.Amount + b.Amount);
    }

    public static bool operator ==(Money a, Money b)
    {
        if (ReferenceEquals(a, b)) return true;
        if (ReferenceEquals(a, null) || ReferenceEquals(b, null)) return false;
        return a.Amount == b.Amount;
    }

    public static bool operator !=(Money a, Money b)
    {
        return !(a == b);
    }
}

var total = new Money(5) + new Money(7);     // викликає operator +
Console.WriteLine(total.Amount);             // 12
Console.WriteLine(new Money(3) == new Money(3));   // True: викликає operator ==
```

## Правила

- Оператор — `public static`, а операнди передаються як параметри. Тип значення, що повертається, довільний: `+` для двох `Money` дає `Money`, `==` дає `bool`.
- Принаймні один параметр має бути типу, в якому оголошено оператор.
- Деякі оператори йдуть **парами**: `==` і `!=`, `<` і `>`, `<=` і `>=`. Якщо визначите один, компілятор вимагатиме другого.
- Нових операторів вигадати не можна, і не можна змінювати кількість операндів. Не можна перевизначити `=`, `.`, `&&`, `||` чи `[]` (індексатори — окрема можливість).

## Оператори не обов'язково перевизначати

`==` для класу нічого не робить, доки ви його не визначили: типово це порівняння посилань. Те саме для `+`. Визначити оператор — це обіцянка, що операція має очікуване людьми значення, тож визначайте його лише тоді, коли це значення ясне.

## Складене присвоєння

Якщо ви визначили `+`, але не `+=`, вираз `a += b` означає `a = a + b`. Писати `+=` самому не потрібно. Наступні лекції розглядають, коли взагалі варто перевантажувати оператори.
