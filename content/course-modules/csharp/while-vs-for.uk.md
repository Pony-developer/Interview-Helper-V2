У C# чотири цикли: `while`, `do-while`, `for` та `foreach`. Будь-який із перших трьох можна записати через будь-який інший, тож вибір стосується **читабельності**: оберіть цикл, що розповідає читачеві, що відбувається.

## Те саме завдання трьома способами

Надрукувати числа від 1 до 5:

```csharp
// for
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine(i);
}

// while
int n = 1;
while (n <= 5)
{
    Console.WriteLine(n);
    n++;
}

// do-while
int k = 1;
do
{
    Console.WriteLine(k);
    k++;
}
while (k <= 5);
```

Вони роблять те саме. У версії з `for` увесь план видно в одному рядку, і саме тому вона тут найкраща.

## Як обирати

| Ситуація | Цикл |
| --- | --- |
| кількість повторень відома (або є довжиною чогось) | `for` |
| повторюємо, доки щось не станеться, і не можемо передбачити, коли | `while` |
| тіло має виконатися **принаймні раз**, незалежно від умови | `do-while` |
| проходимо кожен елемент колекції чи рядка й лише читаємо його | `foreach` |
| повторюємо, доки щось не станеться **посеред** тіла | `while (true)` з `break` |

Приклади:

- «надрукувати перші 10 квадратів»: `for`
- «ділити число навпіл, доки воно не стане меншим за 1»: `while` (кількість кроків залежить від даних)
- «питати користувача, доки відповідь не буде коректною»: `do-while`
- «порахувати пробіли в тексті»: `foreach` або `for`

## Те саме в обох формах

| `for` | `while` |
| --- | --- |
| `for (int i = 0; i < n; i++)` | `int i = 0; while (i < n) { ...; i++; }` |
| лічильник оголошено в заголовку, і після циклу його не видно | змінна живе й після циклу |
| крок важко забути | легко забути `i++`, і цикл стає нескінченним |

## Перевірки еквівалентності

```csharp
for (int i = 0; i < 3; i++)
{
    if (i == 1) continue;
    Console.Write(i);
}
// 02
```

З `continue` цикл `for` **усе одно виконує крок** (`i++`). У формі з `while` треба бути обережним: якщо `i++` стоїть наприкінці тіла, `continue` його пропускає, і цикл застрягає.

```csharp
int i = 0;
while (i < 3)
{
    if (i == 1) continue;   // пропускає i++ нижче: нескінченний цикл!
    Console.Write(i);
    i++;
}
```

Це ще одна причина віддавати перевагу `for`, коли цикл керується лічильником.

## break, continue і return

- `break` виходить із найближчого циклу.
- `continue` пропускає решту тіла й переходить до наступної ітерації (до кроку в `for`, до умови у `while`).
- `return` виходить з усього методу, і це найчистіший вихід із вкладених циклів.

## Практичне правило

1. Можете сказати «для кожного ...»? Використайте `foreach`.
2. Можете сказати «N разів» або «від a до b»? Використайте `for`.
3. Кінець визначає умова? Використайте `while`.
4. Перший прохід має відбутися за будь-яких умов? Використайте `do-while`.
5. Код складний? Винесіть цикл у метод із зрозумілою назвою та `return`.
