Робот стоїть на сітці в точці `(x, y)` і дивиться в один із чотирьох напрямків: `N` (північ), `E` (схід), `S` (південь) або `W` (захід). **Північ** — це напрямок, у якому `y` зростає, а **схід** — той, у якому зростає `x`.

Реалізуйте `Execute(x, y, direction, command)`. Він виконує **одну** команду й повертає новий стан як текст `"x y direction"`:

| Команда | Дія |
| --- | --- |
| `L` | повернути на 90° ліворуч, лишаючись на тій самій клітинці |
| `R` | повернути на 90° праворуч, лишаючись на тій самій клітинці |
| `F` | зробити крок уперед, у напрямку погляду |
| `B` | зробити крок назад, не повертаючись |
| будь-що інше | проігнорувати команду: стан не змінюється |

Приклади:

- `Execute(0, 0, "N", "F")` дає `0 1 N`.
- `Execute(2, 3, "W", "L")` дає `2 3 S`: поворот ліворуч із заходу означає погляд на південь.
- `Execute(1, 1, "W", "B")` дає `2 1 W`: крок назад із позиції, де дивишся на захід, веде на схід.

`Main` не змінюйте. Очікуваний вивід:

```text
0 1 N
0 0 E
3 3 E
2 2 S
2 3 S
0 0 W
2 1 W
1 0 N
1 1 N
```

Підказка: тут природно пасує `switch`. Хороший дизайн розбиває роботу на малі методи, наприклад `TurnLeft` і `TurnRight`, які повертають новий напрямок.
