Кілька класичних прикладів показують, що саме рекурсія робить добре.

## Найбільший спільний дільник

Алгоритм Евкліда за своєю природою рекурсивний: `gcd(a, b) = gcd(b, a mod b)`, а `gcd(a, 0) = a`.

```csharp
static int Gcd(int a, int b)
{
    if (b == 0) return a;          // базовий випадок
    return Gcd(b, a % b);          // числа швидко зменшуються
}
```

`Gcd(48, 18)` викликає `Gcd(18, 12)`, потім `Gcd(12, 6)`, потім `Gcd(6, 0)` і повертає 6. Це **ланцюжок** з O(log n) викликів.

## Степінь діленням навпіл

`x¹⁰ = (x⁵)²`, а `x⁵ = x · (x²)²`. Ділення показника навпіл дає **log p** рівнів замість `p`:

```csharp
static long FastPower(long x, int p)
{
    if (p == 0) return 1;
    long half = FastPower(x, p / 2);          // ОДИН виклик, використаний двічі
    return p % 2 == 0 ? half * half : half * half * x;
}
```

Зверніть увагу, що рекурсивний виклик робиться **один раз**, а його результат використовується повторно. Запис `FastPower(x, p/2) * FastPower(x, p/2)` зробив би два виклики й повернув би повні `p` кроків.

## Двійковий пошук

```csharp
static int Search(int[] sorted, int value, int left, int right)
{
    if (left > right) return -1;                       // порожній діапазон
    int middle = left + (right - left) / 2;
    if (sorted[middle] == value) return middle;
    if (sorted[middle] < value)
        return Search(sorted, value, middle + 1, right);
    return Search(sorted, value, left, middle - 1);
}
```

Діапазон зменшується вдвічі з кожним викликом. Часто рекурсивний **допоміжний** метод із додатковими параметрами (тут `left` та `right`) ховають за простим публічним методом.

## Сума по масиву

```csharp
static int Sum(int[] a, int index)
{
    if (index == a.Length) return 0;
    return a[index] + Sum(a, index + 1);
}
```

Тут «менша задача» — це «решта масиву, починаючи з наступного індексу». Сам масив ніколи не копіюється.

## Ханойські вежі

Три стрижні й `n` дисків різного розміру на першому. Перенесіть їх усі на інший стрижень по одному, ніколи не кладучи більший диск на менший.

Рекурсивна думка: щоб перенести `n` дисків з A на C, (1) перенесіть верхні `n − 1` дисків з A на B, (2) перенесіть найбільший диск з A на C, (3) перенесіть `n − 1` дисків з B на C.

```csharp
static void Hanoi(int n, char from, char to, char via)
{
    if (n == 0) return;
    Hanoi(n - 1, from, via, to);
    Console.WriteLine("Move disk " + n + " from " + from + " to " + to);
    Hanoi(n - 1, via, to, from);
}
```

Для двох дисків `Hanoi(2, 'A', 'C', 'B')` друкує:

```text
Move disk 1 from A to B
Move disk 2 from A to C
Move disk 1 from B to C
```

Кількість ходів — `M(n) = 2 · M(n − 1) + 1`, тобто **2ⁿ − 1**. Для 10 дисків 1 023 ходи, для 64 дисків близько 1.8 · 10¹⁹: жодне залізо ніколи не закінчить. Це рекурсія, яку легко написати й неможливо прискорити, бо сам вивід експоненційний.

## Підрахунок способів

Скількома способами можна піднятися на `n` сходинок, роблячи за раз 1 або 2 кроки? Останній хід був або 1-кроковий (з `n − 1`), або 2-кроковий (з `n − 2`):

```csharp
static long Ways(int n)
{
    if (n <= 2) return n;                    // 1 спосіб для 1 сходинки, 2 для 2
    return Ways(n - 1) + Ways(n - 2);
}
```

Це знову рекурсія Фібоначчі з тими самими повторюваними підзадачами, тож для більших `n` застосуйте мемоїзацію.

## Рекурсія на структурі

Рекурсія природна для **вкладених** даних. Наприклад, рядок зі збалансованими дужками `"(a(b)c)"`: його **глибину** можна перевірити. Простіші приклади — **сума цифр** чи **вкладені списки**. Для вкладених списків «сума всього в списку» — це «сума чисел плюс сума всього в кожному внутрішньому списку». Внутрішній список — менша задача того самого виду. Дерева, теки на диску, документи XML і JSON та вирази в компіляторі обробляють саме так.

## Вибір порядку

Те, куди ви ставите роботу відносно рекурсивного виклику, змінює вивід:

```csharp
static void Down(int n)
{
    if (n == 0) return;
    Console.Write(n + " ");      // ПЕРЕД викликом: 3 2 1
    Down(n - 1);
}

static void Up(int n)
{
    if (n == 0) return;
    Up(n - 1);
    Console.Write(n + " ");      // ПІСЛЯ виклику: 1 2 3
}
```

Перший друкує на шляху **вниз**, а другий — на шляху **назад угору**. Код Ханойських веж вище друкує **посередині**.
