Звідки `Array.Sort` знає, який із двох об'єктів іде першим? Для чисел і рядків це вбудовано. Для **вашого** класу `Array.Sort` не може вгадати: книжки впорядковувати за назвою, за роком чи за ціною? Спробуйте:

```csharp
Book[] books = { new Book("Dune"), new Book("Emma") };
Array.Sort(books);                         // InvalidOperationException: "Failed to compare two elements in the array"
```

Рішення — інтерфейс **`IComparable<T>`**. Клас, що його реалізує, каже: «Я вмію порівнювати себе з іншим об'єктом мого типу». В інтерфейсі один метод:

```csharp
interface IComparable<T>
{
    int CompareTo(T other);
}
```

## Контракт CompareTo

`a.CompareTo(b)` повертає `int`, і важливий лише його **знак**:

- **від'ємне** число, якщо `a` іде **перед** `b`;
- **нуль**, якщо вони **рівні** за порядком;
- **додатне** число, якщо `a` іде **після** `b`.

```csharp
Console.WriteLine(3.CompareTo(5));         // -1: 3 іде перед 5
Console.WriteLine(5.CompareTo(5));         // 0
Console.WriteLine("b".CompareTo("a"));     // 1: "b" іде після "a"
```

Не покладайтеся на точні значення `-1` і `1`: деякі типи повертають інші від'ємні й додатні числа.

## Реалізація

```csharp
class Book : IComparable<Book>
{
    public string Title { get; }
    public int Year { get; }

    public Book(string title, int year)
    {
        Title = title;
        Year = year;
    }

    public int CompareTo(Book other)
    {
        return Year.CompareTo(other.Year);          // спершу давніші книжки
    }
}

Book[] books = { new Book("Emma", 1815), new Book("Dune", 1965), new Book("Ulysses", 1922) };
Array.Sort(books);                                   // тепер це працює
foreach (Book b in books)
{
    Console.WriteLine(b.Year + " " + b.Title);       // 1815 Emma, 1922 Ulysses, 1965 Dune
}
```

Тепер `Array.Sort`, `List<Book>.Sort()` та інші методи, яким потрібен порядок, працюють для `Book`. Це **природний порядок** класу: той, що мається на увазі, коли про інший не кажуть.

## Порівняння за кількома полями

Коли перші поля рівні, порівнюйте наступні. Стандартний спосіб:

```csharp
public int CompareTo(Book other)
{
    int byYear = Year.CompareTo(other.Year);
    if (byYear != 0)
    {
        return byYear;                     // роки різні: відповідь ясна
    }
    return string.CompareOrdinal(Title, other.Title);    // той самий рік: за назвою
}
```

Щоб змінити напрям на зворотний (найновіші першими), поміняйте операнди місцями: `other.Year.CompareTo(Year)`. **Не повертайте `Year - other.Year`**: для великих чисел віднімання може переповнитися й дати хибний знак.

## Рядки: культура чи порядковий

`"a".CompareTo("B")` дотримується правил **поточної культури** (порядок із урахуванням мови, де літери спершу порівнюють без урахування регістру), і результат може залежати від налаштувань комп'ютера. `string.CompareOrdinal(x, y)` просто порівнює **коди символів**: це швидко й однаково скрізь. Усі великі літери стоять перед усіма малими (`"Z"` перед `"a"`). У задачах цього курсу ми вживаємо `CompareOrdinal`, коли порядок виводу має бути точно передбачуваним.

## Правила доброго порівняння

Щоб `Array.Sort` працював правильно, порівняння має бути **узгодженим**:

- `a.CompareTo(a)` дорівнює `0`;
- якщо `a` перед `b`, то `b` після `a` (знаки протилежні);
- якщо `a` перед `b`, а `b` перед `c`, то `a` перед `c`.

Порівняння, що порушує ці правила, може дати дивний порядок або виняток, а помилку важко знайти.

## Неузагальнений IComparable

Є старіший інтерфейс `IComparable` (без `<T>`) із методом `CompareTo(object other)`. Усі числа й рядки реалізують обидва. Він дозволяє писати код, що працює для **будь-чого порівнюваного**, без узагальненого типу: `static IComparable Max(IComparable a, IComparable b)`. Ціна: аргумент приходить як `object`, тож потрібне приведення, а порівняння числа з рядком кидає `ArgumentException`.

## Оператори

Обов'язковий лише `CompareTo`. Якщо ви хочете писати `a < b` для свого класу, треба **додатково** визначити оператори `<`, `>`, `<=` та `>=` (парами), як у задачі «Вектор». Зазвичай досить `CompareTo`.
