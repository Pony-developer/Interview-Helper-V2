Кожне рішення, яке ухвалює програма, зводиться до питання з відповіддю «так» або «ні». У C# цю відповідь представляє тип `bool`, що має рівно два значення: `true` і `false`. Під час друку вони виглядають як `True` та `False`.

```csharp
bool isAdult = true;
bool isEmpty = false;
Console.WriteLine(isAdult);   // True
```

## Оператори порівняння

Порівняння бере два значення й створює `bool`:

| Оператор | Значення | Приклад | Результат |
| --- | --- | --- | --- |
| `==` | дорівнює | `5 == 5` | `True` |
| `!=` | не дорівнює | `5 != 5` | `False` |
| `<` | менше | `3 < 5` | `True` |
| `>` | більше | `3 > 5` | `False` |
| `<=` | менше або дорівнює | `5 <= 5` | `True` |
| `>=` | більше або дорівнює | `4 >= 5` | `False` |

`==` порівнює, `=` присвоює. Їх легко переплутати, і компілятор допомагає лише частково (див. лекцію про типові помилки розгалужень).

Рядки теж можна порівнювати через `==` та `!=`, і порівняння враховує регістр: `"Ann" == "ann"` — це `False`.

## Логічні оператори

| Оператор | Назва | Істинний, коли |
| --- | --- | --- |
| `!a` | не | `a` хибне |
| `a && b` | і | обидва істинні |
| `a \|\| b` | або | принаймні одне істинне |
| `a ^ b` | виключне «або» | рівно одне істинне |

Повна картина для двох значень:

| `a` | `b` | `a && b` | `a \|\| b` | `a ^ b` |
| --- | --- | --- | --- | --- |
| true | true | true | true | false |
| true | false | false | true | true |
| false | true | false | true | true |
| false | false | false | false | false |

## Поєднання умов

```csharp
int age = 20;
bool teen = age >= 13 && age <= 19;
bool outsideWorkingAge = age < 18 || age > 65;
bool notAdult = !(age >= 18);
```

Ланцюжкового порівняння, як у математиці, **немає**. `13 <= age <= 19` не скомпілюється, бо `13 <= age` — це `bool`, а `bool` не можна порівняти з `19`. Напишіть обидва порівняння й поєднайте їх через `&&`.

З тієї самої причини `age == 18 || 21` — помилка: обидві сторони `||` мають бути `bool`. Пишіть `age == 18 || age == 21`.

## Пріоритет

Від найвищого до найнижчого:

1. `!`
2. арифметика: `*`, `/`, `%`, потім `+`, `-`
3. порівняння: `<`, `>`, `<=`, `>=`, потім `==`, `!=`
4. `&&`
5. `||`

Отже, `a || b && c` означає `a || (b && c)`, так само як `2 + 3 * 4` спершу множить. Не змушуйте читача пам'ятати цю таблицю: ставте дужки.

## Закони де Моргана

Коли ви заперечуєте складену умову, `&&` перетворюється на `||` і навпаки, а кожна частина заперечується:

```csharp
!(a && b)   // те саме, що   !a || !b
!(a || b)   // те саме, що   !a && !b
```

Користуйтеся ними для спрощення. «Неправда, що користувач дорослий і має квиток» — це те саме, що «користувач не дорослий або не має квитка»:

```csharp
!(isAdult && hasTicket)  ==  !isAdult || !hasTicket
```

## Гарний стиль для bool

- Називайте змінні та методи типу `bool` як твердження чи питання: `isReady`, `hasDiscount`, `IsEven`.
- Не пишіть `if (isReady == true)`. Змінна вже є `bool`: `if (isReady)`. Так само `if (!isReady)` замість `isReady == false`.
- Повертайте порівняння напряму, а не обгортайте його в `if`:

```csharp
static bool IsEven(int n)
{
    return n % 2 == 0;
}
```

- `bool` не можна перетворити на число чи навпаки: `if (1)` у C# — помилка, на відміну від деяких інших мов.
