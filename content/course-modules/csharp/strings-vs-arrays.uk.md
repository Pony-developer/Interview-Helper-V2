Рядок схожий на масив символів: у нього є `Length`, ви читаєте `s[i]` і можете пройти його циклом. Але ці два типи відрізняються в суттєвих речах.

## Схожі

```csharp
string s = "hello";
char[] a = { 'h', 'e', 'l', 'l', 'o' };

Console.WriteLine(s.Length + " " + a.Length);   // 5 5
Console.WriteLine(s[1] + " " + a[1]);           // e e
```

## Різні

| | `string` | `char[]` |
| --- | --- | --- |
| Чи можна змінити символ? | **ні**, рядок незмінний: `s[0] = 'H'` не компілюється | так: `a[0] = 'H'` |
| `==` порівнює | **текст** | **посилання** (два різні масиви не рівні) |
| Методи | `ToUpper`, `Contains`, `Split`, `Replace`, ... | клас `Array`: `Sort`, `Reverse`, ... |
| Друк | друкує текст | `Console.WriteLine(a)` теж друкує символи, а `a.ToString()` — ні |
| Пам'ять | одне значення | змінний блок, який можна передавати й змінювати |

Щоб «змінити» рядок, створюють новий: `s = "H" + s.Substring(1);`.

## Перетворення між ними

```csharp
char[] letters = "hello".ToCharArray();   // string -> char[]
Array.Reverse(letters);                   // працюємо з масивом: olleh
string back = new string(letters);        // char[] -> string
Console.WriteLine(back);                  // olleh
```

Це класичний спосіб виконати завдання, де потрібно змінювати символи: скопіювати в `char[]`, змінити й зробити рядок з результату.

Сортування літер слова — та сама ідея:

```csharp
char[] chars = "banana".ToCharArray();
Array.Sort(chars);
Console.WriteLine(new string(chars));     // aaabnn
```

Два слова є **анаграмами**, коли сортування їхніх літер дає той самий рядок.

## Рядки та колекції рядків

| У вас є | А потрібне | Використайте |
| --- | --- | --- |
| `string` з роздільниками | частини як масив | `text.Split(...)` |
| масив чи список рядків | один рядок | `string.Join(", ", items)` |
| `string` | його символи як список | `new List<char>(text)` |
| багато дрібних шматків для додавання | один рядок, ефективно | `StringBuilder` |

## Порівняння рядків

`==` та `Equals` порівнюють текст **точно**, символ за символом, тож `"abc" == "ABC"` — це `False`. Для порівнянь без урахування регістру кажіть про це явно:

```csharp
string.Equals("abc", "ABC", StringComparison.OrdinalIgnoreCase);   // True
"abc".ToLower() == "ABC".ToLower();                                 // True, але створює два нові рядки
```

`StringComparison.Ordinal` порівнює коди символів, і воно швидке та передбачуване. Інша родина, як-от `CurrentCulture`, дотримується правил мови: це те, що потрібно для тексту, який показують людям, але результат може залежати від налаштувань комп'ютера.

## Упорядкування рядків

```csharp
Console.WriteLine("apple".CompareTo("banana") < 0);   // True: apple йде першим
Console.WriteLine(string.Compare("b", "a") > 0);      // True
```

`CompareTo` повертає від'ємне число, якщо перший рядок іде першим, нуль, якщо вони рівні, і додатне в іншому разі. `Array.Sort` та `List<string>.Sort` користуються ним. За замовчуванням порядок відповідає алфавіту культури, тож для слів із малих ASCII-літер ви отримуєте очікуваний алфавітний порядок. Для передбачуваного порядку, незалежного від налаштувань, передайте компаратор: `Array.Sort(words, StringComparer.Ordinal)`.

Зважайте на регістр у порядковому (ordinal) порядку: усі великі літери йдуть **перед** малими (`"Zebra"` перед `"apple"`).

## Порожній, null і пробіли

```csharp
string.IsNullOrEmpty(s)        // null або ""
string.IsNullOrWhiteSpace(s)   // null, "" або лише пробіли й табуляції
```

`""` має довжину 0, а `null` не містить рядка взагалі, і `s.Length` кидає `NullReferenceException`. Перевіряйте, перш ніж користуватися рядком, який може бути відсутній.

## Незмінність має ціну

Кожен `+` чи `Replace` створює новий рядок. Для кількох операцій це не має значення. Для тисяч додавань у циклі збирайте шматки в `StringBuilder` (наступна лекція).
