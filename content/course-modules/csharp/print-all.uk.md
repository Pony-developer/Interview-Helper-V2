Клас `Array` — базовий клас **усіх** масивів, тож один метод із параметром типу `Array` може працювати з масивом цілих, рядків, символів і навіть з двовимірним. Напишіть два такі методи:

- `PrintAll(Array items)`: друкує **всі** елементи масиву в один рядок, розділені комою й пробілом, у квадратних дужках: `[1, 2, 3]`. Порожній масив дає `[]`. Елементи двовимірного масиву друкуються рядок за рядком, як один список;
- `CountOf(Array items, object value)`: повертає, скільки елементів масиву **дорівнюють** `value` (вживайте `Equals`). Результат — `int`.

`Main` не змінюйте. Очікуваний вивід:

```text
[1, 2, 3]
[a, b]
[x, y]
[True, False]
[]
[1, 2, 3, 4]
[1.5, 2]
2
2
3
0
```

Рядки по порядку: масив цілих; масив рядків; масив символів; масив булевих значень; порожній масив; двовимірний масив `{ { 1, 2 }, { 3, 4 } }`; масив `double`; а далі чотири результати `CountOf`: кількість `1` у `{ 1, 2, 1, 3 }`, кількість `"a"` у `{ "a", "b", "a" }`, кількість `1` у двовимірному масиві `{ { 1, 1 }, { 2, 1 } }` та кількість `5` у `{ 1, 2, 3 }`.

Підказка: `foreach (object item in items)` обходить **усі** елементи будь-якого масиву в усіх вимірах. `item.ToString()` або конкатенація рядків дає текст елемента (`True` і `False` для булевих значень). Порівнюйте елементи через `item.Equals(value)`: `1.Equals(1)` дорівнює `true`, і `"a".Equals("a")` теж, бо `Equals` — віртуальний метод `object`, який кожен тип перевизначає для себе.
