`GroupBy` розбиває послідовність на **групи** з однаковим ключем. Кожна група знає свій ключ і тримає свої елементи:

```csharp
var words = new[] { "pear", "fig", "apple", "plum", "kiwi" };

var groups = words.GroupBy(w => w.Length);

foreach (IGrouping<int, string> g in groups)
{
    Console.WriteLine(g.Key + ": " + string.Join(", ", g));
}
// 4: pear, plum, kiwi
// 3: fig
// 5: apple
```

Ключ — це те, що повертає лямбда (довжина). Групи йдуть у порядку появи їхнього першого елемента. Кожна група — `IGrouping<TKey, TElement>`: послідовність із властивістю `Key`.

## Підрахунок за групами

```csharp
var counts = words.GroupBy(w => w.Length).Select(g => new { Length = g.Key, Count = g.Count() });
// Довжина 4: 3, довжина 3: 1, довжина 5: 1
```

## Групування за першою літерою

Дуже поширене застосування — групувати елементи за першою літерою, для списку з алфавітними розділами:

```csharp
var byLetter = words.GroupBy(w => w[0]);
foreach (var g in byLetter.OrderBy(g => g.Key))
{
    Console.WriteLine(g.Key + ": " + string.Join(" ", g));
}
```

## Групування — не сортування

Групи з'являються в порядку, в якому їхні ключі вперше **зустріли**, а не за алфавітом. Додайте `OrderBy`, якщо потрібен відсортований порядок, як в останньому прикладі.

## Вартість

`GroupBy` читає всю послідовність і тримає групи в пам'яті. На відміну від `Where`, він не може віддати першу групу, доки не прочитав останній елемент. Тому групування не ліниве так само, як фільтрація.
