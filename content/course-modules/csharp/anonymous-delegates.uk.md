До лямбда-виразів (C# 3) делегат можна було написати на місці, без окремого методу, за допомогою **анонімного методу**:

```csharp
Operation twice = delegate (int a, int b)
{
    return (a + b) * 2;
};

Console.WriteLine(twice(1, 2));     // 6
```

Після ключового слова `delegate` йдуть список параметрів і блок. Назви методу немає, тож код пишеться там, де використовується. Це зручно для короткої дії, що потрібна лише раз.

## Що він уміє, а метод — ні

Анонімний метод **бачить локальні змінні** місця, де його написано, і може їх читати й змінювати:

```csharp
int bonus = 10;
Func<int, int> addBonus = delegate (int x)
{
    return x + bonus;               // використовує локальну змінну bonus
};

Console.WriteLine(addBonus(5));      // 15
```

Це називають **замиканням** (closure), і лекція про замикання пояснює, як це працює.

## Анонімні делегати без параметрів

Якщо делегат не приймає параметрів, дужки можна не писати:

```csharp
Action hello = delegate { Console.WriteLine("hello"); };
hello();
```

## Сьогодні

Анонімні методи — старіші. Новий код використовує лямбда-вирази, які коротші й роблять те саме. `delegate { }` ви ще зустрічатимете у старому коді, тож варто вміти його читати.
