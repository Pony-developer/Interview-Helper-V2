Компілятор вибирає перевантаження за **оголошеними типами** аргументів. У цій задачі ви пишете родину методів `Show`, а `Main` перевіряє, який із них вибрано. **Напишіть ці методи `static string Show(...)`** у класі `Program` (компілятору потрібен **унікальний** список параметрів для кожного):

| Сигнатура | Повертає |
|---|---|
| `Show(int n)` | `int:` + число |
| `Show(double d)` | `double:` + число |
| `Show(string s)` | `string:` + текст |
| `Show(bool b)` | `bool:yes` або `bool:no` |
| `Show(int[] items)` | `ints:` + числа через кому, наприклад `ints:1,2,3` |
| `Show(object o)` | `object:` + `o` як текст |
| `Show(int a, int b)` | `pair:` + `a` + `-` + `b` |
| `Show(string s, int times)` | текст `s`, повторений `times` разів, без нічого між ними |

`Main` не змінюйте. Очікуваний вивід:

```text
int:5
double:5.5
int:120
double:5
string:hi
bool:yes
ints:1,2,3
object:text
pair:1-2
ababab
object:5
string:
```

Рядки по порядку: `int`; `double`; `char` `'x'` (його код 120, і серед методів, що його приймають, найкращий збіг у `int`); `long` `5L` (він перетворюється на `double`, але не на `int`); рядок; `bool`; масив; змінна типу `object`, яка тримає **рядок** (вирішує **оголошений** тип: `object:text`); два числа; рядок із кількістю; число `5`, приведене до `object` (його упаковано, і вибирається перевантаження для `object`); і рядкова змінна, що дорівнює `null` (вибирається `Show(string)`, а текст після `string:` порожній).

Підказка: вам не треба вирішувати, який метод викликається: це робить компілятор, тож просто напишіть усі вісім, кожен із **точними** типами параметрів із таблиці. `string.Join(",", items)` з'єднує числа. Для повторюваного тексту найпростіше вжити цикл із `+=`.
