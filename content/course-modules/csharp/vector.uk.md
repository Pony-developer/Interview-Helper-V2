Вектор на площині — це пара чисел `(x, y)`: напрямок і довжина. Це добрий перший клас із **поведінкою**: він уміє додавати, масштабувати й вимірювати себе.

Напишіть клас `Vector` (над `Program`). Він **незмінний**: створений вектор ніколи не змінюється, а кожна операція повертає **новий** вектор.

- конструктор `Vector(x, y)` зі значеннями `double`;
- властивості лише для читання `X` та `Y`;
- властивість `Length`: `√(x² + y²)`;
- метод `Dot(other)`: **скалярний добуток** `x₁·x₂ + y₁·y₂`, `double`;
- метод `Normalized()`: вектор того самого напрямку довжиною 1 (кожну компоненту поділено на довжину);
- оператори `+` та `-` для двох векторів і `*` для вектора й `double`;
- `ToString()`: текст `(x, y)`, наприклад `(3, 4)`;
- **статична** властивість `Zero` для вектора `(0, 0)`.

Оператори — це `public static Vector operator +(Vector a, Vector b)` і так далі. `Main` не змінюйте. Очікуваний вивід:

```text
(3, 4)
5
(4, 2)
(6, 8)
-5
(0.6, 0.8)
(0, 0)
(2, 6)
```

Рядки по порядку: сам вектор `(3, 4)`; його довжина; сума з `(1, -2)`; добуток на 2; скалярний добуток з `(1, -2)`, що дорівнює `3·1 + 4·(−2) = −5`; нормалізований вектор; статичний нульовий вектор; і різниця з `(1, -2)`.

Підказка: довжину дає `Math.Sqrt`. У `ToString` запис `"(" + X + ", " + Y + ")"` друкує цілі значення `double` без десяткової крапки: `3`, а не `3.0`.
