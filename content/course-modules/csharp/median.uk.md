`Median(numbers)` має повертати **медіану** масиву: середнє значення чисел, коли їх відсортовано. Для парної кількості це середнє двох серединних значень, тож медіана `{ 4, 1, 3, 2 }` дорівнює `2.5`. Для порожнього масиву домовимося, що результат — `0`.

У `Main` сім тестів, і поточна реалізація провалює кілька з них з **двох різних причин**:

1. Вона дає хибну відповідь для деяких вхідних даних.
2. У неї є **побічний ефект**: вона змінює масив, який передав викликач. Тест `input unchanged` це перевіряє.

Знайдіть причини й виправте `Median`, не змінюючи тестів. Не забудьте про порожній масив, який зараз аварійно завершує програму.

Коли все проходить, вивід такий:

```text
ok: odd length
ok: even length
ok: one element
ok: negative numbers
ok: duplicates
ok: input unchanged
ok: empty array
```

Підказка: сортуйте **копію** (`(int[])numbers.Clone()` або `Array.Copy`), а не оригінал. Для парної кількості візьміть два серединні елементи: індекси `n / 2 - 1` та `n / 2`. Діліть на `2.0`, щоб зберегти дробову частину.
