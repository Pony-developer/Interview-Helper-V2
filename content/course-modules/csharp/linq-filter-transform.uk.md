Дві операції складають більшість запитів LINQ: **`Where`** залишає елементи, що проходять перевірку, а **`Select`** перетворює кожен елемент на щось інше.

```csharp
var words = new[] { "pear", "fig", "apple", "kiwi" };

var longWords = words.Where(w => w.Length > 3);         // pear, apple, kiwi
var lengths = words.Select(w => w.Length);              // 4, 3, 5, 4
var labels = words.Select(w => "word: " + w);           // кожне слово отримує префікс
```

`Where` приймає **предикат**: функцію від елемента до `true` або `false`. `Select` приймає **проєкцію**: функцію від елемента до нового значення. Результат `Select` може мати інший тип, ніж вхід: `string` на вході, `int` на виході.

## Індекс

Обидва методи мають перевантаження, які дають також позицію елемента:

```csharp
var numbered = words.Select((w, i) => (i + 1) + ". " + w);   // "1. pear", "2. fig", ...
var skipFirstTwo = words.Where((w, i) => i >= 2);             // apple, kiwi
```

## Ланцюжок

Два методи природно поєднуються. Спершу фільтруйте, потім перетворюйте:

```csharp
var numbers = new[] { 3, 8, 5, 10, 1, 6 };
var result = numbers.Where(n => n > 4).Select(n => n * 10);   // 80, 50, 100, 60
```

Зверніть увагу на порядок: `Where` дивиться на початкові числа, а `Select` множить лише ті, що пройшли. Якщо зробити навпаки, відповідь буде та сама, але роботи може бути більше.

## Синтаксис запитів для того самого

```csharp
var result2 = from n in numbers
              where n > 4
              select n * 10;
```

Обидві версії компілюються в ті самі виклики методів.
