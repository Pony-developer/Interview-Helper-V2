Склеювання рядків через `+` годиться для швидкого повідомлення. Для таблиць, грошей, дат та вирівняних стовпчиків у C# є **рядки формату**.

## Три способи вставити значення в текст

```csharp
string name = "Ann";
double price = 12.5;

Console.WriteLine("Name: " + name + ", price: " + price);       // конкатенація
Console.WriteLine(string.Format("Name: {0}, price: {1}", name, price)); // складений формат
Console.WriteLine($"Name: {name}, price: {price}");              // інтерполяція
```

Усі три друкують `Name: Ann, price: 12.5`. Найзрозуміліша — інтерполяція, із `$` перед лапкою. `{0}` та `{1}` у `string.Format` — це **заповнювачі** для аргументів за номером. `Console.WriteLine` приймає ту саму форму: `Console.WriteLine("{0} is {1}", name, 31);`.

Щоб надрукувати буквальні фігурні дужки, пишіть `{{` та `}}`: `$"{{{name}}}"` друкує `{Ann}`.

## Синтаксис заповнювача

```text
{ індекс [, вирівнювання] [: формат] }
```

В інтерпольованому рядку `індекс` замінюється виразом: `{price,8:F2}`.

## Вирівнювання

Число після коми — це **мінімальна ширина** поля. Додатне означає вирівнювання праворуч, від'ємне — ліворуч:

```csharp
Console.WriteLine($"[{42,6}]");     // [    42]
Console.WriteLine($"[{42,-6}]");    // [42    ]
Console.WriteLine($"[{"ab",5}]");   // [   ab]
```

Значення, довше за ширину, **не** обрізається: воно просто займає більше місця. Той самий ефект дають методи:

```csharp
"ab".PadLeft(5)           // "   ab"
"ab".PadRight(5)          // "ab   "
"7".PadLeft(3, '0')       // "007"
```

Основне застосування — вирівняні стовпчики:

```csharp
Console.WriteLine($"{"Item",-8}{"Qty",4}");
Console.WriteLine($"{"Tea",-8}{2,4}");
Console.WriteLine($"{"Coffee",-8}{10,4}");
```

```text
Item     Qty
Tea        2
Coffee    10
```

## Формати чисел

Після двокрапки йде **специфікатор формату**:

| Формат | Значення | `1234.5678` стає |
| --- | --- | --- |
| `F2` | з фіксованою комою, 2 знаки | `1234.57` |
| `F0` | без дробової частини | `1235` |
| `N2` | з роздільниками розрядів | `1,234.57` |
| `E2` | експоненційний | `1.23E+003` |
| `P1` | відсоток, із частки | `0.256` дає приблизно `25.6%` (пробіли залежать від культури) |
| `D5` | цілі з ведучими нулями | `42` дає `00042` |
| `X` | шістнадцятковий | `255` дає `FF` |
| `0.00` | власний шаблон | `1234.57` |

```csharp
double total = 1234.5678;
Console.WriteLine(total.ToString("F2"));        // 1234.57
Console.WriteLine($"{total:F2}");               // 1234.57
Console.WriteLine($"{total,10:F2}");            // ширина 10, 2 знаки
Console.WriteLine($"{255:X}");                  // FF
Console.WriteLine($"{42:D5}");                  // 00042
```

Округлення в `F2` дотримується звичайного правила для показаного числа (половина від нуля), на відміну від `Math.Round`, що йде до парного сусіда.

## Культура

Десятковий роздільник, роздільник розрядів і спосіб запису дат залежать від **культури**, регіональних налаштувань. На комп'ютері з українськими налаштуваннями `12.5` друкується як `12,5`. Для виводу, що має виглядати однаково скрізь, як-от файл, журнал чи тест, передайте інваріантну культуру:

```csharp
using System.Globalization;

string text = total.ToString("F2", CultureInfo.InvariantCulture);          // завжди 1234.57
string line = string.Format(CultureInfo.InvariantCulture, "{0:F2}", total);
```

Для тексту, який показують людині, правильна власна культура користувача, і саме так працює типова поведінка.

## Дати

```csharp
var date = new DateTime(2026, 11, 23, 14, 5, 9);
Console.WriteLine(date.ToString("yyyy-MM-dd"));        // 2026-11-23
Console.WriteLine(date.ToString("HH:mm:ss"));          // 14:05:09
Console.WriteLine($"{date:dd.MM.yyyy}");               // 23.11.2026
```

`MM` — місяць, а `mm` — хвилини: класична плутанина. `HH` — 24-годинний годинник.

## Усе разом: текстова таблиця

```csharp
string[] names = { "Tea", "Coffee" };
double[] prices = { 3.5, 12.25 };

for (int i = 0; i < names.Length; i++)
{
    Console.WriteLine(string.Format(CultureInfo.InvariantCulture, "{0,-8}{1,8:F2}", names[i], prices[i]));
}
```

```text
Tea          3.50
Coffee      12.25
```

## Що обрати

- Швидке повідомлення: інтерполяція.
- **Таблиця** зі стовпчиками: вирівнювання `{x,8}` або `PadLeft` і `PadRight`.
- **Гроші та вимірювання**: `F2` чи `N2`, разом з інваріантною культурою, якщо формат має бути точним.
- Шаблон, що надходить ззовні, як-от налаштування чи переклад: `string.Format`, бо заповнювачі в самому тексті можна переставляти.
