Клас `System.Array` має готові статичні методи для поширених завдань, тож писати цикли самому не обов'язково. Вони містяться в `System`, який ви вже підключаєте.

```csharp
int[] a = { 5, 2, 9, 1 };
```

## Sort і Reverse

```csharp
Array.Sort(a);      // 1 2 5 9    сам масив сортується на місці
Array.Reverse(a);   // 9 5 2 1    обертається на місці
```

Обидва змінюють масив і нічого не повертають. Рядки сортуються за алфавітом, а числа — за значенням.

## IndexOf

```csharp
int where = Array.IndexOf(a, 2);   // 2: позиція першої двійки
int none = Array.IndexOf(a, 7);    // -1: не знайдено
```

`IndexOf` — стандартний спосіб спитати «чи містить масив це значення?»: відповідь — `Array.IndexOf(a, value) >= 0`.

## BinarySearch

Для **відсортованого** масиву він набагато швидший за перегляд. Повертає індекс або від'ємне число, коли значення немає:

```csharp
int[] sorted = { 1, 2, 5, 9 };
Console.WriteLine(Array.BinarySearch(sorted, 5));   // 2
Console.WriteLine(Array.BinarySearch(sorted, 4) < 0);   // True: не знайдено
```

На невідсортованому масиві результат безглуздий.

## Копіювання

```csharp
int[] copy = new int[a.Length];
Array.Copy(a, copy, a.Length);        // copy.Length елементів з початку

int[] clone = (int[])a.Clone();       // новий масив з тими самими елементами
```

`Array.Copy` також може копіювати частину: `Array.Copy(source, sourceIndex, target, targetIndex, count)`. Цільовий масив має бути достатньо великим.

## Clear

```csharp
Array.Clear(a, 0, a.Length);          // кожен елемент стає значенням за замовчуванням (0)
```

## Resize

Масив не може рости, але `Array.Resize` створює **новий** масив потрібного розміру, копіює в нього елементи й змушує вашу змінну посилатися на нього:

```csharp
int[] data = { 1, 2, 3 };
Array.Resize(ref data, 5);   // 1 2 3 0 0
Array.Resize(ref data, 2);   // 1 2   (решту відрізано)
```

Ключове слово `ref` дозволяє методу змінити саму змінну. Інше посилання на старий масив цієї зміни не бачить. Якщо ваші дані постійно ростуть, використовуйте `List<T>`, про який ітиметься в наступному модулі.

## Розміри та виміри

```csharp
Console.WriteLine(a.Length);        // загальна кількість елементів
Console.WriteLine(a.Rank);          // 1: кількість вимірів
Console.WriteLine(a.GetLength(0));  // довжина першого виміру
```

Для багатовимірних масивів, про які далі, `Length` — це кількість усіх елементів, а `GetLength(d)` — розмір одного виміру.

## Коли писати власний цикл

Бібліотечні методи покривають звичайні завдання. Пишіть цикл самі, коли правило специфічне для вашої задачі: підрахунок значень у діапазоні, пошук шаблону, знаходження першого елемента, що задовольняє умову. Саме це ви робитимете в практичних завданнях.
