The variables `a` and `b` hold `3` and `8`. Swap them so that `a` ends up as `8` and `b` as `3`.

Do not type the numbers again: the program must work for any starting values. Use a third variable to keep one of the values safe for a moment.

Expected output:

```text
a = 8
b = 3
```

Hint: if you write `a = b;` first, the old value of `a` is gone for good.
