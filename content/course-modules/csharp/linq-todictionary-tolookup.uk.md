`ToDictionary` і `ToLookup` перетворюють послідовність на швидку таблицю пошуку. Обидва потребують ключа для кожного елемента; вони відрізняються тим, що відбувається, коли ключ зустрічається двічі.

```csharp
var words = new[] { "pear", "fig", "apple" };

Dictionary<string, int> lengths = words.ToDictionary(w => w, w => w.Length);
Console.WriteLine(lengths["apple"]);          // 5
```

Перша лямбда дає ключ, друга — значення. Результат — `Dictionary`, тож пошук швидкий, як пояснювала попередня лекція про словники.

## Повторювані ключі

Словник не може містити один ключ двічі:

```csharp
var names = new[] { "Ann", "Bob", "Ann" };
// names.ToDictionary(n => n, n => 1);       // ArgumentException: an item with the same key has already been added
```

Спершу приберіть дублікати (`Distinct()`), або використайте `ToLookup`.

## ToLookup: один ключ, багато значень

`ToLookup` будує структуру, схожу на словник, чиї значення — **групи**. Кілька елементів можуть мати один ключ, а відсутній ключ дає порожню групу, а не виняток:

```csharp
var byLength = words.ToLookup(w => w.Length);
foreach (string w in byLength[4])            // pear, і більше ніщо не має довжину 4
{
    Console.WriteLine(w);
}
Console.WriteLine(byLength[9].Count());       // 0: відсутній ключ дає порожню послідовність
```

Відмінність від `GroupBy` у тому, що `Lookup` будується **одразу** і його можна багато разів шукати за ключем, тоді як `GroupBy` — послідовність, яку читають один раз.

## Вибір

| Потреба | Використовувати |
|---|---|
| Одне значення на ключ, ключі унікальні | `ToDictionary` |
| Кілька значень на ключ, пошук за ключем | `ToLookup` |
| Групи, що читаються один раз, як послідовність | `GroupBy` |

## Ключі мають бути добрими

Обидва методи використовують `GetHashCode` і `Equals` ключа (лекції про хешування й `Equals` пояснюють чому). Якщо ключ — клас без коректної рівності, пошук не знайде очікуваного.
