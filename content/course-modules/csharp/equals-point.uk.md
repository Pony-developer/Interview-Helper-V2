Зробіть клас `Point` **об'єктом-значенням**: дві точки з однаковими координатами **рівні**, де б їх не створили. Зараз `Point` порівнюється за посиланням, тож `new Point(1, 2) == new Point(1, 2)` дорівнює `false`, а `HashSet` тримає дублікати.

Додайте до `Point` (залиште його дві властивості й конструктор):

- `Equals(object)`: `true` для `Point` з тими самими `X` та `Y`; `false` для `null` і для об'єкта **іншого типу** (ніколи не кидайте виняток);
- `GetHashCode()`: **узгоджений** з `Equals`: рівні точки дають рівні хеш-коди (наприклад, `X * 31 + Y` у блоці `unchecked`);
- оператори `==` і `!=`, що порівнюють значення й **працюють із `null`** (`p == null` не повинно падати й не повинно рекурсувати);
- `ToString()`: `(x, y)`.

`Main` не змінюйте. Очікуваний вивід:

```text
True
True
False
True
False
False
True
2
True
1 second
1
(1, 2)
True
True
False
```

Рядки по порядку: `a == b` для двох рівних точок; `a.Equals(b)`; `ReferenceEquals(a, b)` (усе ще `False`: це різні об'єкти); `a != c` для різних точок; `a.Equals(null)`; `a.Equals("(1, 2)")` (рядок, а не точка); рівні хеш-коди; кількість елементів у `HashSet` після додавання `a`, `b` (рівної) та `c`; чи містить множина **нову** точку `(2, 1)`; словник, де ключ `b` **замінив** значення ключа `a` (`1 second`); позиція нової `(1, 2)` у списку; точка як текст; `a.Equals(boxed)`, де точку збережено у змінній типу `object` (поліморфний виклик усе ще працює); змінна, що дорівнює `null`, порівнювана з `null` (`True`); і точка, порівнювана з `null` (`False`).

Підказка: в `Equals` вживайте `obj as Point` і перевіряйте результат через **`ReferenceEquals(other, null)`**. Не пишіть `other == null` усередині коду `==` чи `Equals`: це знову викликало б ваш власний оператор. Оператор `==` має вигляд `public static bool operator ==(Point a, Point b)`, а компілятор вимагає `!=` разом із ним.
