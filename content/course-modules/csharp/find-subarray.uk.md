Знайдіть один масив усередині іншого.

Реалізуйте `IndexOfSub(numbers, part)`. Він повертає індекс у `numbers`, з якого починається **перше** входження всієї послідовності `part`, так що елементи `numbers[i]`, `numbers[i + 1]`, ... по одному дорівнюють `part[0]`, `part[1]`, ... Якщо такого місця немає, повертає `-1`.

Особливі випадки:

- **порожній** `part` знаходиться за індексом `0`;
- `part`, довший за `numbers`, знайти не можна: `-1`.

Для `numbers = { 1, 2, 3, 2, 3, 4, 2, 3, 4, 5 }`:

- `{ 2, 3, 4 }` починається за індексом 3, а не 1, бо за індексом 1 послідовність читається як `2, 3, 2`;
- `{ 4, 5 }` починається за індексом 8;
- `{ 5, 6 }` не трапляється;
- `{ 3, 2, 3 }` починається за індексом 2.

`Main` не змінюйте. Очікуваний вивід:

```text
3
8
-1
0
0
-1
2
```

Підказка: початкова позиція пробігає `0 .. numbers.Length - part.Length`. Для кожного початку перевіряйте елементи `part` внутрішнім циклом і відмовляйтеся від позиції, щойно один елемент відрізняється.
