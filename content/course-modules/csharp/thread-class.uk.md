Клас `System.Threading.Thread` створює потік і керує ним. Ви даєте йому метод для виконання і запускаєте його:

```csharp
using System.Threading;

static void Greet()
{
    Console.WriteLine("hello from a thread");
}

var thread = new Thread(Greet);     // група методів стає делегатом ThreadStart
thread.Start();                     // метод тепер виконується в новому потоці
thread.Join();                      // головний потік чекає тут, доки Greet не завершиться
Console.WriteLine("done");
```

## Найважливіші методи

- `Start()` починає виконання потоку.
- `Join()` блокує викликаючий потік, доки інший потік не завершиться. Без нього програма може завершитися раніше, ніж потік виконає свою роботу.
- `Sleep(ms)` на деякий час призупиняє поточний потік. Він зручний для демонстрацій, але рідко потрібен у робочому коді.

## Передача даних

Потік приймає метод без параметрів або з одним параметром `object`. Для інших даних вживайте замикання або малий клас:

```csharp
int n = 5;
var worker = new Thread(() => Console.WriteLine(n * 2));   // лямбда захоплює n
worker.Start();
worker.Join();
```

## Результат потоку

Потік не може повернути значення напряму. Збережіть результат у змінній, яку потік записує, а головний потік читає після `Join()`. Лекції про блокування показують, як безпечно ділити таку змінну.

## Потоки не безкоштовні

Кожен потік має власний стек, що займає пам'ять, а перемикання між потоками займає час. Створювати потік для кожної дрібної роботи марнотратно. Пізніші лекції про `Parallel` і задачі показують кращі способи використати багато дрібних робіт.
