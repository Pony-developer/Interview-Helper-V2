Кожен член класу є або **членом екземпляра**, або **статичним** членом. Різниця вирішує, **кому він належить**.

## Члени екземпляра належать об'єкту

Кожен об'єкт має **власні** поля екземпляра, а методи екземпляра працюють з даними **цього** об'єкта:

```csharp
class Counter
{
    public int Value;                    // поле екземпляра: окреме в кожного Counter

    public void Increment()              // метод екземпляра: працює з "this" лічильником
    {
        Value++;
    }
}

var a = new Counter();
var b = new Counter();
a.Increment();
a.Increment();
b.Increment();
Console.WriteLine(a.Value + " " + b.Value);    // 2 1: окремі дані
```

Щоб ними користуватися, потрібен **об'єкт**: `a.Increment()`.

## Статичні члени належать класу

**Статичний** член існує **один раз** для всього класу, чи є об'єкти, чи ні. Ним користуються через **назву класу**:

```csharp
class Counter
{
    public int Value;
    public static int Created;           // статичне поле: ОДНЕ для всього класу

    public Counter()
    {
        Created++;                       // кожен новий лічильник збільшує спільне число
    }
}

var a = new Counter();
var b = new Counter();
Console.WriteLine(Counter.Created);      // 2: читаємо через назву класу
```

Статичні члени вам уже знайомі: `Math.Sqrt`, `Console.WriteLine`, `int.Parse`, `string.Join`, `Array.Sort`. Їх викликають через клас, бо вони не працюють з жодним конкретним об'єктом.

## Порівняння

| | Екземпляра | Статичний |
| --- | --- | --- |
| Належить | кожному об'єкту | самому класу |
| Для використання потрібен об'єкт | так | ні |
| Доступ через | `object.Member` | `ClassName.Member` |
| Кількість копій | одна на об'єкт | рівно одна |
| Може використовувати `this` | так | **ні** |
| Живе | доки живе об'єкт | протягом усієї програми |

## Хто що може використовувати

- Метод **екземпляра** може використовувати і члени екземпляра, і статичні.
- **Статичний** метод **не має `this`**, тож не може напряму використовувати члени екземпляра: немає об'єкта, у якого спитати. Йому треба передати об'єкт параметром.

```csharp
class Counter
{
    public int Value;
    public static int Created;

    public void Show() => Console.WriteLine(Value + " of " + Created);    // обидва: нормально

    public static void Reset()
    {
        Created = 0;                  // нормально: статичний член
        // Value = 0;                 // помилка: Value якого лічильника?
    }
}
```

## Вибір: статичний чи екземпляра?

Спитайте: **це належить одному конкретному об'єкту чи ідеї загалом?**

- Назва книжки: **екземпляра**. Різні книжки мають різні назви.
- Кількість створених книжок: **статичне**. Це одне число на всіх.
- Метод, що обчислює щось зі своїх даних (`book.ReadingDays(40)`): **екземпляра**.
- Метод, що не торкається даних жодного об'єкта (`Math.Max(a, b)`, `int.Parse(text)`): **статичний**.
- **Фабрика**, що створює об'єкти: часто статична (`Point.Origin`, `Color.FromRgb(...)`).

Добре правило: якщо метод мусить брати об'єкт власного класу **першим параметром**, він, імовірно, хоче бути методом екземпляра.

## Статичні константи

Значення, що **ніколи не змінюється** й однакове для всіх, — це **константа**:

```csharp
class Circle
{
    public const double Pi = 3.14159;                      // константа часу компіляції, неявно статична
    public static readonly Circle Unit = new Circle(1);    // статичне значення, створене під час виконання

    public double Radius;
    public Circle(double radius) { Radius = radius; }
    public double Area => Pi * Radius * Radius;
}

Console.WriteLine(Circle.Pi);
```

`const` — для значень, відомих під час компіляції (числа, рядки). `static readonly` — для значень, які треба створити під час запуску програми, як-от об'єкти.

## Статичні конструктори

Клас може мати **один** статичний конструктор. Він виконується автоматично, один раз, перед першим використанням класу й налаштовує статичні дані:

```csharp
class Settings
{
    public static readonly string[] Names;
    static Settings()
    {
        Names = new[] { "low", "medium", "high" };
    }
}
```

## Небезпеки статичного стану

**Змінюване статичне поле** — це **глобальна змінна**. Будь-хто може змінити її звідки завгодно, і вона живе стільки, скільки програма:

- код, що її використовує, важко **зрозуміти**: результат методу залежить від того, що раніше зробив якийсь інший код;
- її важко **тестувати**: один тест лишає слід для наступного;
- вона **небезпечна**, коли її одночасно використовує кілька потоків.

Статичні **константи** та значення **лише для читання** — нормально. Статичний **змінюваний** стан має бути рідкістю й добре прихованим. Лекція про статичні класи до цього повернеться.

## Статичне та пам'ять

Дані екземпляра створюються з кожним `new` і можуть бути зібрані, коли на об'єкт ніхто не посилається. Статичні дані лишаються до завершення програми. Статична колекція, що лише росте («кеш» без ліміту), — це **витік пам'яті**.

## Підсумок

- **Екземпляра**: один на об'єкт, потрібен об'єкт, може використовувати `this`.
- **Статичний**: один на клас, використовується через назву класу, не має `this`.
- Обирайте, питаючи, кому член **належить**.
- Статичне використовуйте для констант і функцій, яким не потрібні дані жодного об'єкта. Уникайте спільного змінюваного статичного стану.
