Двійковий пошук має природну рекурсивну форму: подивіться на середину, а потім шукайте в **лівій** або **правій** половині тим самим методом. Рекурсія глибока лише на `log₂ n` рівнів, тож вона безпечна навіть для мільйона елементів.

Реалізуйте `Search(sorted, value)`. Він повертає індекс `value` у відсортованому масиві `sorted` або `-1`, якщо значення немає. Усі значення в масиві **різні**. Напишіть **рекурсивний** допоміжний метод із діапазоном `left` і `right` як додатковими параметрами й викличте його з `Search` для всього масиву.

Базовий випадок — **порожній діапазон** (`left > right`): значення там немає.

`Main` перевіряє малий масив, порожній масив і масив із **мільйона** елементів: парні числа `0, 2, 4, ..., 1 999 998`. Рекурсія, що робить один виклик на елемент, там переповнила б стек, тож ділення навпіл суттєве. `Main` не змінюйте. Очікуваний вивід:

```text
7 -> 3
1 -> 0
13 -> 6
4 -> -1
20 -> -1
0 -> -1
-1
999999
-1
0
```

Перші шість рядків — пошуки в `{ 1, 3, 5, 7, 9, 11, 13 }`. Рядок `-1` — пошук у порожньому масиві. Останні три — пошуки `1 999 998`, `1 999 999` та `0` у великому масиві: останній елемент, непарне число, якого немає, і перший елемент.

Підказка: `middle = left + (right − left) / 2`. Якщо середній елемент менший за значення, шукайте в `middle + 1 .. right`. Якщо більший — у `left .. middle − 1`.
