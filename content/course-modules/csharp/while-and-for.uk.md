Цикли повторюють блок коду, доки виконується умова.

## while

```csharp
var n = 1;
while (n < 100)
    n *= 2;
Console.WriteLine(n); // 128
```

Умова перевіряється **перед** кожним проходом, тож тіло може не виконатися жодного разу. `do { ... } while (condition);` перевіряє після, тому завжди виконується хоча б раз.

## for

Коли відомо, скільки разів повторювати, `for` тримає лічильник в одному місці:

```csharp
for (var i = 0; i < 5; i++)
    Console.Write(i + " ");   // 0 1 2 3 4
```

Три частини — це початок, умова та крок. Рахувати від 0 і зупинятися **перед** довжиною (`i < 5`) — звичка C#, і вона збігається з індексами масивів.

## break і continue

```csharp
for (var i = 1; i <= 10; i++)
{
    if (i % 2 == 0) continue; // одразу до наступного проходу
    if (i > 7) break;         // вийти з циклу
    Console.Write(i + " ");   // 1 3 5 7
}
```

## Типові помилки

- **Помилка на одиницю**: `i <= 5` замість `i < 5` дає один зайвий прохід.
- **Нескінченний цикл**: умова ніколи не стає хибною, бо змінна не оновлюється.
- **Зміна лічильника в тілі**: такий цикл важко зрозуміти. Якщо крок змінюється, краще взяти `while`.
