**Обернений індекс** відповідає на питання «у яких документах трапляється це слово?» Він зіставляє кожне слово зі списком номерів документів, де воно є. Так працюють пошукові системи.

Напишіть метод `BuildIndex(string[] docs)`, що повертає `ILookup<string, int>`:

- номери документів починаються з `1`;
- кожне слово документа записується для нього один раз, навіть якщо воно трапляється в ньому кілька разів;
- слово, якого немає в жодному документі, дає порожню послідовність при пошуку.

Слова розділені одинарними пробілами. `Main` не змінюйте. Очікуваний вивід:

```text
1 3
1 2
3
0
```

Рядки по порядку: документи зі словом `cat` (документи `1` і `3`); документи зі словом `dog` (`1` і `2`); документи зі словом `fish` (лише `3`); і кількість документів зі словом `zebra`, яка дорівнює `0`.

Підказка: `docs.SelectMany((text, i) => text.Split(' ').Distinct().Select(w => new KeyValuePair<string, int>(w, i + 1)))` будує послідовність пар (слово, документ). Потім `ToLookup(p => p.Key, p => p.Value)` перетворює її на індекс.
