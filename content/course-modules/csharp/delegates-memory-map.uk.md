Делегат — це **об'єкт**. Як будь-який об'єкт, він живе в купі, а змінна типу делегата тримає посилання на нього. Об'єкт делегата зберігає дві речі: метод, який треба викликати, і об'єкт, якому належить метод (його ціль, target). Для статичного методу ціль — `null`.

```csharp
delegate int Operation(int a, int b);
static int Add(int a, int b) { return a + b; }

Operation f = Add;     // f — посилання
Operation g = f;       // g — друге посилання на той самий об'єкт делегата
g = Multiply;          // тепер g посилається на НОВИЙ об'єкт делегата; f не змінився
```

## Картина

```text
стек                        купа
----                        ----
f  -------------------->  [делегат: метод = Add,      ціль = null]
g  -------------------->  [делегат: метод = Multiply, ціль = null]
```

Присвоєння копіює посилання, а не делегат. Зміна `g` не змінює `f`.

## Методи екземплярів у купі

```text
counter  ----------------->  [об'єкт Counter: total = 5]
f        ----------------->  [делегат: метод = Counter.Add, ціль = counter]
```

Делегат утримує об'єкт лічильника живим, навіть коли змінна `counter` виходить з області видимості. Це важливо для замикань у пізніших лекціях.

## Делегати незмінні

Поєднання чи видалення методів (наступна частина модуля) створює **новий** об'єкт делегата. Старий не змінюється. Тому `a + b` для делегатів повертає нове значення.

## Порожній делегат

Змінна типу делегата дорівнює `null`, доки її не присвоєно. Виклик `null`-делегата кидає `NullReferenceException`, тож перевіряйте перед викликом:

```csharp
Operation h = null;
if (h != null)
{
    Console.WriteLine(h(1, 2));
}
```
