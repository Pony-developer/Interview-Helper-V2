Коли структуру передають у метод, метод отримує **копію**. Зміни всередині методу не доходять до змінної викликаючого.

```csharp
struct Point
{
    public int X;
}

static void Move(Point p)
{
    p.X = 100;                 // змінює лише копію
}

Point a = new Point { X = 1 };
Move(a);
Console.WriteLine(a.X);        // 1: структура викликаючого не змінилася
```

Це те саме правило, що й для `int`: передача `int` у метод не може змінити число викликаючого. Об'єкт класу поводився б інакше, бо копіюється лише посилання:

```csharp
static void MoveObject(PointClass p)
{
    p.X = 100;                 // змінює спільний об'єкт
}
```

## Повернення структури

Метод може повертати структуру. Викликаючий отримує нову копію — це звичайний спосіб отримати змінене значення, не змінюючи оригінал:

```csharp
static Point Shifted(Point p, int dx)
{
    return new Point { X = p.X + dx };
}

Point a = new Point { X = 1 };
Point b = Shifted(a, 5);
Console.WriteLine(a.X + " " + b.X);     // 1 6
```

## Ціна копіювання

Копія малої структури дешева. Велика структура (багато полів) копіюється при кожному виклику, а це коштує часу й пам'яті. Для великих даних або коли метод мусить змінити змінну викликаючого, передавайте її **за посиланням** через `ref` — тема наступної лекції.
