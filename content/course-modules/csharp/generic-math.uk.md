Роками в C# не можна було написати простий метод: узагальнений `Sum`, що працює для `int`, `double` і `decimal`.

```csharp
static T Sum<T>(T[] items)
{
    T total = 0;              // помилка: 0 — це int, а не T
    foreach (T x in items)
        total = total + x;    // помилка: для T немає оператора +
    return total;
}
```

Обмеження могли вимагати лише **екземплярних** членів, а `0` і `+` — **статичні**: вони належать типу, а не значенню. Обхідні шляхи: копія методу для кожного типу, `dynamic` (повільно) або дерева `Expression` (складно).

## Статичні абстрактні члени (C# 11, .NET 7)

Тепер інтерфейс може вимагати **статичний** член:

```csharp
interface IHasZero<TSelf> where TSelf : IHasZero<TSelf>
{
    static abstract TSelf Zero { get; }
    static abstract TSelf operator +(TSelf a, TSelf b);
}
```

`TSelf` — це сам тип, що реалізує інтерфейс («самопосилальне» узагальнення). Кожен такий тип мусить надати власні `Zero` і `+`. Усередині узагальненого методу їх викликають через параметр типу: `T.Zero`.

## `INumber<T>`

.NET 7 уже реалізує такі інтерфейси для всіх вбудованих числових типів у `System.Numerics`: `IAdditionOperators`, `IComparisonOperators`, `INumber<T>` та інші. Метод стає таким:

```csharp
using System.Numerics;

static T Sum<T>(T[] items) where T : INumber<T>
{
    T total = T.Zero;
    foreach (T x in items)
        total += x;
    return total;
}

Sum(new[] { 1, 2, 3 });          // 6
Sum(new[] { 1.5, 2.5 });         // 4.0
Sum(new[] { 0.1m, 0.2m });       // 0.3
```

JIT і далі компілює окрему версію для кожного значущого типу, тож узагальнений `Sum` такий самий швидкий, як написаний вручну.

## Де це трапляється

- Бібліотеки для чисел, векторів, статистики й розбору (`IParsable<T>` дає статичний `T.Parse`).
- У прикладному коді — рідко: звичайного інтерфейсу з екземплярними методами зазвичай досить.

Практичні завдання цього курсу виконуються на C# 7, де цієї можливості немає. Спробуйте її в локальному проєкті на .NET 8 або новішому.

## Правило

Коли узагальненому алгоритму потрібна **статична** операція (константа, оператор, фабричний метод на кшталт `Parse`), використовуйте статичний абстрактний член інтерфейсу. Для всього іншого простіші звичайні екземплярні члени.
