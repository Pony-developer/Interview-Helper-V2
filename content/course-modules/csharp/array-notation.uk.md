Той самий масив можна записати кількома способами. Вони відрізняються довжиною та тим, де їх дозволено.

## Створення масиву заданого розміру

```csharp
int[] scores = new int[5];        // п'ять нулів
string[] names = new string[3];   // три null
bool[] flags = new bool[2];       // два false
```

Новий масив заповнюється **значенням за замовчуванням** свого типу: `0` для чисел, `false` для `bool`, `'\0'` для `char` та `null` для рядків та інших посилальних типів. Розмір може бути змінною: `new int[n]`. Від'ємний розмір кидає виняток.

## Створення масиву зі значеннями

Повна форма двічі називає тип:

```csharp
int[] a = new int[] { 1, 2, 3 };
int[] b = new int[3] { 1, 2, 3 };   // розмір необов'язковий; якщо вказано, має збігатися
```

**Коротка форма** пропускає `new`:

```csharp
int[] c = { 1, 2, 3 };
string[] names = { "Ann", "Bo", "Cy" };
```

Коротка форма дозволена **лише в оголошенні** змінної. Її не можна застосувати для подальшого присвоєння чи як аргумент:

```csharp
int[] c;
c = { 1, 2, 3 };          // помилка
Sum({ 1, 2, 3 });         // помилка
```

У таких місцях потрібна форма з `new`:

```csharp
c = new int[] { 1, 2, 3 };
Sum(new int[] { 1, 2, 3 });
```

## Нехай тип знайде компілятор

Якщо елементи показують свій тип, його можна пропустити й після `new`, а також використати `var`:

```csharp
var d = new[] { 1, 2, 3 };         // int[]
var e = new[] { "a", "b" };        // string[]
var f = new[] { 1, 2.5, 3 };       // double[]: найкращий спільний тип — double
Sum(new[] { 4, 5, 6 });
```

Коли спільного типу немає, це помилка компіляції:

```csharp
var g = new[] { 1, "two" };        // помилка CS0826: no best type found for an implicitly-typed array
```

## Підсумок форм

| Форма | Де працює |
| --- | --- |
| `int[] a = new int[5];` | будь-де; розмір і значення за замовчуванням |
| `int[] a = new int[] { 1, 2, 3 };` | будь-де |
| `int[] a = { 1, 2, 3 };` | лише в оголошенні |
| `var a = new[] { 1, 2, 3 };` | будь-де; тип виводиться |

Новіші версії C# також дозволяють `int[] a = [1, 2, 3];`. Онлайн-запускач цього курсу використовує старіший компілятор, тож тримайтеся форм вище.

## Корисно знати

- У кінці переліку дозволена кома, що зручно для переліку на кілька рядків:

```csharp
string[] days =
{
    "Mon",
    "Tue",
    "Wed",
};
```

- Якщо вказано і розмір, і значення, вони мусять узгоджуватися: `new int[2] { 1, 2, 3 }` не компілюється.
- Порожній масив — це `new int[0]` або `new int[] { }`. Це не `null`.
- Розмір масиву — це `Length` (властивість, без дужок). Колекції на кшталт `List<T>` натомість використовують `Count`.
- Масиви в сигнатурі методу виглядають так само: `static int[] Squares(int[] numbers)` приймає й повертає масив.
