Часто кілька задач запускають разом, і програмі потрібні всі або перша, що завершиться. Це роблять два методи:

- `Task.WhenAll(tasks)` завершується, коли **кожна** задача завершилась. Його результат для елементів `Task<T>` — масив результатів **у порядку задач**, незалежно від того, у якому порядку вони завершилися.
- `Task.WhenAny(tasks)` завершується, коли завершилась **перша** задача, і повертає її.

```csharp
static async Task<int> SquareAsync(int x)
{
    await Task.Delay(100 * x);                // чим більший x, тим довша задача
    return x * x;
}

var tasks = new[] { SquareAsync(3), SquareAsync(1), SquareAsync(2) };
int[] results = await Task.WhenAll(tasks);    // 9, 1, 4: порядок входу, а не завершення
```

## Першою завершилась: WhenAny

```csharp
Task<int> slow = SquareAsync(5);
Task<int> quick = SquareAsync(1);
Task<int> first = await Task.WhenAny(slow, quick);
Console.WriteLine(await first);               // 1: швидка завершилася першою
```

`WhenAny` корисний для таймауту: змагайте справжню роботу з `Task.Delay(limit)` і подивіться, яка завершиться першою.

## Помилки в WhenAll

Якщо деякі задачі падають, `WhenAll` чекає на всі, а потім повідомляє про кожне виключення. Наступна лекція пояснює, як їх читати.

## Запуск перед очікуванням

Як і в попередній лекції, запуск усіх задач спершу і очікування потім — те, що змушує їх виконуватися разом. Писати `await` усередині циклу, по одній задачі, означає виконувати їх одну за одною, і це повільніше.
