Масив — це послідовність фіксованої довжини зі значень одного типу.

```csharp
int[] scores = new int[3];          // { 0, 0, 0 }: нові масиви містять значення за замовчуванням
int[] primes = { 2, 3, 5, 7 };      // ініціалізований значеннями
var names = new[] { "Ann", "Bo" };  // тип виводиться: string[]
```

## Індекси та довжина

Індекси починаються з **0**, тому останній елемент має індекс `Length - 1`:

```csharp
Console.WriteLine(primes[0]);                 // 2
Console.WriteLine(primes[primes.Length - 1]); // 7
primes[1] = 13;                               // масиви змінювані
```

Читання `primes[4]` кидає `IndexOutOfRangeException`: C# завжди перевіряє межі масиву.

## Обхід масиву

```csharp
for (var i = 0; i < primes.Length; i++)
    Console.WriteLine(i + ": " + primes[i]);

foreach (var p in primes)
    Console.WriteLine(p);
```

Беріть `for`, коли потрібен індекс або треба змінювати елементи, і `foreach`, коли значення лише читаються.

## Масиви — це посилання

```csharp
int[] a = { 1, 2, 3 };
int[] b = a;      // b вказує на той самий масив
b[0] = 100;
Console.WriteLine(a[0]); // 100
```

Присвоєння масиву копіює **посилання**, а не елементи. Те саме відбувається, коли ви передаєте масив у метод: метод може змінити ваш масив.

## Порожні масиви

`new int[0]` — коректний масив із `Length == 0`. Код, що читає `numbers[0]` без перевірки довжини, на ньому впаде, тож продумуйте порожній випадок.
