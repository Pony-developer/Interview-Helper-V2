Пошук шаблону всередині тексту — базова задача: чи є `"ell"` у `"hello"`, і де саме? Найпростіший метод — **наївний пошук**: перебрати кожну початкову позицію й порівняти шаблон із текстом там:

```csharp
static int NaiveSearch(string text, string pattern)
{
    for (int start = 0; start + pattern.Length <= text.Length; start++)
    {
        int i = 0;
        while (i < pattern.Length && text[start + i] == pattern[i])
        {
            i++;
        }
        if (i == pattern.Length)
        {
            return start;                 // збіглися всі символи
        }
    }
    return -1;                            // не знайдено
}

Console.WriteLine(NaiveSearch("hello world", "world"));   // 6
Console.WriteLine(NaiveSearch("hello world", "xyz"));     // -1
```

## Як це працює

Зовнішній цикл вибирає початкову позицію. Внутрішній порівнює символи по одному й зупиняється на першій невідповідності. Якщо збіглися всі символи, початкова позиція — відповідь.

## Вартість

Для тексту довжини `n` і шаблону довжини `m` у найгіршому випадку це близько `n · m` порівнянь. Приклад: текст `"aaaaaaaaab"` і шаблон `"aaab"`. На кожній позиції пошук збігається на три символи `a`, перш ніж зірватися, і повторює це на кожній позиції.

Для повсякденного використання з короткими шаблонами наївний пошук достатньо швидкий і його легко зробити правильно. Наступна лекція показує метод, що уникає повторних порівнянь, використовуючи хеш.
