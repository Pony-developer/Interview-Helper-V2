Думаючий ШІ повільний, тож він працює у власному потоці, а головна програма продовжує роботу. Метод `Think(int seed)` готовий: він представляє повільне обчислення і повертає `seed * seed * 100`. Напишіть клас `ThinkingThread`, що запускає `Think` у новому потоці:

- `Start()`: створює `Thread`, який виконує метод `Work`, і запускає його;
- `Work()`: обчислює `Program.Think(seed)` і зберігає результат. Зберігайте його й встановлюйте `done` у `true` **під одним замком**, щоб інший потік ніколи не побачив одне без другого;
- `Wait()`: чекає на завершення потоку (`Join`). Якщо потік ніколи не запускали, нічого не робіть;
- `Result`: збережений результат, що читається під замком;
- `Done`: `true`, коли роботу завершено, що читається під замком.

`Main` не змінюйте. Очікуваний вивід:

```text
900
2500
True
False
```

Рядки по порядку: результат потоку для seed `3` (`3 * 3 * 100`); результат для seed `5`; `True`, бо після очікування обидва потоки завершені; і `False` для потоку, який ніколи не запускали.

Підказка: `new Thread(Work)` достатньо для створення потоку. Замок — це `sync`, об'єкт, який уже оголошено.
