Рано чи пізно в кожній програмі з'являються помилки. Вони бувають трьох видів, і кожен шукають по-своєму.

## Помилки компіляції

Компілятор відмовляється збирати програму. Нічого не запускається.

```csharp
int count = 4      // error CS1002: ; expected
string name = 42;  // error CS0029: Cannot implicitly convert type `int' to `string'
```

Це найдружніші помилки: компілятор називає рядок, стовпчик і що саме не так.

## Помилки виконання (винятки)

Програма компілюється, але падає під час роботи, і середовище виконання кидає **виняток**:

```csharp
int zero = 0;
Console.WriteLine(10 / zero);        // DivideByZeroException
int n = int.Parse("forty-two");      // FormatException
int[] a = new int[3];
Console.WriteLine(a[3]);             // IndexOutOfRangeException
```

Повідомлення називає тип винятку та **стек викликів** — ланцюжок методів, що привів до помилки. Читайте його згори: перший рядок вашого власного коду зазвичай і є місцем, куди варто дивитися.

## Логічні помилки

Програма запускається й завершується, але відповідь неправильна:

```csharp
double average = a + b + c / 3;   // на 3 ділиться лише c
```

Жоден інструмент не повідомить про них сам. Їх знаходять, коли знають, яким має бути результат, і перевіряють його — вручну або тестами. Найчастіші підозрювані — пріоритет операторів і цілочисельне ділення: `*`, `/` і `%` виконуються раніше за `+` і `-`, тож за сумнівів ставте дужки.
