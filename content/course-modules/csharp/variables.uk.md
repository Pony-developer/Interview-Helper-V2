**Змінна** — це іменована ділянка пам'яті, у якій лежить значення. Кожна змінна в C# має **тип** (що вона може зберігати) та **ім'я** (як до неї звертатися).

```csharp
int age = 25;          // оголошення та ініціалізація
string city = "Kyiv";
double height;         // лише оголошення
height = 1.68;         // присвоєння пізніше
```

## Оголошення, присвоєння, читання

Шаблон такий: `тип ім'я = значення;`. Знак `=` — це **присвоєння**, а не математична рівність: C# спершу обчислює праву частину й зберігає результат у змінній зліва.

```csharp
int score = 10;
score = score + 5;          // прочитали 10, додали 5, зберегли 15
Console.WriteLine(score);   // 15
```

Коли ви присвоюєте одну змінну іншій, значення **копіюється**. Далі змінні живуть окремо:

```csharp
int a = 5;
int b = a;
a = 10;
Console.WriteLine(b);   // 5
```

Кілька змінних одного типу можна оголосити в одній інструкції, але читати легше, коли кожна на своєму рядку:

```csharp
int x = 1, y = 2;
```

## Як обрати ім'я

- Використовуйте літери, цифри та `_`; ім'я не може починатися з цифри й не може містити пробілів чи `-`.
- Імена **чутливі до регістру**: `score` і `Score` — різні змінні.
- Ключове слово, як-от `class`, `int` чи `static`, не може бути іменем.
- За домовленістю локальні змінні пишуть у **camelCase** (`totalPrice`), а типи та методи — у **PascalCase** (`Program`, `Main`).
- Добре ім'я пояснює, що означає значення: `price` каже більше, ніж `x`.

## Використання до присвоєння

C# не дозволяє читати локальну змінну, яка могла так і не отримати значення:

```csharp
int total;
Console.WriteLine(total);   // помилка CS0165: Use of unassigned local variable 'total'
```

## Константи

**Константа** — це іменоване значення, яке ніколи не змінюється. Беріть її замість «магічного числа», що повторюється по всьому коду:

```csharp
const double Vat = 0.2;
double price = 100;
Console.WriteLine(price * Vat);   // 20
Vat = 0.3;                        // помилка: константу не можна змінити
```

## Область видимості

Змінна існує від свого оголошення до закриваючої `}` блоку, у якому її оголосили:

```csharp
static void Main()
{
    int a = 1;
    {
        int b = 2;
        Console.WriteLine(a + b);   // 3
    }
    Console.WriteLine(b);   // помилка CS0103: The name 'b' does not exist in the current context
}
```

У внутрішньому блоці також не можна оголосити другу змінну `a`, поки зовнішня `a` ще діє.
