Напишіть узагальнений метод, що повертає **найбільший елемент** масиву, для будь-якого типу, який можна порівнювати:

```csharp
static T Max<T>(T[] items) where T : IComparable<T>
```

Тримайте перший елемент як найкращий на цей момент і порівнюйте з ним кожен інший елемент. `Main` не змінюйте. Очікуваний вивід:

```text
9
plum
2.5
z
7
```

Рядки по порядку: максимум із `3, 9, 2`; найбільший із рядків `"pear", "apple", "plum"` (рядки порівнюються за алфавітом, і `plum` стоїть останнім); найбільший `double` — `2.5`; найбільший символ — `z`; і єдиний елемент масиву з одного елемента — `7`.

Підказка: `items[i].CompareTo(best) > 0` означає, що `items[i]` більший за `best`. Почніть цикл з індексу `1`, бо індекс `0` уже найкращий. Метод працює для кожного типу з обмеженням, тож окрема версія для кожного типу не потрібна.
