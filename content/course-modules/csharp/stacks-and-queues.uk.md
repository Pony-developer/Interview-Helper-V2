**Стек** і **черга** — це контейнери, які відрізняються лише **порядком**, в якому елементи з них виходять.

- **Стек** працює за принципом **LIFO**: останнім прийшов — першим вийшов. Як стос тарілок: кладете тарілку зверху й беретеся за верхню.
- **Черга** працює за принципом **FIFO**: першим прийшов — першим вийшов. Як черга в магазині: першого в черзі обслуговують першим.

```csharp
using System.Collections.Generic;

var stack = new Stack<int>();
stack.Push(1);
stack.Push(2);
stack.Push(3);
Console.WriteLine(stack.Pop());       // 3: останній покладений виходить першим
Console.WriteLine(stack.Peek());      // 2: дивимося на верх, не видаляючи його

var queue = new Queue<int>();
queue.Enqueue(1);
queue.Enqueue(2);
queue.Enqueue(3);
Console.WriteLine(queue.Dequeue());   // 1: першим доданий виходить першим
Console.WriteLine(queue.Peek());      // 2
```

## Операції

| Стек | Черга | Що робить |
|---|---|---|
| `Push(x)` | `Enqueue(x)` | додає елемент |
| `Pop()` | `Dequeue()` | видаляє й повертає елемент, що виходить наступним |
| `Peek()` | `Peek()` | повертає цей елемент, не видаляючи його |
| `Count` | `Count` | кількість елементів |

Взяття елемента з **порожнього** стека чи черги кидає `InvalidOperationException`. Перевіряйте `Count > 0` заздалегідь або будьте готові зловити виняток.

## Де їх використовують

- **Стеки**: кнопка «скасувати» в редакторі, стек викликів програми (кожен виклик методу кладеться в стек, кожне повернення його знімає), перевірка дужок, обчислення виразів.
- **Черги**: завдання друку, запити, що чекають на сервер, порядок завдань у грі, пошук у ширину в графах.

## Чому порядок важливий

Покладіть числа 1, 2, 3 в обидва контейнери — і `Pop` та `Dequeue` віддадуть їх у протилежному порядку. Вибирайте структуру за питанням, на яке треба відповісти: «що було **найновішим**?» — це стек; «що **чекало найдовше**?» — це черга.

Наступні лекції показують, як створити ці контейнери самим, і як використати їх у реальних задачах.
