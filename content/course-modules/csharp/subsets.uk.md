Множина з `n` елементів має **2ⁿ підмножин**: для кожного елемента ви вирішуєте «входить» чи «ні», і рішення незалежні. Згенерувати всі — ідеальна робота для рекурсії.

## Дерево рішень

Для елементів `a`, `b`, `c` вирішуйте про кожен по черзі:

```text
                      (початок)
                 /               \
           пропустити a         взяти a
          /      \               /      \
  пропустити b  взяти b  пропустити b  взяти b
      /  \        /  \       /  \        /  \
   проп. взяти проп. взяти проп. взяти проп. взяти     <- c
    c     c     c    c     c    c      c     c
   {}    {c}   {b}  {bc}  {a}  {ac}   {ab}  {abc}
```

Кожен шлях від кореня до листка — одна підмножина. Листків **8 = 2³**.

## Код

```csharp
static void Subsets(string items, int index, string current, List<string> result)
{
    if (index == items.Length)               // усі рішення ухвалено
    {
        result.Add(current);
        return;
    }
    Subsets(items, index + 1, current, result);                     // пропустити items[index]
    Subsets(items, index + 1, current + items[index], result);      // взяти items[index]
}

var all = new List<string>();
Subsets("abc", 0, "", all);
```

`all` — це `"", "c", "b", "bc", "a", "ac", "ab", "abc"` (перший елемент — «найстарше» рішення, тому підмножини виходять у порядку листків вище). Порожній рядок — це **порожня підмножина**, і вона враховується.

Рекурсія має три стандартні складники:

- **Стан**: індекс елемента, про який ухвалюється рішення, і підмножина, побудована досі.
- **Базовий випадок**: індекс дійшов до кінця, і одну повну підмножину записано.
- **Вибори**: для кожного елемента дві гілки.

## Те саме без рекурсії: бітова маска

Кожна підмножина відповідає числу від `0` до `2ⁿ − 1`, двійкові цифри якого кажуть, які елементи входять:

```csharp
int n = items.Length;
for (int mask = 0; mask < (1 << n); mask++)          // 1 << n — це 2ⁿ
{
    string subset = "";
    for (int j = 0; j < n; j++)
        if ((mask & (1 << j)) != 0)                  // чи встановлено біт j?
            subset += items[j];
    Console.WriteLine("{" + subset + "}");
}
```

Це робить те саме, циклом. Воно компактне для `n` до близько 30. Рекурсія гнучкіша: у ній легко **відсікти гілку рано**, як покажуть наступні розділи.

## Розмір відповіді

| n | 2ⁿ |
| --- | --- |
| 10 | 1 024 |
| 20 | 1 048 576 |
| 25 | 33 554 432 |
| 30 | понад мільярд |
| 40 | близько 10¹² |

Час роботи принаймні дорівнює **розміру виводу**, і з кожним новим елементом він подвоюється. Генерувати всі підмножини практично лише для `n` до близько 20–25.

## Підмножини з умовою: підрахунок

Часто самі підмножини не потрібні, а лише скільки з них задовольняють умову. **Скільки підмножин `{3, 34, 4, 12, 5, 2}` у сумі дають 9?**

```csharp
static int CountSubsets(int[] numbers, int index, int remaining)
{
    if (remaining == 0) return 1;                        // суму досягнуто
    if (index == numbers.Length) return 0;               // елементи скінчилися
    int without = CountSubsets(numbers, index + 1, remaining);
    int with = CountSubsets(numbers, index + 1, remaining - numbers[index]);
    return without + with;
}
```

Дві гілки додаються, бо кожна підмножина або пропускає елемент, або бере його. Для прикладу підмножини із сумою 9 — це `{4, 5}` та `{3, 4, 2}`, тож відповідь 2. (Перший рядок означає, що порожній залишок вважається успіхом. З невід'ємними числами пильнуйте, що елементи з нульовим значенням тоді можуть враховуватися обома способами.)

## Відсікання

Коли всі числа додатні, а `remaining` стає **від'ємним**, жодне продовження не допоможе. Відсікайте гілку одразу:

```csharp
if (remaining < 0) return 0;
```

Ця ідея — **повернення назад** (backtracking) із **відсіканням**: будуйте відповідь крок за кроком і відмовляйтеся від часткової відповіді, щойно вона не може привести до розв'язку. Це не змінює найгіршого випадку, але може зробити пошук швидким на практиці.

## Підмножини фіксованого розміру: комбінації

Щоб обрати рівно `k` з `n` елементів, передавайте `k` далі й зупиняйтеся, коли обрано достатньо:

```csharp
static void Choose(string items, int start, int k, string current, List<string> result)
{
    if (k == 0) { result.Add(current); return; }
    for (int i = start; i < items.Length; i++)
        Choose(items, i + 1, k - 1, current + items[i], result);   // лише елементи ПІСЛЯ i
}
```

`Choose("abcd", 0, 2, "", r)` дає `ab, ac, ad, bc, bd, cd`: 6 підмножин, тобто «4 по 2». Незабаром буде лекція про це разом із розміщеннями.

## Шаблон повернення назад

Підмножини, перестановки, головоломки та багато задач пошуку вкладаються в один шаблон:

```text
Solve(state):
    if state is complete:   записати відповідь; return
    for each choice available in this state:
        зробити вибір
        Solve(new state)
        скасувати вибір      <- лише якщо стан спільний, а не переданий копією
```

У коді вище рядки передаються як **нові** значення, тож скасовувати нічого. Коли ви використовуєте спільний масив чи список, зміну треба скасувати після рекурсивного виклику, інакше гілки заважатимуть одна одній. Наступна лекція це покаже.
