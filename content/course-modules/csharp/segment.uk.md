Відрізок будується з двох точок, і це гарний приклад об'єктів, що **містять інші об'єкти**. Клас `Point` (із `X`, `Y`, конструктором і `ToString()`, що друкує `(x, y)`) **уже написано**. Напишіть клас `Segment`.

`Segment` має:

- конструктор `Segment(a, b)` із двома об'єктами `Point`;
- властивість `Length`: відстань між двома точками;
- метод `Midpoint()`: **нова** `Point` посередині;
- метод `Contains(p)`: `true`, якщо точка `p` лежить **на відрізку**, разом із кінцями. Точка має лежати на прямій через `a` та `b` **і** всередині прямокутника, який охоплюють дві точки. Порівнюйте векторний добуток з нулем із малим допуском на кшталт `1e-9`;
- властивість `IsHorizontal`: `true`, коли обидві точки мають однакове `Y`;
- метод `Translate(dx, dy)`: повертає **новий** відрізок, зсунутий на задані величини. Початковий має лишитися без змін.

`Main` не змінюйте. Очікуваний вивід:

```text
10
(3, 4)
True
False
False
True
(4, 5)
(3, 4)
True
False
```

Рядки по порядку, для відрізка від `(0, 0)` до `(6, 8)`: його довжина; його середина; чи лежить на ньому `(3, 4)`; чи лежить `(3, 5)` (вона поза прямою); чи лежить `(9, 12)` (вона на прямій, але за кінцем); чи лежить кінець `(0, 0)`; середина зсунутого відрізка; середина **початкового** (незмінного); і `IsHorizontal` для горизонтального відрізка та для цього.

Підказка: для точки `p` векторний добуток — це `(b.X − a.X)·(p.Y − a.Y) − (b.Y − a.Y)·(p.X − a.X)`. Він дорівнює 0 для точок на прямій. Потім перевірте, що `p.X` лежить між `Math.Min(a.X, b.X)` та `Math.Max(a.X, b.X)`, і те саме для `Y`.
