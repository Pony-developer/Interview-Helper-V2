Таблиці, дошки, зображення та матриці мають два виміри. Для них у C# є **прямокутний** масив: один об'єкт-масив із рядками й стовпчиками, що записується з комою всередині дужок.

## Створення та індексація

```csharp
int[,] grid = new int[3, 4];   // 3 рядки, 4 стовпчики, усі нулі
grid[1, 2] = 7;                // рядок 1, стовпчик 2
Console.WriteLine(grid[1, 2]); // 7
```

Елемент адресується **двома індексами в одній парі дужок**: `grid[row, col]`. Обидва починаються з 0. `grid[1][2]` — інший синтаксис, для масивів масивів (див. наступну лекцію), і тут він не працює.

## Ініціалізація значеннями

```csharp
int[,] matrix =
{
    { 1, 2, 3 },
    { 4, 5, 6 },
};
```

Кожна внутрішня пара фігурних дужок — один рядок, і в кожному рядку має бути однакова кількість елементів.

## Розміри

| Вираз | Значення | Для `matrix` |
| --- | --- | --- |
| `matrix.GetLength(0)` | кількість рядків | 2 |
| `matrix.GetLength(1)` | кількість стовпчиків | 3 |
| `matrix.Length` | кількість **усіх** елементів | 6 |
| `matrix.Rank` | кількість вимірів | 2 |

Будьте обережні: `Length` — це не кількість рядків.

## Обхід двовимірного масиву

Два вкладені цикли: перший за рядками, другий за стовпчиками:

```csharp
for (int row = 0; row < matrix.GetLength(0); row++)
{
    for (int col = 0; col < matrix.GetLength(1); col++)
    {
        Console.Write(matrix[row, col] + " ");
    }
    Console.WriteLine();
}
```

```text
1 2 3 
4 5 6 
```

`foreach` теж працює, але він розплющує масив і проходить усі елементи один за одним, рядок за рядком, не повідомляючи, де закінчується рядок:

```csharp
foreach (int value in matrix)
{
    Console.Write(value + " ");   // 1 2 3 4 5 6
}
```

## Типові завдання

**Сума всіх елементів**

```csharp
int sum = 0;
for (int r = 0; r < matrix.GetLength(0); r++)
    for (int c = 0; c < matrix.GetLength(1); c++)
        sum += matrix[r, c];
```

**Діагональ квадратної матриці**: елементи, де рядок дорівнює стовпчику.

```csharp
for (int i = 0; i < n; i++) Console.Write(square[i, i] + " ");
```

**Транспонування**: обмін рядків і стовпчиків у новому масиві.

```csharp
int[,] t = new int[matrix.GetLength(1), matrix.GetLength(0)];
for (int r = 0; r < matrix.GetLength(0); r++)
    for (int c = 0; c < matrix.GetLength(1); c++)
        t[c, r] = matrix[r, c];
```

**Дошка із символів**

```csharp
char[,] board = new char[3, 3];
for (int r = 0; r < 3; r++)
    for (int c = 0; c < 3; c++)
        board[r, c] = '.';
board[1, 1] = 'X';
```

## Три й більше вимірів

Та сама ідея розширюється: `int[,,] cube = new int[2, 3, 4];` — це два шари 3 × 4. Виміри понад три трапляються рідко.

## Сусіди й край

Коли ви дивитеся на сусідів клітинки, спершу перевіряйте межі. Клітинка над `(row, col)` — це `(row - 1, col)`, і для `row == 0` її не існує:

```csharp
bool hasAbove = row > 0;
bool hasRight = col < grid.GetLength(1) - 1;
```

Читання `grid[-1, col]` кидає `IndexOutOfRangeException`, як і для одновимірного масиву.

## Майте на увазі

- Прямокутний масив — це **один об'єкт**, у якого всі клітинки лежать в одному блоці пам'яті.
- Усі рядки мають однакову довжину. Якщо рядки різної довжини, використайте масив масивів.
- Передача в метод працює як для будь-якого масиву: метод отримує посилання й може змінювати клітинки.
