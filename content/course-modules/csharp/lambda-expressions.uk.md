**Лямбда-вираз** — найкоротший спосіб записати делегат. Він має вигляд `параметри => тіло`:

```csharp
Func<int, int> square = x => x * x;            // один параметр, тіло-вираз
Func<int, int, int> add = (a, b) => a + b;     // два параметри
Action<string> say = s => Console.WriteLine(s);  // без результату

Console.WriteLine(square(7));                  // 49
Console.WriteLine(add(2, 5));                  // 7
say("hi");                                     // hi
```

Стрілка `=>` читається як «переходить у». Ліворуч — параметри, праворуч — тіло. Якщо тіло — один вираз, його значення і є результатом лямбди, і `return` не пишеться.

## Списки параметрів

```csharp
x => x * 2                  // один параметр: дужки не потрібні
(x) => x * 2                // те саме, з дужками
(a, b) => a + b             // два параметри
() => 42                    // без параметрів: дужки обов'язкові
(int a, int b) => a + b     // типи можна записати, але зазвичай їх не пишуть
```

Компілятор знає типи з делегата, до якого перетворюється лямбда, тому типи зазвичай пропускають.

## Тіла-блоки

Коли тілу потрібно кілька інструкцій, використовуйте фігурні дужки й `return`:

```csharp
Func<int, bool> isEven = n =>
{
    int remainder = n % 2;
    return remainder == 0;
};
```

## Де з'являються лямбди

```csharp
var numbers = new List<int> { 5, 12, 7, 30 };
int firstBig = numbers.Find(n => n > 10);      // 12
numbers.RemoveAll(n => n < 10);                // видаляє 5 і 7
```

Скрізь, де метод очікує делегат, можна передати лямбду безпосередньо. Наступна лекція показує більше прикладів.
