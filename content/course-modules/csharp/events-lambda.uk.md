Лямбда-вирази — найзручніший спосіб написати обробник, бо обробник зазвичай короткий і потрібен в одному місці:

```csharp
var button = new Button();
int clicks = 0;
button.Clicked += () => clicks++;           // лямбда захоплює змінну clicks

button.Click();
button.Click();
Console.WriteLine(clicks);                  // 2
```

Лямбда — замикання (див. модуль про делегати): вона читає й змінює локальну змінну `clicks`, яка живе, доки живе підписка.

## Лямбди зі стандартною сигнатурою

Для `EventHandler<T>` лямбда отримує два параметри: відправника і дані:

```csharp
var t = new Thermometer();
t.TemperatureChanged += (sender, e) =>
{
    if (e.New > 30)
    {
        Console.WriteLine("too hot: " + e.New);
    }
};
t.Set(35);                                  // too hot: 35
```

## Порядок обробників

Обробники виконуються в порядку підписки. Якщо один обробник кидає виняток, решта не виконується, тож тримайте обробники короткими й безпечними або перехоплюйте винятки всередині них.

## Лямбди й відписка

Як показала попередня лекція, лямбду не можна прибрати іншою лямбдою. Якщо ви підписали лямбду і згодом хочете відписатися, тримайте її у змінній типу делегата. Простіша альтернатива — підписувати іменований метод.

## Коли вживати лямбду

- обробник короткий і використовується в одному місці;
- йому потрібні локальні змінні методу, що підписується;
- підписка живе стільки ж, скільки об'єкт, тож відписка не потрібна.

Іменований метод вживайте, коли обробник довгий, використовується в кількох місцях або його треба буде прибрати пізніше.
