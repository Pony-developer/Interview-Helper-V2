Вектор на площині — це пара `(x, y)`. Його координати приховані, а зовнішній код працює з його **довжиною** та напрямком. Напишіть клас `Vector`:

- **приватні** поля для `x` та `y` і властивості лише для читання `X` та `Y`;
- конструктор `Vector(x, y)` і конструктор без параметрів для нульового вектора, що **викликає перший** через `: this(0, 0)`;
- **статична фабрика** `FromPolar(length, degrees)`: вектор цієї довжини, спрямований під цим кутом від осі `x` проти годинникової стрілки (`x = length · cos`, `y = length · sin`, кут у радіанах: `degrees · π / 180`);
- властивість **`Length`**:
  - `get` повертає `√(x² + y²)`;
  - `set` **змінює довжину й зберігає напрямок**: обидві координати множаться на `нова довжина / стара довжина`. **Від'ємне** значення кидає `ArgumentOutOfRangeException`. Для **нульового** вектора, що не має напрямку, додатна довжина кидає `InvalidOperationException` (а `0` приймається й нічого не змінює);
- `ToString()`: `(x, y)`, кожне число округлене до 2 знаків після коми, наприклад `(0.5, 0.87)`.

`Main` не змінюйте. Очікуваний вивід:

```text
(3, 4)
5
(6, 8)
10
(0, 0)
(0, 2)
(0.5, 0.87)
negative length
(6, 8)
no direction
(0, 0)
```

Рядки по порядку: вектор `(3, 4)` і його довжина; вектор після `Length = 10` (його розтягнуто до `(6, 8)`) і його нова довжина; нульовий вектор; `FromPolar(2, 90)` (він дивиться вгору); `FromPolar(1, 60)`; відхилена від'ємна довжина, а вектор не змінився; відхилена спроба задати довжину нульовому вектору; і нульовий вектор після `Length = 0`.

Підказка: `Math.Cos` і `Math.Sin` потребують радіанів. `Math.Round(value, 2)` округлює числа для `ToString`; текст `double` для цілих чисел не має `.0`. Перевірки в сеттері робіть **раніше**, ніж змінюєте поля.
