Уявіть метод, що сортує або фільтрує список. Правило сортування щоразу може бути іншим: за іменем, за віком, у зворотному порядку. Як метод має знати, яке правило застосувати?

## Спроба 1: скопіювати метод

```csharp
static void SortByName(List<Person> people) { /* сортування за іменем */ }
static void SortByAge(List<Person> people) { /* сортування за віком */ }
```

Кожному правилу потрібна власна копія того самого циклу. Кожна зміна алгоритму має бути внесена в кожну копію.

## Спроба 2: прапорець і switch

```csharp
static void Sort(List<Person> people, string rule)
{
    if (rule == "name") { /* ... */ }
    else if (rule == "age") { /* ... */ }
}
```

Тепер один метод містить усі правила. Нове правило означає нову гілку в цьому методі, і метод мусить знати про кожне правило в програмі. До того ж правило передається рядком, який компілятор не може перевірити.

## Спроба 3: інтерфейс

```csharp
interface ISortRule { bool IsLess(Person a, Person b); }
```

Це працює, але кожне правило потребує нового класу з одним методом. Для одного порівняння це забагато церемоній.

## Чого ми хочемо

Ми хочемо передати саму **поведінку** як аргумент: «ось правило, використовуй його». Правило — це значення, як число, яке метод викликає, коли потрібно. У C# це роблять **делегати**: тип, що тримає посилання на метод. Наступні лекції показують, як їх оголосити, використати й скоротити.
