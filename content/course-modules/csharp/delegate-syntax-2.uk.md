Один делегат може тримати **кілька** методів одразу. Поєднання їх через `+=` створює делегат, що викликає кожен метод по черзі; видалення через `-=` прибирає один. Це називають **мультикастом** (multicast). Напишіть тип делегата й два методи, які вживає `Main`.

- Оголосіть тип делегата `Notify`: він приймає один параметр `string` і нічого не повертає (`void`). Помістіть оголошення вище за `Program`.
- Напишіть статичний метод `ConsoleNotify(string message)`: він друкує `console: ` і далі повідомлення.
- Напишіть статичний метод `LogNotify(string message)`: він друкує `log: ` і далі повідомлення.

`Main` не змінюйте. Очікуваний вивід:

```text
console: saved
log: saved
log: loaded
no handlers
```

Рядки по порядку: `n` викликає обидва методи, тож повідомлення друкується двічі; після `n -= ConsoleNotify` викликається лише метод журналу; а змінна делегата, яку ніколи не присвоювали, дорівнює `null`, тож `Main` повідомляє, що обробників немає.

Підказка: `Notify n = ConsoleNotify;`, потім `n += LogNotify;` створює делегат із двома методами. Виклик `n("saved")` викликає їх у порядку додавання.
