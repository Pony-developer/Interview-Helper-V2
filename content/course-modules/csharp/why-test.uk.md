Тест — це код, який запускає ваш код із відомими вхідними даними й перевіряє результат. Тести перетворюють «здається, працює» на «працює для цих випадків» і зберігають це, коли ви згодом щось змінюєте.

## Найпростіший тест

```csharp
static void Check(int actual, int expected, string name)
{
    Console.WriteLine((actual == expected ? "ok" : "FAIL") + ": " + name);
}

Check(Add(2, 3), 5, "small numbers");
Check(Add(-2, 2), 0, "opposite numbers");
```

У реальних проєктах натомість використовують тестовий фреймворк: **xUnit**, **NUnit** або **MSTest**. Ідея та сама:

```csharp
[Fact]
public void Add_ReturnsSum()
{
    Assert.Equal(5, Calculator.Add(2, 3));
}
```

Фреймворк знаходить кожен тест, запускає його й повідомляє, які впали.

## Що тестувати

Звичайні вхідні дані — найпростіше. Помилки ховаються на краях:

- **порожні** дані: `""`, порожній масив, порожній список;
- **один** елемент — найменший непорожній випадок;
- **межі**: 0, від'ємні числа, `int.MaxValue`, перший і останній індекс;
- **повторювані** значення, уже відсортовані та відсортовані навпаки дані.

## Спершу червоний, потім зелений

Коли знайшли помилку, спочатку напишіть тест, який через неї падає (**червоний**), а потім виправляйте код, доки тест не пройде (**зелений**). Тест лишається в проєкті й гарантує, що помилка не повернеться.
