Побудуйте малий **конвеєр очищення тексту** зі взаємозамінних частин. Інтерфейс готовий:

```csharp
interface ITextFilter
{
    string Apply(string text);
}
```

**Напишіть ці класи, і всі вони реалізують `ITextFilter`:**

- `TrimFilter`: прибирає пробіли на початку й наприкінці;
- `CollapseSpacesFilter`: замінює кожну послідовність кількох пробілів **одним** пробілом (регулярні вирази не вживайте: пройдіть символами);
- `UpperFilter`: перетворює текст на верхній регістр;
- `RemoveDigitsFilter`: прибирає всі цифри `0`-`9`;
- `ReplaceFilter(from, to)`: замінює кожне входження тексту `from` текстом `to`;
- `Pipeline`: фільтр, що **містить інші фільтри**:
  - `Add(filter)` додає фільтр у кінець і **повертає сам конвеєр**, щоб виклики можна було ланцюжити: `new Pipeline().Add(a).Add(b)`;
  - `Apply(text)` запускає фільтри **в порядку додавання**, передаючи результат кожного наступному. Порожній конвеєр повертає текст без змін;
  - `Count` — кількість фільтрів, доданих до нього.

Оскільки `Pipeline` сам є `ITextFilter`, його можна **додати до іншого конвеєра**. Вкладений конвеєр рахується як **один** фільтр. `Main` не змінюйте. Очікуваний вивід:

```text
[hello big world]
[BYE BIG WORLD]
abc
unchanged
3
bonono
QUIET PLEASE
```

Рядки по порядку: конвеєр `clean` (обрізати, стиснути) для `"   hello    big   world  "`; конвеєр `shout`, що містить `clean`, потім `UpperFilter`, потім заміну `HELLO` на `BYE`, для того самого тексту; цифри, прибрані з `a1b22c333`; порожній конвеєр; `Count` конвеєра `shout` (3, бо `clean` рахується як один); `ReplaceFilter`, вжитий через змінну типу інтерфейсу (`banana`, де `a` замінено на `o`); і конвеєр, побудований ланцюжком викликів `Add`.

Підказка: тримайте фільтри в `List<ITextFilter>` (`using System.Collections.Generic;` для вас написано). Кожен клас-фільтр — лише кілька рядків. Сенс задачі — побачити, що **нова поведінка — це новий малий клас** і що частини можна поєднувати в будь-якому порядку без змін у старому коді.
