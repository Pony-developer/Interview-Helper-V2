`for` — цикл для випадків, коли відомо, скільки разів повторювати, або коли повторення керується лічильником. Він збирає в один рядок три частини, які `while` розкидає.

```csharp
for (int i = 0; i < 5; i++)
{
    Console.Write(i + " ");   // 0 1 2 3 4
}
```

## Три частини

```csharp
for (ініціалізація; умова; крок)
{
    тіло
}
```

1. **Ініціалізація** виконується один раз, перед циклом.
2. **Умова** перевіряється перед кожною ітерацією. Коли вона `false`, цикл завершується.
3. **Крок** виконується після кожної ітерації.

Це точно те саме, що:

```csharp
{
    int i = 0;
    while (i < 5)
    {
        // тіло
        i++;
    }
}
```

## Скільки ітерацій?

- `for (i = a; i < b; i++)` виконується `b − a` разів (для `b > a`).
- `for (i = a; i <= b; i++)` виконується `b − a + 1` разів.

Лічба з 0 і зупинка **перед** довжиною — звичка C#. Вона збігається з індексами: рядок із 5 символів має позиції від 0 до 4.

## Варіації

```csharp
for (int i = 10; i > 0; i--)         // зворотний відлік: 10 9 8 ... 1
for (int i = 0; i < 20; i += 5)      // більший крок: 0 5 10 15
for (int i = 10; i > 0; i -= 3)      // 10 7 4 1
```

В одному циклі можна мати **два лічильники**. Розділяйте частини комами:

```csharp
for (int i = 0, j = 5; i < j; i++, j--)
{
    Console.WriteLine(i + " " + j);   // 0 5, потім 1 4, потім 2 3
}
```

Будь-яку частину можна лишити порожньою. `for (;;)` — нескінченний цикл, як `while (true)`.

## Область видимості лічильника

Змінна, оголошена в заголовку `for`, існує лише всередині циклу:

```csharp
for (int i = 0; i < 3; i++) { }
Console.WriteLine(i);   // помилка: the name 'i' does not exist in the current context
```

Це перевага: два цикли один за одним можуть обидва використовувати `i`. Якщо значення потрібне після циклу, оголосіть змінну **перед** ним:

```csharp
int i;
for (i = 0; i < 5; i++) { }
Console.WriteLine(i);   // 5
```

## Обхід рядка

```csharp
string word = "hello";
for (int i = 0; i < word.Length; i++)
{
    Console.WriteLine(word[i]);
}
```

Ось кілька шаблонів:

```csharp
// обернення: рахуємо вниз від останнього індексу
string reversed = "";
for (int i = word.Length - 1; i >= 0; i--)
{
    reversed += word[i];
}
Console.WriteLine(reversed);   // olleh

// підрахунок символів, що відповідають правилу
int vowels = 0;
for (int i = 0; i < word.Length; i++)
{
    if (word[i] == 'a' || word[i] == 'e' || word[i] == 'i' || word[i] == 'o' || word[i] == 'u')
    {
        vowels++;
    }
}
Console.WriteLine(vowels);   // 2
```

Якщо ви лише читаєте символи, простіший `foreach`, бо індексу, у якому можна помилитися, немає:

```csharp
foreach (char c in word)
{
    Console.Write(c + "-");   // h-e-l-l-o-
}
```

## Пастки

- **Помилка на одиницю**: `i <= word.Length` робить зайвий крок, а `word[word.Length]` кидає `IndexOutOfRangeException`.
- **Зміна лічильника в тілі** ускладнює розуміння циклу. Якщо крок нерегулярний, використайте `while`.
- **Лічильники `double`**: `for (double x = 0; x < 1; x += 0.1)` може виконатися 11 разів замість 10, бо 0.1 у двійковому вигляді неточне (див. лекцію про порівняння чисел з плаваючою комою). Проходьте по `int`, а `double` обчислюйте всередині: `double x = i / 10.0;`.
- **Крапка з комою після заголовка**: `for (int i = 0; i < 3; i++);` — цикл із порожнім тілом, а наступний блок виконується один раз.
- **Складання тексту через `+=` у довгому циклі** щоразу створює новий рядок. Для малих текстів це нормально. Для великих є `StringBuilder`.
