Колекція, побудована через `yield return`, — **лінива**: вона обчислює кожен елемент лише тоді, коли його хтось просить. Нічого не зберігається заздалегідь, тож послідовність може бути навіть нескінченною:

```csharp
static IEnumerable<int> Naturals()
{
    int n = 1;
    while (true)                      // ніколи не завершується
    {
        yield return n;
        n++;
    }
}

foreach (int n in Naturals())
{
    if (n > 3) break;                 // зупиняємо самі
    Console.Write(n + " ");           // 1 2 3
}
```

Список потребував би нескінченної пам'яті. Ітератор потребує одного числа за раз.

## Конвеєри працюють поелементно

Ланцюжки методів LINQ над лінивою послідовністю утворюють **конвеєр**. Кожен елемент проходить усі кроки, перш ніж почнеться наступний:

```csharp
static IEnumerable<int> Trace(IEnumerable<int> items)
{
    foreach (int x in items)
    {
        Console.WriteLine("produce " + x);
        yield return x;
    }
}

var result = Trace(new[] { 1, 2, 3 }).Where(x => x % 2 == 1);
foreach (int x in result)
{
    Console.WriteLine("use " + x);
}
// produce 1
// use 1
// produce 2
// produce 3
// use 3
```

Елемент `2` створюється, відфільтровується й ніколи не використовується. Ніхто не чекає, поки створять усі елементи.

## Лінивість не зберігає результат

Ліниву послідовність **виконують заново щоразу**, коли її перелічують. Два цикли за тим самим викликом `Trace(...)` створять елементи двічі. Якщо результати потрібні двічі, збережіть їх один раз:

```csharp
var stored = Trace(new[] { 1, 2 }).ToList();   // робота виконується один раз, тут
```

## Коли лінивість допомагає

- читання величезного файлу рядок за рядком, без завантаження всього;
- ранній зупинок: `First()` або `break` не обчислює решту;
- нескінченні чи дуже довгі згенеровані послідовності;
- передача послідовності через кілька методів без створення копій.

## Коли вона шкодить

Якщо джерело змінюється між моментом створення послідовності та моментом її читання, ви побачите нові дані. Також виняток всередині ітератора з'являється лише під час перелічування, а не під час виклику методу. Розділ про особливі випадки в лекції про yield return повертається до цього.
