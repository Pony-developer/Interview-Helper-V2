Два невеликі інструменти для статистики й тексту, кожен із розв'язанням через LINQ.

- `Median(IEnumerable<double> values)`: медіана значень. Відсортуйте їх; для непарної кількості — середнє значення, для парної — середнє з двох середніх. Для відсутніх значень поверніть `0`. Вхідну послідовність не змінюйте;
- `Bigrams(string text)`: **біграми** тексту: кожні два сусідні символи, по порядку, як рядок. `"hello"` дає `he`, `el`, `ll`, `lo`. Текст з одного символу дає жодної біграми.

Метод `ShowAll` готовий. `Main` не змінюйте. Очікуваний вивід:

```text
4
5.5
he el ll lo

3
```

Рядки по порядку: медіана `5, 1, 9, 3` (відсортовано `1, 3, 5, 9`; середнє `3` і `5`); медіана `2, 7, 4, 10` (середнє `4` і `7`); біграми `hello`; біграми `a`, тобто порожній рядок; і кількість різних біграм `abcabc`, що дорівнює `3` (`ab`, `bc`, `ca`).

Підказка: `values.OrderBy(v => v).ToList()` сортує значення. `Enumerable.Range(0, text.Length - 1)` дає початкові позиції біграм; використайте `Math.Max(0, ...)`, щоб текст з одного символу давав порожній діапазон.
