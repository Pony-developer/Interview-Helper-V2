Цикл може містити інший цикл. Внутрішній цикл виконується **повністю** на кожній ітерації зовнішнього.

```csharp
for (int row = 0; row < 3; row++)
{
    for (int col = 0; col < 4; col++)
    {
        Console.Write("*");
    }
    Console.WriteLine();
}
```

```text
****
****
****
```

Зовнішній цикл рахує рядки. Для кожного рядка внутрішній друкує чотири зірочки в одному рядку (`Console.Write` не переходить на новий), а тоді `Console.WriteLine()` завершує рядок. Тіло внутрішнього циклу виконується 3 × 4 = **12** разів.

## Шаблон для сітки

Майже кожна картинка із символів має той самий каркас:

```csharp
for (int row = 0; row < height; row++)
{
    for (int col = 0; col < width; col++)
    {
        // вирішуємо, який символ стоїть у (row, col)
        Console.Write(...);
    }
    Console.WriteLine();   // завершуємо рядок
}
```

Усе мистецтво — у рішенні. Для кожної клітинки спитайте: що я знаю про `row` і `col`?

| Картинка | Правило для клітинки `(row, col)` |
| --- | --- |
| заповнений прямокутник | завжди `*` |
| рамка | `*`, якщо `row == 0 \|\| row == height - 1 \|\| col == 0 \|\| col == width - 1`, інакше пробіл |
| шахівниця | `#`, якщо `(row + col) % 2 == 0`, інакше `.` |
| головна діагональ | `*`, якщо `row == col` |
| друга діагональ | `*`, якщо `row + col == size - 1` |
| трикутник | `*`, якщо `col <= row` |

Наприклад, трикутник:

```csharp
for (int row = 0; row < 4; row++)
{
    for (int col = 0; col <= row; col++)
    {
        Console.Write("*");
    }
    Console.WriteLine();
}
```

```text
*
**
***
****
```

Тут внутрішній цикл залежить від лічильника зовнішнього: його межа — `row`, тож кожен рядок довший на одну зірочку.

## Таблиця множення

```csharp
for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 3; j++)
    {
        Console.Write(i * j + " ");
    }
    Console.WriteLine();
}
```

```text
1 2 3 
2 4 6 
3 6 9 
```

Зверніть увагу на пробіл після останнього числа в кожному рядку. Коли важливий точний вивід, як у практичних завданнях, уникайте цього, наприклад записуючи роздільник лише **між** елементами.

## Імена та правила

- Давайте лічильникам змістовні імена: `row` і `col` або `i` і `j`. Не використовуйте те саме ім'я в обох циклах: внутрішнє `i` конфліктувало б із зовнішнім.
- Внутрішній цикл починається спочатку на кожній ітерації зовнішнього, тож оголошуйте його лічильник **усередині** зовнішнього циклу.
- `break` і `continue` діють **лише на найглибший** цикл. Щоб вийти з обох одразу, винесіть їх у метод і скористайтеся `return` або прапорцем.

```csharp
static bool HasPair(int target)
{
    for (int a = 1; a < 10; a++)
    {
        for (int b = 1; b < 10; b++)
        {
            if (a * b == target) return true;   // виходить з обох циклів
        }
    }
    return false;
}
```

## Вартість

Якщо обидва цикли повторюються `n` разів, тіло виконується `n × n` разів. У десять разів більше даних означає в сто разів більше роботи. Це **O(n²)** (див. лекцію про O-нотацію): нормально для шахівниці, проблема для мільйона елементів.
