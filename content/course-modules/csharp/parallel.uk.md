Створювати потоки вручну нудно. Для циклів, чиї ітерації незалежні, клас `Parallel` (у `System.Threading.Tasks`) розподіляє роботу між доступними ядрами сам:

```csharp
using System.Threading.Tasks;

int[] data = new int[8];
Parallel.For(0, data.Length, i =>
{
    data[i] = i * i;                        // кожна ітерація пише свій елемент
});

Parallel.ForEach(new[] { "a", "b", "c" }, s =>
{
    Console.WriteLine(s);                   // порядок цих рядків не визначений
});

Parallel.Invoke(
    () => Console.WriteLine("first"),       // ці дві дії можуть виконуватися одночасно
    () => Console.WriteLine("second"));
```

`Parallel.For` виконує тіло для кожного індексу, `ForEach` — для кожного елемента, а `Invoke` запускає кілька різних дій. Коли всі вони завершаться, виклик повертається.

## Правило безпечного паралельного циклу

Кожна ітерація має працювати зі **своїми даними**: писати в `data[i]`, а не в спільну суму. Якщо ітерації мусять змінювати одну спільну змінну, захистіть її блокуванням (наступна лекція) або використайте `Interlocked`. Інакше результат залежить від часу.

## Коли Parallel допомагає

- робота на одну ітерацію достатньо велика (принаймні кілька мікросекунд);
- ітерації незалежні одна від одної;
- машина має кілька ядер.

Для крихітних ітерацій вартість розподілу роботи більша за саму роботу, і простий цикл швидший.

## Винятки

Якщо одна ітерація кидає виняток, виклик `Parallel` збирає винятки й кидає `AggregateException` з усіма ними.
