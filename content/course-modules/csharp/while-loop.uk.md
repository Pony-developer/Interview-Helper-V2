Базова форма вам уже знайома:

```csharp
while (condition)
{
    // тіло
}
```

C# перевіряє умову. Якщо вона `true`, тіло виконується один раз, і умова перевіряється знову. Коли вона стає `false`, цикл завершується, і програма продовжує роботу після нього. Кожен прогін тіла називається **ітерацією**. Якщо умова хибна з самого початку, ітерацій нуль.

## Трасування циклу

Щоб зрозуміти цикл, зіграйте роль комп'ютера: записуйте змінні після кожної ітерації. Ось сума цифр числа `472`:

```csharp
int n = 472;
int sum = 0;
while (n > 0)
{
    sum += n % 10;   // додаємо останню цифру
    n /= 10;         // відкидаємо останню цифру
}
Console.WriteLine(sum);   // 13
```

| Ітерація | `n` до | `n % 10` | `sum` після | `n` після |
| --- | --- | --- | --- | --- |
| 1 | 472 | 2 | 2 | 47 |
| 2 | 47 | 7 | 9 | 4 |
| 3 | 4 | 4 | 13 | 0 |

Після цього перевірка `n > 0` хибна, і цикл зупиняється. Таблиця трасування знаходить більшість помилок ще до запуску.

## Поширені шаблони

**Лічба**: повторити фіксовану кількість разів.

```csharp
int i = 0;
while (i < 3)
{
    Console.WriteLine("Hello");
    i++;
}
```

**Накопичення**: нарощування суми, добутку чи тексту.

```csharp
int product = 1;
int k = 1;
while (k <= 5)
{
    product *= k;
    k++;
}
Console.WriteLine(product);   // 120
```

**Зменшення чи зростання до мети**: кількість кроків наперед невідома. Саме тут `while` кращий за `for`.

```csharp
int steps = 0;
int n = 100;
while (n > 1)
{
    n /= 2;
    steps++;
}
Console.WriteLine(steps);   // 6   (100 -> 50 -> 25 -> 12 -> 6 -> 3 -> 1)
```

**Розбирання числа**: `n % 10` — остання цифра, а `n / 10` — число без неї. Повторюйте, доки нічого не лишиться, як у прикладі вище.

**Очікування сигналу** (*вартовий*): продовжувати, доки не з'явиться особливе значення, наприклад доки введення не дорівнюватиме `"quit"`.

## Як переконатися, що цикл завершиться

Щось усередині тіла має наближати умову до `false`. Якщо нічого не наближає, цикл нескінченний:

```csharp
int i = 0;
while (i < 5)
{
    Console.WriteLine(i);
    // забули i++, тож це ніколи не завершиться
}
```

Перш ніж писати цикл, дайте відповідь на три питання:

1. Що істинне **перед** першою ітерацією?
2. Що змінюється в **кожній** ітерації?
3. Чому умова **зрештою** стане хибною?

Іноді нескінченний цикл задумано. `while (true)` із `break` усередині — законний спосіб записати «повторювати, доки щось не станеться посеред тіла».

## Переповнення може зробити цикл нескінченним

Цей цикл виглядає невинно:

```csharp
int power = 1;
while (power < n)
{
    power *= 2;
}
```

Якщо `n` більше за 2³⁰ (близько мільярда), `power` переповнює `int` після 2³⁰: наступне подвоєння стає від'ємним, `power < n` лишається `true` вічно, і цикл не завершується. Коли значення можуть бути великими, беріть `long`.

## do-while

`do { ... } while (condition);` перевіряє умову **після** тіла, тож тіло виконується принаймні раз. Не забувайте крапку з комою наприкінці.

```csharp
int x = 10;
do
{
    x++;
}
while (x < 5);
Console.WriteLine(x);   // 11: тіло виконалося раз, хоч 10 < 5 хибне
```

## Граничні випадки для перевірки

- Цикл не має нічого робити, коли нічого робити не треба: нуль ітерацій (`n = 0`).
- Рівно одна ітерація.
- Гранична величина умови: чи зупиняється цикл на `n`, чи на один раніше?
- Найбільші вхідні дані. Чи достатньо це швидко і чи вміщується в тип?
