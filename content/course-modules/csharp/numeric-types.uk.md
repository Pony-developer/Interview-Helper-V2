C# — мова зі статичною типізацією: кожна змінна має тип, який фіксується під час оголошення.

```csharp
int count = 4;         // цілі числа
double price = 12.5;   // числа з дробовою частиною
var total = price * count; // компілятор виведе double
```

## Числові типи, які ви використовуватимете найчастіше

| Тип | Розмір | Зберігає | Літерал |
| --- | --- | --- | --- |
| `int` | 32 біти | цілі числа приблизно від −2,1 до 2,1 млрд | `42` |
| `long` | 64 біти | цілі числа приблизно до 9,2 × 10¹⁸ | `42L` |
| `double` | 64 біти | дробові числа, близько 15–16 значущих цифр | `4.2` |
| `float` | 32 біти | дробові числа, близько 7 значущих цифр | `4.2f` |
| `decimal` | 128 біт | точні десяткові дроби, для грошей | `4.2m` |

Літерал теж має тип: `4.2` — це `double`, тому `float f = 4.2;` не скомпілюється, а `float f = 4.2f;` — так.

## Цілочисельне ділення

Коли обидва операнди цілі, результат теж цілий, а дробова частина відкидається:

```csharp
Console.WriteLine(7 / 2);    // 3
Console.WriteLine(7 / 2.0);  // 3.5
Console.WriteLine(7 % 2);    // 1, остача
```

## Перетворення

Перетворення в тип, який вміщує будь-яке значення початкового, — **неявне**:

```csharp
int small = 1000;
long big = small;      // гаразд
double d = big;        // гаразд
```

Зворотне перетворення може втратити інформацію, тому C# вимагає **явного приведення**:

```csharp
double pi = 3.99;
int whole = (int)pi;                 // 3: дробова частина відкидається, а не округлюється
int nearest = (int)Math.Round(pi);   // 4
```

`int x = 10000L;` — помилка: `10000L` має тип `long`, а `long` не можна покласти в `int` без приведення, навіть якщо значення помістилося б.

## Переповнення

Арифметика з `int` тихо «перекручується», коли результат не вміщується:

```csharp
int max = int.MaxValue;
Console.WriteLine(max + 1); // -2147483648
```

Якщо обчислення може перевищити близько двох мільярдів, одразу беріть `long`.
