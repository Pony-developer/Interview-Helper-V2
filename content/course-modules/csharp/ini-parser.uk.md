Файли налаштувань трапляються скрізь, і їх читання — типове завдання для програми. У практичному запускачі файлів немає, тож текст файлу вам дають як рядок, а ви читаєте його **по рядках** через `StringReader`, точно так, як читали б справжній файл.

Формат — простий INI-файл:

```text
# settings
name = Assay
[server]
host = localhost
port = 8080

[user]
name = Ann
; a comment
 lang = uk 
oops, this line has no equals sign
[links]
url = http://x.org/?a=b
```

Реалізуйте `Parse(text)`. Він повертає `Dictionary<string, string>` із налаштуваннями.

Правила:

- Пробіли навколо рядка, ключа й значення ігноруються.
- **Порожні рядки** та **рядки-коментарі**, що починаються з `#` або `;`, пропускаються.
- Рядок `[name]` починає **секцію**. Ключі, що йдуть далі, зберігаються як `name.key`. До першої секції ключ зберігається без префікса.
- Рядок `key = value` розбивається за **першим** `=`, тож саме значення може містити `=`.
- Рядок, що не підходить під жодне з цього (без `=`), ігнорується.

`Main` розбирає наведений вище текст і друкує записи, відсортовані за ключем. `Main` не змінюйте. Очікуваний вивід:

```text
links.url = http://x.org/?a=b
name = Assay
server.host = localhost
server.port = 8080
user.lang = uk
user.name = Ann
```

Зверніть увагу, що `name` двічі трапляється в тексті: один раз без секції та один раз у `[user]`. Це різні ключі, `name` та `user.name`.

Підказка: `reader.ReadLine()` повертає `null` наприкінці тексту. `line.IndexOf('=')` дає позицію першого `=`, а `Substring` вирізає ключ і значення.
