## Завдання

Напишіть дві половини роботи з рядком запиту.

1. **`Query.Build(baseUrl, pairs)`**:
   - пропускайте пари зі значенням `null`;
   - екрануйте кожен ключ і значення через `Uri.EscapeDataString` (щоб `&`, `#`, пробіли й не-ASCII літери були закодовані);
   - з'єднайте їх як `key=value` через `&` і допишіть після `?`; якщо нічого не лишилося, поверніть `baseUrl` без змін (без зайвого `?`).
2. **`Query.Parse(url)`**:
   - візьміть текст після `?` і до `#`, якщо він є;
   - розбийте за `&`, ігноруючи порожні частини; кожну частину розділіть на **першому** `=` (частина без `=` отримує порожнє значення);
   - трактуйте `+` як пробіл, потім розекрануйте через `Uri.UnescapeDataString`;
   - зберігайте в словнику з ключами **без урахування регістру**; якщо ключ повторюється, перемагає останнє значення.

Очікуваний результат:

```
https://shop.test/search?q=C%23%20%26%20.NET&city=%D0%9A%D0%B8%D1%97%D0%B2&page=2
https://shop.test/
C# & .NET | Київ | 2 | 3
sort=name flag=''
shop.test /search https 443
```
