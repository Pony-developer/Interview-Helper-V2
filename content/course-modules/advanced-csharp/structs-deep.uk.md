## Що таке структура

`struct` — тип значення: змінні містять самі дані, а присвоєння їх копіює. Структури можуть мати поля, властивості, методи, конструктори та реалізовувати інтерфейси, але:

- не можуть наслідуватися від іншої структури чи класу (усі вони походять від `System.ValueType`), і від них ніхто не може наслідуватися;
- не мають фіналізатора;
- `default(MyStruct)` існує завжди: усі поля нульові/null, жоден конструктор не викликається.

```csharp
public struct Point
{
    public int X { get; set; }
    public int Y { get; set; }
    public Point(int x, int y) { X = x; Y = y; }
    public double Length => Math.Sqrt(X * X + Y * Y);
}
```

З C# 10 структура може мати власний конструктор без параметрів та ініціалізатори полів. Обережно: `default(Point)` і `new Point[10]` все одно цей конструктор пропускають.

## readonly struct

```csharp
public readonly struct Money
{
    public decimal Amount { get; }
    public string Currency { get; }
    public Money(decimal amount, string currency) { Amount = amount; Currency = currency; }
    public Money Add(Money other) => new Money(Amount + other.Amount, Currency);
}
```

Кожне поле мусить бути лише для читання. Переваги:

- незмінність гарантує компілятор;
- компілятор може передати її як `in` чи викликати її члени на `readonly`-полі **без захисних копій**.

Можна також позначати окремі члени `readonly` (C# 8), обіцяючи, що вони не змінюють стан.

## Пастка змінних структур

```csharp
var list = new List<Point> { new Point(1, 1) };
list[0].X = 5;          // помилка компіляції: list[0] повертає копію
var p = list[0]; p.X = 5;   // компілюється, але змінює лише копію
```

Ось чому типи значень загалом мають бути **незмінними**.

## ref struct

`ref struct` може жити **лише в стеку**. `Span<T>` і `ReadOnlySpan<T>` — ref-структури. Компілятор забороняє все, що могло б перенести таку структуру в купу:

- ні пакування, ні перетворення на `object` чи інтерфейс;
- ні полів такого типу в класах чи звичайних структурах;
- ні використання в `async`-методах, ітераторах чи лямбдах, що її захоплюють.

Натомість ref-структура може безпечно тримати посилання на стекову пам'ять чи на середину масиву.

## Record struct (C# 10)

```csharp
public readonly record struct Temperature(double Celsius);
```

Компілятор генерує конструктор, властивості, рівність за значенням, `ToString` і підтримку `with`.

## Коли обирати структуру

Обирайте структуру, коли виконується **все** з переліченого:

1. вона подає одне значення (координату, гроші, колір, проміжок часу);
2. вона невелика (як правило, 16 байтів чи менше);
3. вона незмінна;
4. її не пакуватимуть часто.

Інакше беріть клас. Велика змінна структура поєднує найгірше з обох світів: дорогі копії та несподівану семантику.

## Що сказати на співбесіді

- Структури копіюються при присвоєнні, не успадковуються і завжди мають нульовий `default`.
- Робіть структури `readonly`, щоб уникнути захисних копій і помилок зміни.
- `ref struct` (як `Span<T>`) живе лише в стеку — саме це робить її безпечною та швидкою.
