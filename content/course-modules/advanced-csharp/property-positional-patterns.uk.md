## Патерни властивостей (C# 8)

Патерн властивостей перевіряє, що значення **не null**, і що його властивості відповідають вкладеним патернам:

```csharp
if (order is { Status: OrderStatus.Paid, Total: > 1000 })
    FlagForReview(order);

if (person is { Address: { Country: "UA" } }) ...
if (person is { Address.Country: "UA" }) ...     // розширений патерн властивостей C# 10: те саме
```

Сам `{ }` означає «не null»: `if (x is { } nonNull)` — спосіб перевірити й назвати non-null значення.

Вкладені патерни можуть бути будь-якими: константи, реляційні, патерни типу, вкладені патерни властивостей чи `var` для захоплення:

```csharp
if (request is { Headers.Count: > 0, Body: string { Length: var len } } && len < 10_000) ...
```

## Позиційні патерни (C# 8)

Тип із методом `Deconstruct` (record, кортежі, ваші класи) можна зіставляти за позиціями:

```csharp
public record Point(int X, int Y);

string Quadrant(Point p) => p switch
{
    (0, 0) => "origin",
    (> 0, > 0) => "I",
    (< 0, > 0) => "II",
    (< 0, < 0) => "III",
    (> 0, < 0) => "IV",
    _ => "on an axis",
};
```

### Патерни кортежів

switch по кортежу робить рішення з кількома змінними компактними:

```csharp
string Play(string a, string b) => (a, b) switch
{
    ("rock", "scissors") or ("scissors", "paper") or ("paper", "rock") => "first wins",
    var (x, y) when x == y => "draw",
    _ => "second wins",
};
```

## switch-вирази на практиці

```csharp
decimal ShippingCost(Order o) => o switch
{
    { Total: >= 100 } => 0m,
    { Destination.Country: "UA", Weight: <= 1 } => 3m,
    { Destination.Country: "UA" } => 5m,
    { IsExpress: true } => 25m,
    _ => 15m,
};
```

Правила:

- гілки обчислюються **згори донизу**; перемагає перший збіг;
- компілятор попереджає, коли гілки не покривають усіх входів (не вичерпні), і видає помилку на гілки, що ніколи не спрацюють (поглинуті);
- вхід без збігу кидає `SwitchExpressionException` під час виконання;
- кожна гілка — вираз; щоб виконати інструкції, візьміть switch-інструкцію або викличте метод.

## Патерни проти поліморфізму

Зіставлення за типами — функціональний стиль: типи даних прості, а операції живуть у `switch`-виразах. Віртуальні методи — ООП-стиль: операції живуть у типах. Емпіричне правило:

- набір **типів фіксований**, а операцій стає дедалі більше (AST, набір команд, типи повідомлень) → патерни;
- **операції фіксовані**, а нові типи постійно з'являються (плагіни, UI-елементи) → віртуальні методи.

## Попередній огляд C# 11: патерни списків

Не в C# 10, але знати варто: `if (args is [var first, .., var last])` зіставляє масиви й списки за формою.

## Що сказати на співбесіді

- `{ Prop: патерн }` перевіряє non-null + значення властивостей; C# 10 дозволяє писати `A.B.C: value`.
- Позиційні патерни використовують `Deconstruct`; патерни кортежів поєднують кілька значень.
- switch-вирази: перемагає перший збіг, перевіряються вичерпність і недосяжні гілки.
