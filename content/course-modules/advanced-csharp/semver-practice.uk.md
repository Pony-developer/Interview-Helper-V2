## Завдання

`SemVer` моделює версії на кшталт `2.1.0` або `2.0.0-beta`. Зробіть його сортованим і придатним як ключ словника чи множини.

1. **`CompareTo(SemVer other)`**: порівняйте `Major`, потім `Minor`, потім `Patch` як числа (тож `1.10.0 > 1.2.0`). Якщо всі рівні:
   - тегу немає в жодної → рівні;
   - версія **з** тегом **менша** за ту саму версію без тегу (`2.0.0-beta < 2.0.0`);
   - два теги порівнюються через `string.CompareOrdinal`.
   - null `other` іде першим: поверніть додатне число.
2. **`Equals(SemVer)`**, **`Equals(object)`** і **`GetHashCode()`**: узгоджені з `CompareTo` (рівні саме тоді, коли порівняння дає 0).
3. Оператори **`<`** і **`>`**.

Далі `Main` сортує за природним порядком і власним `IComparer`, створеним через `Comparer<T>.Create`.

Очікуваний результат:

```
0.9.12 < 1.2.0-alpha < 1.2.0 < 1.10.0 < 2.0.0-alpha < 2.0.0-beta < 2.0.0
True
False
2
2.0.0, 1.10.0, 1.2.0, 0.9.12
```
