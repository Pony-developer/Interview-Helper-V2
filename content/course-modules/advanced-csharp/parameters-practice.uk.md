## Завдання

Допишіть три методи класу `Params`:

1. **`Swap<T>(ref T a, ref T b)`** міняє місцями дві змінні викликача. Має працювати для будь-якого типу.
2. **`TryParsePoint(string text, out int x, out int y)`** розбирає текст на кшталт `"3,4"` або `" 10 , -2 "` (пробіли навколо чисел дозволені). У разі успіху присвоює `x` і `y` та повертає `true`. На будь-якому некоректному вході (не рівно дві частини, або частина — не число) повертає `false` і присвоює **обом** `x` та `y` значення `0`. Пам'ятайте: `out`-параметр має бути присвоєний на кожному шляху.
3. **`Sum(params int[] values)`** повертає суму аргументів, `0`, коли їх немає.

Очікуваний результат:

```
a=2 b=1
right left
'3,4' -> True (3, 4)
' 10 , -2 ' -> True (10, -2)
'7' -> False (0, 0)
'x,1' -> False (0, 0)
0
5
10
30
```
