## char і string

- `char` — одна **кодова одиниця UTF-16** (16 бітів). Символи поза базовою багатомовною площиною, як-от більшість емодзі, займають *два* `char` (сурогатна пара).
- `string` — незмінна послідовність `char`. Кожна «зміна» (`Replace`, `+`, `ToUpper`) повертає **новий** рядок.
- `string` — тип посилання, але `==` порівнює **вміст**, бо оператор перевантажено.

### Літерали

```csharp
string path1 = "C:\\temp\\log.txt";   // escape-послідовності
string path2 = @"C:\temp\log.txt";    // дослівний: зворотні скісні — буквальні, "" означає лапку
string msg   = $"Total: {total:C2}";   // інтерпольований із рядком формату
string both  = $@"Folder: {dir}\logs"; // інтерпольований + дослівний
```

C# 10 дозволяє **константні інтерпольовані рядки**, коли всі частини — константи:

```csharp
const string Product = "Shop";
const string Title = $"{Product} admin";   // працює в C# 10
```

### Складання рядків у циклах

Оскільки рядки незмінні, `s += x` у циклі щоразу копіює весь рядок: O(n²). Використовуйте `StringBuilder` (або `string.Join`, `string.Concat`).

## Масиви

Масив — це блок елементів одного типу фіксованого розміру з індексацією від нуля. Масиви завжди є типами посилань, навіть масив структур.

```csharp
int[] numbers = { 5, 3, 8 };
var names = new string[3];        // { null, null, null }
var points = new Point[1000];     // 1000 структур підряд: одна алокація
```

Кожен доступ **перевіряє межі**; індекс поза діапазоном кидає `IndexOutOfRangeException`. JIT прибирає перевірку, коли може довести, що індекс безпечний, наприклад у простому циклі `for (i = 0; i < a.Length; i++)`.

### Прямокутні та зубчасті

```csharp
int[,] grid = new int[3, 4];          // один блок, 3 рядки x 4 стовпці
grid[1, 2] = 7;
int rows = grid.GetLength(0);         // 3

int[][] jagged = new int[3][];        // 3 окремі масиви, створюються пізніше
jagged[0] = new int[] { 1 };
jagged[1] = new int[] { 1, 2, 3 };    // рядки різної довжини
```

### Індекси та діапазони (C# 8)

```csharp
int[] a = { 10, 20, 30, 40, 50 };
int last = a[^1];         // 50: ^1 означає «перший з кінця»
int[] mid = a[1..4];      // { 20, 30, 40 }: початок включно, кінець виключно
int[] tail = a[2..];      // { 30, 40, 50 }
```

Діапазон на масиві створює **копію**. На `Span<T>` він створює **представлення** без копіювання, тому спани використовують у коді, чутливому до продуктивності.

## Що сказати на співбесіді

- Рядки незмінні; у циклах збирайте їх через `StringBuilder`.
- `char` — це UTF-16, тож `"😀".Length` дорівнює 2.
- `int[,]` прямокутний, `int[][]` зубчастий; діапазони копіюють масиви, але нарізають спани.
