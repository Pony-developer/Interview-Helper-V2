## Завдання

Реалізуйте **`Importer.ImportAllAsync(files, importOne, progress, token)`** за домовленостями TAP:

1. Обробляйте файли **по черзі**, очікуючи `importOne(file, token)` для кожного й підсумовуючи повернуту кількість рядків.
2. **Перед** кожним файлом викликайте `token.ThrowIfCancellationRequested()`, щоб скасований імпорт зупинявся з `OperationCanceledException`.
3. **Після** кожного файлу звітуйте прогрес як `completed * 100 / total` через `progress` (який може бути null).
4. Поверніть загальну кількість рядків.

`Main` спершу виконує повний імпорт, потім другий, обробник прогресу якого скасовує токен, щойно досягнуто 50%: третій файл не має навіть почати оброблятися.

`SyncProgress<T>` звітує синхронно в потоці, що викликає, тож консольний вивід лишається впорядкованим. У UI-застосунку ви б використали `Progress<T>`, що повертає звіти в потік UI.

Очікуваний результат:

```
progress 25%
progress 50%
progress 75%
progress 100%
rows 200
progress 25%
progress 50%
import cancelled
```
