## Завдання

Спроєктуйте невеликий двійковий формат файлу для показів датчиків через `BinaryWriter`/`BinaryReader`.

**Формат**: 4 ASCII-байти `SNS1` (магічний заголовок), `int32` з кількістю записів, далі для кожного показу: `Sensor` як рядок із префіксом довжини (`BinaryWriter.Write(string)`), `Time.Ticks` як `int64`, `Value` як `double`, `Alarm` як `bool`.

1. **`Write(stream, readings)`** записує формат. Створюйте писача з `leaveOpen: true` (і `Encoding.UTF8`), бо потік належить викликачу, який хоче потім прочитати його назад.
2. **`Read(stream)`** читає його назад, точно в тому самому порядку й тих самих типах. Якщо перші 4 байти — не `SNS1`, киньте `InvalidDataException("Not a sensor file")`. Тут теж `leaveOpen: true`.

Зверніть увагу, як кирилична назва датчика переживає цикл запису й читання: у префіксі зберігається довжина рядка в байтах (UTF-8), а не кількість символів.

Очікуваний результат:

```
bytes: 88, position: 88
temp-1 10:00:00 21.5
temp-2 10:00:05 87.25 ALARM
датчик-3 10:01:00 -4
stream still open: True
Not a sensor file
```
