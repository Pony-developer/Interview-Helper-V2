## Завдання

Порахуйте частоти слів у багатьох документах **паралельно**.

Реалізуйте **`WordCount.Top(documents, n)`**:

1. Використайте `Parallel.ForEach` по документах.
2. Розбийте кожен документ на слова: послідовності літер у нижньому регістрі (`char.IsLetter`, `char.ToLowerInvariant`); усе інше — роздільники.
3. Рахуйте у спільному **`ConcurrentDictionary<string, int>`** через атомарний `AddOrUpdate(word, 1, (_, c) => c + 1)`. (Звичайний `Dictionary` тут зіпсував би себе; `d[w] = d[w] + 1` на `ConcurrentDictionary` губив би оновлення.)
4. Після циклу поверніть перші `n` записів у вигляді `"word=count"`, упорядкувавши за кількістю **за спаданням**, а при нічиїй — за словом (ординально).

Очікуваний результат:

```
the=1600
dog=800
fox=800
lazy=800
quick=700
```
