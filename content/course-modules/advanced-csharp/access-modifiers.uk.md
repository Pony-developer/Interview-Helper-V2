## Шість рівнів

| Модифікатор | Доступний з |
| --- | --- |
| `public` | будь-якого місця |
| `internal` | тієї самої збірки (проєкту) |
| `protected` | класу, що його оголошує, і похідних від нього класів |
| `protected internal` | тієї самої збірки **або** похідних класів будь-де (об'єднання) |
| `private protected` (C# 7.2) | похідних класів **у тій самій збірці** (перетин) |
| `private` | лише типу, що його оголошує |

```csharp
public class Engine
{
    private int _rpm;                       // лише Engine
    protected void Ignite() { }             // Engine і підкласи
    internal void Calibrate() { }           // будь-що в цій збірці
    private protected void Tune() { }       // лише підкласи в цій збірці
}
```

## Значення за замовчуванням

- Члени класу чи структури: **`private`**.
- Типи верхнього рівня (не вкладені): **`internal`**.
- Члени інтерфейсу: `public` (C# 8+ дозволяє інші модифікатори для реалізацій за замовчуванням).
- Члени enum: завжди `public`.

Писати модифікатор явно — добра звичка, навіть коли він збігається із замовчуванням.

## Правила, які перевіряє компілятор

- Тип не може відкривати менш доступний тип у своїй публічній сигнатурі: `public`-метод не може повертати `internal`-клас.
- Перевизначення мусить зберігати ту саму доступність, що й перевизначений член.
- Підклас може бути менш доступним за базовий, але не більш: `internal class B : PublicBase` — можна, `public class B : InternalBase` — ні.

## Дружні збірки

```csharp
[assembly: InternalsVisibleTo("Shop.Billing.Tests")]
```

Це дає тестовому проєкту бачити `internal`-члени, тож не треба робити щось `public` лише для тестів. Для підписаних збірок додайте публічний ключ.

## Інкапсуляція на практиці

- Тримайте поля `private`; відкривайте поведінку через методи та властивості.
- Використовуйте `private set` чи `init` замість публічних сеттерів, коли викликачі не мають змінювати стан.
- Повертайте представлення лише для читання (`IReadOnlyList<T>`, `ReadOnlyCollection<T>`) замість внутрішнього `List<T>`, інакше викликачі зможуть додавати й видаляти елементи у вас за спиною.

```csharp
private readonly List<OrderLine> _lines = new();
public IReadOnlyList<OrderLine> Lines => _lines;
public void AddLine(OrderLine line) { Validate(line); _lines.Add(line); }
```

## Що сказати на співбесіді

- `protected internal` — це АБО, `private protected` — це І.
- Члени класу за замовчуванням `private`, типи верхнього рівня — `internal`.
- Для тестів використовуйте `InternalsVisibleTo`, а не розширюйте доступ.
