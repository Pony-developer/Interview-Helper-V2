## Що стоїть над BCL

CLR і BCL дають універсальну платформу. Прикладні шари додають API для певного *виду* програм.

### Веб і сервіси: ASP.NET Core

- **Minimal API та MVC-контролери** для HTTP API.
- **Razor Pages і MVC-представлення** для HTML, що рендериться на сервері.
- **Blazor**: UI-компоненти на C#. *Blazor Server* виконує їх на сервері й синхронізує DOM через з'єднання SignalR; *Blazor WebAssembly* запускає сам рантайм .NET у браузері.
- **gRPC** і **SignalR** для RPC та push-повідомлень у реальному часі.

ASP.NET Core кросплатформний, працює за власним швидким веб-сервером (Kestrel) і побудований навколо dependency injection та конвеєра middleware.

### Десктоп

| Шар | Платформа | Примітки |
| --- | --- | --- |
| **Windows Forms** | Windows | Найстаріший і найпростіший UI з дизайнером. Досі поширений для внутрішніх інструментів. |
| **WPF** | Windows | XAML, прив'язування даних, стилі та шаблони; векторний рендеринг. |
| **WinUI 3** | Windows 10+ | Сучасний нативний UI-стек Windows. |
| **.NET MAUI** | Windows, macOS, Android, iOS | Одна кодова база на XAML/C# для десктопу й мобільних; наступник Xamarin.Forms. |

WPF і Windows Forms працюють на сучасному .NET, але лишаються лише для Windows, тому їхні проєкти націлюються на `net6.0-windows`.

### Дані та хмара

- **Entity Framework Core**: ORM, що перетворює LINQ-запити на SQL.
- **Worker services**: довготривалі фонові процеси з тією самою моделлю хостингу та DI, що й ASP.NET Core.
- **Azure Functions** та інші serverless-хости виконують .NET-код на кожну подію.

### Ігри та інше

- **Unity** виконує C#-скрипти на власному рантаймі на базі Mono/IL2CPP.
- **ML.NET** для машинного навчання, **Orleans** для розподілених систем акторів.

## Як обрати (типове питання на співбесіді)

- HTTP API чи веб-сайт → ASP.NET Core.
- Бізнесовий десктоп-застосунок лише для Windows → WPF (або WinForms для чогось невеликого).
- Один застосунок для телефонів і десктопу → .NET MAUI.
- Фонова обробка → worker service або Azure Functions.

## Що сказати на співбесіді

- *Мова* та BCL спільні; прикладний шар визначає модель хостингу, UI-технологію та охоплення платформ.
- Кросплатформні: ASP.NET Core, MAUI, Blazor. Лише Windows: WPF, WinForms, WinUI.
