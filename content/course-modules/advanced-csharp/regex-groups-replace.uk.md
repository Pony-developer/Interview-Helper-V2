## Захоплювальні групи

Дужки групують частину шаблону й **захоплюють** те, з чим вона збіглася:

```csharp
Match m = Regex.Match("Order #1042 for 99.50 EUR", @"#(\d+) for (\d+\.\d{2}) (\w{3})");
string id = m.Groups[1].Value;        // 1042
string amount = m.Groups[2].Value;    // 99.50
string currency = m.Groups[3].Value;  // EUR
// Groups[0] — увесь збіг
```

**Іменовані групи** зрозуміліші й переживають правки шаблону:

```csharp
var rx = new Regex(@"#(?<id>\d+) for (?<amount>\d+\.\d{2}) (?<cur>[A-Z]{3})");
Match m2 = rx.Match(text);
if (m2.Success)
{
    int id = int.Parse(m2.Groups["id"].Value);
    decimal amount = decimal.Parse(m2.Groups["amount"].Value, CultureInfo.InvariantCulture);
}
```

- `(?:...)` групує **без** захоплення (для альтернатив чи квантифікаторів): `(?:https?|ftp)://`.
- Необов'язкова група, що не брала участі, має `Success == false` і порожнє `Value`: перевіряйте `Success` перед розбором.
- Група під квантифікатором зберігає кожне повторення в `Group.Captures`.
- **Зворотні посилання** знову збігаються з тим самим текстом: `\b(\w+)\s+\1\b` знаходить подвоєні слова («the the»); іменоване: `\k<word>`.

## Заміна

```csharp
// шаблони заміни: $1, ${name}, $0 (увесь збіг), $$ (буквальний $)
string iso = Regex.Replace("05.03.2024", @"(?<d>\d{2})\.(?<m>\d{2})\.(?<y>\d{4})", "${y}-${m}-${d}");   // 2024-03-05

// MatchEvaluator обчислює кожну заміну в коді
string masked = Regex.Replace(log, @"\b\d{12}(\d{4})\b", m => new string('*', 12) + m.Groups[1].Value);

string doubled = Regex.Replace("price 10, tax 2", @"\d+", m => (int.Parse(m.Value) * 2).ToString());   // price 20, tax 4
```

Використовуйте `${name}` з дужками, коли за назвою чи номером групи йдуть цифри (`${1}0` проти `$10`).

## Розбиття

```csharp
string[] fields = Regex.Split("pens ,ink;;  pads", @"\s*[,;]+\s*");   // pens | ink | pads
string[] keep = Regex.Split("a1b2c", @"(\d)");                          // a | 1 | b | 2 | c: захоплені роздільники включаються
```

Для простих односимвольних роздільників `string.Split` швидший; `Regex.Split` — коли роздільники різні.

## Невелика книга рецептів

| Задача | Шаблон |
| --- | --- |
| стиснути пробіли | `\s+` → `" "` |
| обрізати кожен рядок | `(?m)^\s+|\s+$` → `""` |
| подвоєні слова | `\b(\w+)\s+\1\b` |
| проста перевірка e-mail | `^[^@\s]+@[^@\s]+\.[^@\s]+$` (справжня перевірка — надіслати лист підтвердження) |
| дата ISO | `^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$` |
| пари key=value | `(?<key>\w+)=(?<value>[^;]*)` |
| camelCase у слова | `(?<=[a-z])(?=[A-Z])` → `" "` |

Не розбирайте HTML, JSON чи XML регулярними виразами: використовуйте справжній парсер.

## Що сказати на співбесіді

- `( )` захоплює, `(?<name> )` дає назву, `(?: )` лише групує; перевіряйте `Group.Success`.
- Шаблони заміни використовують `$1`/`${name}`; `MatchEvaluator` обчислює заміни в коді.
- `Regex.Split` справляється з різними роздільниками; захоплені роздільники зберігаються.
