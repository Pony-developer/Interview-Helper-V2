## Завдання

`Resources` зберігає рядки за назвою культури, де `""` означає інваріантні (нейтральні) ресурси, ті, що живуть в основній збірці. Реалізуйте **`Get(key, culture)`** так, щоб він поводився як `ResourceManager` із сателітними збірками:

1. Почніть із заданої культури й підіймайтеся її **ланцюжком батьків** через `CultureInfo.Parent`: `uk-UA` → `uk` → інваріантна (її `Name` — `""`). Батько інваріантної культури — вона сама, тож зупиніться після її перевірки.
2. На кожному кроці, якщо для цієї назви культури є таблиця і вона містить ключ, поверніть значення.
3. Якщо нічого не знайдено ніде, поверніть `"[key]"` (дужки роблять відсутні переклади помітними на екрані).

Зверніть увагу: `de-AT` знаходить `Warenkorb` через батька `de`, а `fr-FR` не має французьких ресурсів і відкочується до нейтральних англійських.

Останній рядок `Main` розбирає повне ім'я збірки через `AssemblyName`.

Очікуваний результат:

```
uk-UA: Вітаємо / Кошик / Checkout / [Missing]
uk: Привіт / Кошик / Checkout / [Missing]
de-AT: Hello / Warenkorb / Checkout / [Missing]
fr-FR: Hello / Cart / Checkout / [Missing]
Shop.Core 2.1.0.7 major=2 culture=''
```
