## Квантифікатори

| Квантифікатор | Значення |
| --- | --- |
| `*` | 0 чи більше |
| `+` | 1 чи більше |
| `?` | 0 або 1 (необов'язково) |
| `{n}` | рівно n |
| `{n,}` | n чи більше |
| `{n,m}` | від n до m |

```csharp
Regex.IsMatch("colour", @"^colou?r$");          // u необов'язкова
Regex.IsMatch("2024-3-5", @"^\d{4}-\d{1,2}-\d{1,2}$");
```

Квантифікатор діє на один елемент перед ним: символ, клас чи групу в дужках: `(ab)+` повторює `ab`.

## Жадібні проти лінивих

За замовчуванням квантифікатори **жадібні**: беруть якомога більше, а потім віддають назад (бектрекінг), лише якщо решта шаблону не збігається. Додавання `?` робить їх **лінивими**: якомога менше.

```csharp
string html = "<b>one</b> and <b>two</b>";
Regex.Match(html, "<b>.*</b>").Value;    // "<b>one</b> and <b>two</b>": жадібний біжить до ОСТАННЬОГО </b>
Regex.Match(html, "<b>.*?</b>").Value;   // "<b>one</b>": лінивий зупиняється на ПЕРШОМУ </b>
```

Часто ще кращий вибір — заперечений клас, що не може проскочити далі: `<b>[^<]*</b>`.

## Твердження нульової ширини

Твердження перевіряють умову в **позиції**, не поглинаючи символів.

| Твердження | Виконується там, де |
| --- | --- |
| `^`, `$`, `\A`, `\z` | початок/кінець вводу (або рядка в режимі Multiline) |
| `\b` | межа слова (між `\w` і `\W`) |
| `\B` | не межа слова |
| `(?=...)` | **lookahead**: те, що далі, збігається |
| `(?!...)` | **негативний lookahead**: те, що далі, не збігається |
| `(?<=...)` | **lookbehind**: те, що перед, збігається |
| `(?<!...)` | **негативний lookbehind** |

```csharp
// лише цілі слова
Regex.Matches("cat concatenate cat.", @"\bcat\b").Count;   // 2

// правило пароля: 8+ символів, хоча б одна цифра й одна велика літера
Regex.IsMatch(pwd, @"^(?=.*\d)(?=.*[A-Z]).{8,}$");

// число ціни після знака валюти, не захоплюючи сам знак
Regex.Match("Total: $42.50", @"(?<=\$)\d+(\.\d{2})?").Value;   // 42.50

// "error", за яким не йде "-free"
Regex.IsMatch(text, @"\berror\b(?!-free)");
```

Lookahead — стандартний спосіб виразити кілька незалежних умов («містить цифру І велику літеру») в одному шаблоні. .NET підтримує **lookbehind змінної довжини**, чого не вміють багато інших рушіїв.

## Опції, що змінюють зіставлення

| Опція | Вбудовано | Ефект |
| --- | --- | --- |
| `IgnoreCase` | `(?i)` | без урахування регістру |
| `Multiline` | `(?m)` | `^`/`$` збігаються на початках/кінцях рядків |
| `Singleline` | `(?s)` | `.` збігається й з `\n` |
| `IgnorePatternWhitespace` | `(?x)` | дозволити пробіли й коментарі `#` у шаблоні |
| `ExplicitCapture` | `(?n)` | захоплюють лише іменовані групи |

```csharp
var phone = new Regex(@"
    ^\+?(?<country>\d{1,3})?   # необов'язковий код країни
    [\s-]?\(?(?<area>\d{3})\)? # код регіону, можливо в дужках
    [\s-]?(?<number>\d{3}[\s-]?\d{4})$", RegexOptions.IgnorePatternWhitespace);
```

## Що сказати на співбесіді

- `*`, `+`, `?`, `{n,m}` кількісно визначають елемент перед ними; за замовчуванням жадібні, ліниві з завершальним `?`.
- `\b` і lookaround перевіряють позиції, не поглинаючи текст.
- Lookahead поєднують незалежні умови; `IgnorePatternWhitespace` робить складні шаблони читабельними.
