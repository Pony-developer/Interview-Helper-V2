## Завдання

Перереалізуйте три оператори LINQ як **ітератори**, щоб на власні очі побачити відкладене потокове виконання. Кожен з них логує, що робить.

1. **`MyWhere(predicate)`**: для кожного елемента джерела надрукуйте `where <item>`, потім віддайте його, якщо предикат істинний.
2. **`MySelect(selector)`**: для кожного елемента джерела надрукуйте `select <item>`, потім віддайте спроєктоване значення.
3. **`MyTake(count)`**: віддайте перші `count` елементів і **перестаньте тягнути** з джерела (`yield break` одразу після останнього, не просячи в джерела ще один елемент).

Уважно подивіться на очікуваний результат:

- першим іде `query built`: під час створення запиту нічого не виконується.
- `8` з'являється, хоча його вставили **після** побудови запиту: відкладене виконання бачить поточний список.
- Елементи проходять по одному через усі три оператори (`where 8`, `select 8`, `got 80`), а перелічення зупиняється після двох результатів, тож 3–6 ніхто навіть не переглядає.
- `Count()` перелічує запит **ще раз**, тож усе логування повторюється.

Очікуваний результат:

```
query built
where 8
select 8
got 80
where 1
where 2
select 2
got 20
where 8
select 8
where 1
where 2
select 2
count again: 2
```
