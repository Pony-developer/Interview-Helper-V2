## Завдання

Реалізуйте маленьку мову тривалостей поверх `TimeSpan`.

1. **`Durations.Parse(text)`** читає рядки на кшталт `"1d 2h 30m 15s"`: числа, за якими йде одиниця `d`, `h`, `m` чи `s`, у будь-якому порядку й наборі, пробіли необов'язкові (`"2h0m"` коректний). Додайте частини через `TimeSpan.FromDays/FromHours/...`. Невідома одиниця кидає `FormatException` з повідомленням `Unknown unit 'w'`; відсутнє число чи одиниця теж кидають `FormatException`.
2. **`Durations.Format(t)`** записує той самий формат назад, пропускаючи нульові частини: `01:30:00` стає `1h 30m`. `TimeSpan.Zero` стає `0s`. Використовуйте властивості-компоненти `Days`, `Hours`, `Minutes`, `Seconds` (а не `TotalHours`!).

Останні два рядки `Main` показують арифметику дат: додавання місяця до 30 січня високосного року обрізається до 29 лютого, а різниця дат дає `TimeSpan`.

Очікуваний результат:

```
1d 2h 30m 15s => 1.02:30:15 => 1d 2h 30m 15s
90m => 01:30:00 => 1h 30m
45s 1h => 01:00:45 => 1h 45s
2h0m => 02:00:00 => 2h
0s
error: Unknown unit 'w'
2024-02-29
31
```
