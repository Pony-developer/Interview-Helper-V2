## Завдання

Зберігайте паролі правильно: ніколи не сам пароль, а повільний посолений хеш **PBKDF2** у форматі `iterations.saltBase64.hashBase64`.

1. **`Hash(password, salt, iterations)`**: виведіть `HashSize` (32) байтів через `new Rfc2898DeriveBytes(password, salt, iterations)` і `GetBytes` та поверніть три частини, з'єднані крапками. (Сіль передається лише для того, щоб демонстрацію можна було повторити; справжній код створює її через `RandomNumberGenerator` для кожного пароля.)
2. **`Verify(password, stored)`**: розділіть збережений рядок (поверніть false, якщо в ньому не три частини), декодуйте сіль і очікуваний хеш, **перерахуйте** хеш з тією самою сіллю й кількістю ітерацій і порівняйте **за сталий час** (XOR-акумулятор).

Зберігання кількості ітерацій разом із кожним хешем дозволяє згодом її підвищити, не зламавши наявних користувачів.

Примітка щодо сучасного .NET: перевагу варто віддавати статичному `Rfc2898DeriveBytes.Pbkdf2(password, salt, iterations, HashAlgorithmName.SHA256, 32)` (.NET 6) із сотнями тисяч ітерацій; ця практика використовує конструктор, бо він доступний у рантаймі практики.

Очікуваний результат:

```
1000.AAcOFRwjKjE4P0ZNVFtiaQ==.1J2KlD7qO87UDBt2QbRivPmScPCoWtFU5OYJW3THxgI=
True
False
same hash with another salt: False
True
```
