## Анонімні типи

```csharp
var person = new { Name = "Ann", Age = 31 };
Console.WriteLine(person.Name);   // Ann
Console.WriteLine(person);        // { Name = Ann, Age = 31 }

var name = "Bob"; var age = 25;
var other = new { name, age };    // назви властивостей виведено: { name = Bob, age = 25 }
```

Компілятор генерує **клас** з:

- властивостями лише для читання (анонімні типи незмінні, хоча з C# 10 для них працює `with`);
- `Equals` і `GetHashCode` за значеннями всіх властивостей;
- зручним `ToString`.

Два вирази анонімних об'єктів з однаковими назвами й типами властивостей в однаковому порядку в одній збірці мають **один** згенерований тип.

Їхнє основне місце — проєкції LINQ:

```csharp
var summary = orders.Select(o => new { o.Id, o.Customer.Name, Total = o.Lines.Sum(l => l.Price) });
```

Обмеження: тип не має імені, яке можна написати, тож він не може з'явитися в сигнатурі методу, полі чи властивості. Повернення через `object` чи `dynamic` втрачає статичну типізацію. Коли дані мають вийти за межі методу, беріть кортеж або record.

## Кортежі-значення (C# 7)

```csharp
(string Name, int Age) p = ("Ann", 31);
Console.WriteLine(p.Name);              // іменований елемент
Console.WriteLine(p.Item2);             // базова назва поля теж працює

var q = (Name: "Bob", Age: 25);         // назви в літералі
var r = ("Cat", 4);                     // без назв: Item1, Item2
```

Кортежі — це `System.ValueTuple<...>`: **змінні типи значень**. Назви елементів — зручність часу компіляції; під час виконання вони стираються (рефлексія бачить `Item1`, `Item2`).

### Повернення кількох значень

```csharp
static (int Min, int Max) Range(int[] values) { /* ... */ return (min, max); }

var (lo, hi) = Range(data);             // деконструкція у дві змінні
(int lo2, _) = Range(data);             // відкинути непотрібне
```

Це чистіше за `out`-параметри, особливо в async-методах (які не можуть мати `out`).

### Рівність та інші трюки

```csharp
Console.WriteLine((1, "a") == (1, "a"));     // True: поелементно (C# 7.3)
(a, b) = (b, a);                             // обмін без тимчасової змінної
var dict = new Dictionary<(int, int), string>();   // кортеж як складений ключ: рівність за значенням + добрий хеш
```

## Анонімний тип, кортеж чи record?

| Потреба | Що брати |
| --- | --- |
| Тимчасова форма даних усередині методу, особливо в LINQ-запиті, що може стати SQL | анонімний тип |
| Повернути два-три значення з private/internal методу | кортеж |
| Дані, що перетинають межі API, потребують назви, документації чи поведінки | `record` або клас |

Кортежі в публічних API припустимі, але швидко стають незрозумілими: `(string, string, int)` каже набагато менше, ніж `CustomerSummary`.

## Що сказати на співбесіді

- Анонімні типи: згенеровані компілятором незмінні класи з рівністю за значенням; лише для локального використання.
- Кортежі: змінні структури `ValueTuple`; назви існують лише під час компіляції; чудові для кількох результатів і деконструкції.
- Коли дані заслуговують на назву — беріть record.
