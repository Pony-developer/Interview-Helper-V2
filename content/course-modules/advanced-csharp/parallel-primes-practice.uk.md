## Завдання

Два класичні патерни паралелізму даних.

1. **`CountParallel(from, to)`** рахує прості числа в `[from, to)` через перевантаження `Parallel.For` з **локальним станом потоку**:
   - `localInit: () => 0L` дає кожному робітнику власну проміжну суму;
   - тіло повертає `local + 1`, коли `IsPrime(i)`, інакше `local`;
   - `localFinally` додає проміжну суму кожного робітника до спільного результату через `Interlocked.Add`.

   Оновлення одного спільного лічильника з кожної ітерації було б гонкою (або, з lock, повільно). Результат має дорівнювати послідовному підрахунку.

2. **`FirstPrimes(start, count)`** повертає перші `count` простих чисел `>= start`, **по порядку**, через PLINQ: `Enumerable.Range(...)` → `AsParallel()` → `AsOrdered()` → `Where(IsPrime)` → `Take(count)` → `ToList()`. Без `AsOrdered()` п'ять отриманих простих чисел можуть бути не найменшими й повернутися в будь-якому порядку.

Очікуваний результат:

```
primes up to 200000: 17984 (sequential 17984)
1000003, 1000033, 1000037, 1000039, 1000081
```
