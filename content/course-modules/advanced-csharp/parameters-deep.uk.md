## За замовчуванням — за значенням

Без модифікатора аргумент **копіюється** в параметр. Для типу значення це копія даних; для типу посилання — копія *посилання*, тож метод може змінити вміст об'єкта, але не може змусити змінну викликача вказувати на інший об'єкт.

```csharp
void Reset(StringBuilder sb) { sb.Clear(); sb = new StringBuilder("x"); }
var b = new StringBuilder("hello");
Reset(b);
Console.WriteLine(b.Length);   // 0: Clear() змінив наш об'єкт, а перепризначення — ні
```

## Модифікатори

| Модифікатор | Передається | Викликач має присвоїти до виклику? | Метод мусить присвоїти? | Метод може змінювати? |
| --- | --- | --- | --- | --- |
| *(немає)* | за значенням | так | ні | свою копію |
| `ref` | за посиланням | **так** | ні | так, і викликач це бачить |
| `out` | за посиланням | ні | **так**, до повернення | так |
| `in` | за посиланням (лише читання) | так | ні | **ні** |

```csharp
static void Swap(ref int a, ref int b) { int t = a; a = b; b = t; }

if (int.TryParse(text, out int value))   // out var: оголошення просто у виклику
    Console.WriteLine(value);

_ = int.TryParse(text, out _);           // відкинути out-значення, яке не потрібне

static double Length(in Vector3 v) => Math.Sqrt(v.X * v.X + v.Y * v.Y + v.Z * v.Z);
```

`in` існує заради продуктивності: велика структура передається за посиланням без копіювання, а метод обіцяє її не змінювати. Якщо структура не `readonly`, виклик її методу все ще може створити приховану *захисну копію*; позначка `readonly` на структурі цього уникає.

## params

```csharp
static int Max(params int[] values) { /* ... */ }
Max(3, 9, 4);          // масив будує компілятор
Max(new[] { 3, 9 });   // або ви передаєте його самі
Max();                 // порожній масив, не null
```

`params` має бути останнім параметром, і він може бути лише один.

## Необов'язкові та іменовані параметри

```csharp
void Log(string message, int level = 1, bool timestamp = true) { }

Log("start");                         // level = 1, timestamp = true
Log("disk full", timestamp: false);   // пропустити параметр, назвавши наступний
Log(level: 3, message: "boom");       // іменовані аргументи в будь-якому порядку
```

Значення за замовчуванням **вшиваються у викликача** під час компіляції. Якщо бібліотека змінить значення за замовчуванням, код, скомпільований зі старою версією, користуватиметься старим значенням, доки його не перекомпілюють.

## ref-локальні змінні та ref-повернення

```csharp
ref int FindSlot(int[] array, int value)
{
    for (int i = 0; i < array.Length; i++)
        if (array[i] == value) return ref array[i];
    throw new InvalidOperationException();
}

int[] data = { 1, 2, 3 };
ref int slot = ref FindSlot(data, 2);
slot = 20;                     // пише прямо в data[1]
```

## var

`var` означає «виведи тип з ініціалізатора». Змінна все одно статично типізована; `var x = 5;` назавжди `int`. Використовуйте, коли тип очевидний з правої частини.

## Що сказати на співбесіді

- Типи посилань теж передаються *за значенням*: копіюється посилання. `ref` передає саму змінну.
- `out` мусить присвоїти той, кого викликають; `ref` — той, хто викликає; `in` — посилання лише для читання.
- Значення параметрів за замовчуванням компілюються в місце виклику.
