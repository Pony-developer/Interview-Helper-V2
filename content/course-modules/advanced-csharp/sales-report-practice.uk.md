## Завдання

`Data` містить чотирьох клієнтів і чотири замовлення, кожне з рядками. Напишіть п'ять методів звіту на LINQ, без циклів:

1. **`TotalRevenue()`**: сума `Qty * Price` за всіма рядками всіх замовлень (`SelectMany` + `Sum`).
2. **`RevenueByCity()`**: виручка за містом клієнта, від найбільшої, у вигляді `"City: amount"`. Міста без замовлень не з'являються. (`Join` замовлень з клієнтами, `GroupBy` за містом, `Sum`, `OrderByDescending`.)
3. **`UnitsPerProduct()`**: загальна кількість на продукт, упорядковано за назвою продукту, у вигляді `"Product x Qty"`.
4. **`OrdersPerCustomer()`**: **кожен** клієнт з кількістю замовлень, включно з клієнтами без замовлень (це ліве зовнішнє з'єднання: `GroupJoin`), упорядковано за іменем, у вигляді `"Name: N"`.
5. **`KyivMonths()`**: унікальні місяці (`yyyy-MM`), у які клієнт з Києва зробив замовлення, за зростанням.

Очікуваний результат:

```
Total: 94.5
Kyiv: 82.5
Lviv: 12
Ink x 8, Pad x 4, Pen x 15
Ann: 2, Bob: 1, Cid: 1, Dee: 0
2024-01, 2024-02
```
