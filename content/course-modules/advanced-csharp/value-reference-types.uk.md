## Два різновиди типів

Кожен тип C# — або **тип значення**, або **тип посилання**. Від цього залежить, що означають присвоєння, рівність і `null`.

| | Типи значень | Типи посилань |
| --- | --- | --- |
| Приклади | `int`, `double`, `bool`, `char`, `decimal`, `DateTime`, будь-яка `struct`, будь-який `enum` | `string`, масиви, будь-який `class`, `interface`, `delegate`, `record` (клас) |
| Змінна містить | самі дані | посилання (адресу) на об'єкт |
| Присвоєння копіює | усе значення | лише посилання; обидві змінні бачать той самий об'єкт |
| Може бути `null` | ні (якщо не `Nullable<T>`, тобто `T?`) | так |

```csharp
struct PointS { public int X; }
class  PointC { public int X; }

var s1 = new PointS { X = 1 };
var s2 = s1;          // копія
s2.X = 9;
Console.WriteLine(s1.X);   // 1

var c1 = new PointC { X = 1 };
var c2 = c1;          // той самий об'єкт
c2.X = 9;
Console.WriteLine(c1.X);   // 9
```

## Де що живе

- **Стек**: локальні змінні й параметри методів. Звільняється автоматично, коли метод повертається. Швидко.
- **Купа**: об'єкти типів посилань, створені через `new`. Звільняє збирач сміття.

Поширене спрощення: «типи значень живуть у стеку». Точніше: тип значення живе *там, де його оголошено*. Локальний `int` лежить у стеку, але `int`-поле класу живе всередині об'єкта в купі, а елементи `int[]` — усередині масиву в купі.

Об'єкт типу посилання завжди коштує заголовок (вказівник на тип і sync block, 16 байтів на 64-біт) плюс поля з округленням. Тип значення коштує лише свої поля. Тому мільйони маленьких структур у масиві набагато дешевші за мільйони маленьких об'єктів.

## Значення за замовчуванням

Кожне поле й елемент масиву автоматично ініціалізуються значенням за замовчуванням: `0` для чисел, `false` для `bool`, `'\0'` для `char`, `null` для посилань, а для структури кожне поле отримує своє значення за замовчуванням. Його дає `default(T)` або просто `default`.

Локальні змінні натомість мають бути **гарантовано присвоєні** перед використанням; компілятор не дозволить прочитати неприсвоєну локальну змінну.

## Вбудовані типи та їхні псевдоніми

Ключові слова C# — це псевдоніми типів BCL: `int` — це `System.Int32`, `string` — `System.String`, `object` — `System.Object`, `bool` — `System.Boolean`. Вони тотожні; ключове слово просто коротше.

## Що сказати на співбесіді

- Присвоєння копіює значення для структур і посилання для класів.
- «Типи значень у стеку» правда лише для локальних змінних; поля живуть усередині об'єкта, що їх містить.
- Структуру беріть для невеликих незмінних даних-значень (точка, гроші, діапазон дат). Клас — для всього, що має ідентичність або великий стан.
