## Що таке регулярний вираз

Регулярний вираз (regex) — шаблон, що описує множину рядків. Рушій .NET живе в `System.Text.RegularExpressions`:

```csharp
bool valid = Regex.IsMatch("SKU-1042", @"^SKU-\d{4}$");               // перевірка
Match m = Regex.Match("Order 42 shipped", @"\d+");                     // перший збіг
Console.WriteLine(m.Value + " at " + m.Index);                         // 42 at 6
foreach (Match x in Regex.Matches("a1 b22 c333", @"\d+")) Console.Write(x.Value + " ");   // 1 22 333
string clean = Regex.Replace("too    many   spaces", @"\s+", " ");     // стиснути пробіли
string[] parts = Regex.Split("a, b;c", @"\s*[,;]\s*");                 // розбити за кількома роздільниками
```

Пишіть шаблони **дослівними рядками** (`@"..."`), щоб `\d` доходив до рушія без змін.

## Будівельні блоки

| Шаблон | Збігається з |
| --- | --- |
| `abc` | буквальним текстом |
| `.` | будь-яким символом, крім нового рядка |
| `\d` / `\D` | цифрою / не-цифрою |
| `\w` / `\W` | символом слова (літери, цифри, `_`) / будь-чим іншим |
| `\s` / `\S` | пробільним / непробільним символом |
| `[aeiou]`, `[a-z0-9]` | одним символом із набору чи діапазону |
| `[^0-9]` | одним символом **не** з набору |
| `\.` `\(` `\\` | екранованими метасимволами, буквально |
| `a\|b` | альтернативою: `a` або `b` |
| `^` / `$` | початком / кінцем вводу (або рядка з `Multiline`) |

Символи з особливим значенням (`. * + ? ( ) [ ] { } ^ $ | \`) потребують зворотної скісної, щоб бути буквальними. `Regex.Escape(userText)` екранує весь рядок, і це критично, коли введення користувача стає частиною шаблону.

Зверніть увагу: у .NET `\d` і `\w` **враховують Unicode**: `\d` збігається й з арабсько-індійськими та іншими цифрами. Використовуйте `[0-9]` або `RegexOptions.ECMAScript`, коли маєте на увазі лише ASCII-цифри.

## Якорі важливі

`IsMatch` шукає шаблон **будь-де** у вводі:

```csharp
Regex.IsMatch("my code is 12345!", @"\d{4}");      // True: "1234" там є
Regex.IsMatch("my code is 12345!", @"^\d{4}$");    // False: увесь ввід має бути 4 цифрами
```

Для валідації завжди ставте якорі. `\A` і `\z` — суворі якорі «початок/кінець вводу» (`$` ще й допускає завершальний новий рядок).

## Об'єкт Regex

```csharp
private static readonly Regex Sku = new(@"^SKU-\d{4}$", RegexOptions.Compiled | RegexOptions.IgnoreCase);
bool ok = Sku.IsMatch(input);
```

Створення `Regex` розбирає шаблон (а з `Compiled` ще й генерує IL), тож створюйте його раз і повторно використовуйте: екземпляри потокобезпечні. Статичні допоміжні методи кешують нещодавно використані шаблони (`Regex.CacheSize`, за замовчуванням 15).

## Що сказати на співбесіді

- `IsMatch`, `Match`/`Matches`, `Replace`, `Split` покривають більшість потреб.
- Екрануйте метасимволи (і введення користувача через `Regex.Escape`); використовуйте дослівні рядки.
- Ставте якорі в шаблонах валідації (`^...$` або `\A...\z`); повторно використовуйте екземпляри `Regex`.
