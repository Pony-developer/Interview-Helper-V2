## object: корінь усього

`System.Object` — найвищий базовий тип. Його публічні члени доступні на кожному значенні:

| Член | Призначення |
| --- | --- |
| `ToString()` | текстове подання; перевизначте його, щоб полегшити налагодження й логування |
| `Equals(object)` | рівність; для класів за замовчуванням — рівність посилань, для структур — поле за полем |
| `GetHashCode()` | хеш для словників; має узгоджуватися з `Equals` |
| `GetType()` | точний тип під час виконання у вигляді `System.Type` |
| `ReferenceEquals(a, b)` (статичний) | true лише тоді, коли обидва посилаються на той самий об'єкт |

`GetType()` дає тип екземпляра під час виконання; `typeof(T)` — тип, відомий під час компіляції:

```csharp
object o = "hi";
Console.WriteLine(o.GetType() == typeof(string));   // True
Console.WriteLine(o.GetType().Name);                 // String
```

## Пакування та розпакування

Тип значення можна розглядати як `object` (чи інтерфейс). Для цього рантайм **пакує** його: виділяє об'єкт у купі й копіює туди значення.

```csharp
int n = 42;
object boxed = n;        // пакування: алокація в купі + копіювання
int back = (int)boxed;   // розпакування: перевірка типу + копіювання назовні
```

Три речі, які варто пам'ятати:

1. **Пакування копіює.** Зміна `n` після цього не змінює `boxed`.
2. **Розпакування вимагає точного типу.** `(long)boxed` кидає `InvalidCastException`, хоча `int` перетворюється на `long`. Пишіть `(long)(int)boxed`.
3. **Пакування коштує** алокації та подальшої роботи GC. У гарячих місцях це накопичується.

### Де ховається пакування

```csharp
ArrayList list = new ArrayList(); list.Add(5);       // неузагальнена колекція: пакує
string s = string.Format("{0}", 5);                  // params object[]: пакує
IComparable c = 5;                                    // інтерфейс на структурі: пакує
Console.WriteLine($"{5}");                           // сучасні компілятори цього уникають
enumValue.HasFlag(Flags.A);                           // пакувало в старих рантаймах; оптимізовано з .NET Core 2.1
```

Головні ліки — узагальнення: `List<int>` зберігає `int` напряму, а `where T : IComparable<T>` дозволяє викликати `CompareTo` на структурі без пакування.

## Статична та динамічна перевірка типів

- **Статична**: компілятор перевіряє `string s = 5;` і відмовляє.
- **Під час виконання**: низхідне приведення чи розпакування перевіряє CLR, який кидає `InvalidCastException`, якщо об'єкт не того типу.

## Що сказати на співбесіді

- Пакування = загорнути тип значення в об'єкт у купі; розпакування = скопіювати назад із перевіркою точного типу.
- Пакування неявне, тож шукайте його в неузагальнених API, параметрах типу `object` та інтерфейсах, реалізованих структурами.
- Перевизначайте `ToString` для налагодження; `Equals` і `GetHashCode` — разом або ніяк.
