## Завдання

Реалізуйте самостійно класичні бітові трюки, що стоять за `System.Numerics.BitOperations` (у рантаймі практики цього класу немає).

1. **`PopCount(uint)`**: кількість одиничних бітів. Підказка: `value &= value - 1` скидає наймолодший встановлений біт; порахуйте, скільки разів це можна зробити.
2. **`IsPowerOfTwo(uint)`**: степінь двійки має рівно один встановлений біт, тож `value & (value - 1)` дорівнює нулю. Пам'ятайте, що 0 — **не** степінь двійки.
3. **`RoundUpToPowerOf2(uint)`**: найменший степінь двійки, `>=` значення. Підказка: відніміть 1, «розмажте» старший біт у всі молодші позиції через `value |= value >> 1`, `>> 2`, `>> 4`, `>> 8`, `>> 16`, потім додайте 1.
4. **`Log2(uint)`**: індекс старшого встановленого біта (зсувайте вправо, доки значення не стане 0, рахуючи кроки).

Останній рядок `Main` показує встановлення й перевірку окремих бітів у слові-прапорцях.

Очікуваний результат:

```
0: pop=0 pow2=False
1: pop=1 pow2=True
11: pop=3 pow2=False
64: pop=1 pow2=True
1000: pop=6 pow2=False
4294967295: pop=32 pow2=False
1 -> 1, log2=0
5 -> 8, log2=2
64 -> 64, log2=6
1000 -> 1024, log2=9
00001001 True
```
