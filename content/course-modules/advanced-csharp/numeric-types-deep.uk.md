## Родина числових типів

| Вид | Типи | Примітки |
| --- | --- | --- |
| Знакові цілі | `sbyte` (8), `short` (16), `int` (32), `long` (64) | `int` — тип за замовчуванням для цілих літералів |
| Беззнакові цілі | `byte`, `ushort`, `uint`, `ulong` | без від'ємних значень |
| Цілі нативного розміру | `nint`, `nuint` (C# 9) | 32 або 64 біти залежно від процесу |
| Двійкові з рухомою комою | `float` (32), `double` (64) | `double` — тип за замовчуванням для літералів із крапкою |
| Десяткові з рухомою комою | `decimal` (128) | точний для десяткових дробів; для грошей |

Суфікси літералів обирають тип: `10L` (long), `10U` (uint), `1.5F` (float), `1.5M` (decimal). Роздільники цифр полегшують читання: `1_000_000`, `0b1010_1010`, `0xFF_FF`.

## Перетворення

- **Неявні**, коли інформацію не можна втратити: `int` → `long`, `int` → `double`, `float` → `double`.
- **Явні** (приведення), коли можна: `long` → `int`, `double` → `int`, `double` → `float`.
- Приведення дробового значення до цілого **відкидає** дробову частину в бік нуля: `(int)-3.9` дає `-3`. Якщо треба округлення, беріть `Math.Round` (за замовчуванням банківське) або `Convert.ToInt32` (який округлює).

## Пастка 8- і 16-бітних типів

Арифметичні оператори визначені лише для `int`, `uint`, `long`, `ulong`, `float`, `double`, `decimal`. Менші типи спершу розширюються до `int`:

```csharp
short a = 1, b = 2;
short c = a + b;          // помилка: a + b має тип int
short d = (short)(a + b); // ок
```

## Переповнення цілих

За замовчуванням цілочисельна арифметика **тихо перекочується**:

```csharp
int x = int.MaxValue;
x++;                       // тепер int.MinValue, жодної помилки
```

`checked` перетворює переповнення на `OverflowException`:

```csharp
int y = checked(x * 2);          // вираз
checked { total += price * qty; } // блок
```

Можна увімкнути перевірку для всього проєкту (`<CheckForOverflowUnderflow>true</CheckForOverflowUnderflow>`) і локально вимикати її через `unchecked`. Константні вирази завжди перевіряються під час компіляції.

## Особливі значення з рухомою комою

Ділення `double` на нуль **не** кидає винятку:

```csharp
Console.WriteLine(1.0 / 0);    // ∞ (PositiveInfinity)
Console.WriteLine(0.0 / 0);    // NaN
Console.WriteLine(double.NaN == double.NaN);   // False!  використовуйте double.IsNaN
```

Натомість ціле ділення на нуль кидає `DivideByZeroException`.

## double проти decimal

```csharp
Console.WriteLine(0.1 + 0.2 == 0.3);       // False
Console.WriteLine(0.1m + 0.2m == 0.3m);    // True
```

`double` зберігає числа в основі 2, тож 0.1 — лише наближення. `decimal` зберігає їх в основі 10 з 28–29 значущими цифрами, тож грошові суми лишаються точними. Ціна: `decimal` приблизно в 10 разів повільніший і має значно менший діапазон.

| `double` для | `decimal` для |
| --- | --- |
| науки, графіки, статистики, усього виміряного | грошей, цін, кількостей, які рахують в основі 10 |

Ніколи не порівнюйте `double` через `==` після обчислень; порівнюйте з допуском: `Math.Abs(a - b) < 1e-9`.

## Що сказати на співбесіді

- Переповнення цілих перекочується, якщо не використати `checked`.
- `byte + byte` має тип `int`.
- `double` для вимірювань, `decimal` для грошей; `NaN != NaN`.
