## Завдання

Рантайм практики — старіший Mono без `Span<T>`, тож ключову ідею ви побудуєте самі: `readonly struct Slice`, що є **представленням** (текст + початок + довжина) над рядком. Створення, обрізання й під-зрізи ніколи не копіюють символи; алокує лише `ToString()`.

1. **`Sub(start, length)`**: вужче представлення відносно цього зрізу. Киньте `ArgumentOutOfRangeException`, якщо воно вийшло б за межі зрізу.
2. **`Trim()`**: посуньте початок уперед через пробіли, а кінець — назад через пробіли; поверніть вужче представлення.
3. **`TryParseInt(out value)`**: розбирайте цифри напряму (`value = value * 10 + (ch - '0')`), повертаючи false для порожнього зрізу чи будь-якої не-цифри. Без `Substring`, без `int.Parse`.
4. **`Csv.SumColumn(text, column)`**: ідіть текстом **лише вперед** через `IndexOf('\n')` і `IndexOf(',')`, вирізаючи рядки й поля, і підсумуйте потрібну колонку (обрізану); значення, що не розбираються, пропускайте.

Саме так парсери на спанах у сучасному .NET уникають створення рядка для кожного поля.

Очікуваний результат:

```
[order-42 ,  1500] start=2 length=16
[1500] True 1500
False 0
False
qty total: 42
price total: 14
out of range
```
