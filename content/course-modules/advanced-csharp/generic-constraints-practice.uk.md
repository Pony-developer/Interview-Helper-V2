## Завдання

Дві узагальнені частини, кожна спирається на свої обмеження.

1. **`Generic.Max<T>(IList<T> items) where T : IComparable<T>`** повертає найбільший елемент. Для порожнього списку поверніть `default(T)`. Використовуйте `CompareTo`; саме обмеження дозволяє його викликати, і це працює для `int`, `string` і `DateTime` без пакування.

2. **`Registry<T> where T : class, IEntity, new()`** зберігає по одній сутності на кожен `Id`. `GetOrCreate(id, init)`:
   - якщо сутність із таким `id` уже збережена, поверніть її (і не викликайте `init`);
   - інакше створіть нову через `new T()` (це дозволяє обмеження `new()`), передайте її в `init(entity, id)`, щоб заповнити, збережіть результат під ключем `id` і поверніть.

Очікуваний результат:

```
17
plum
0
2022
Pen Pen same=True count=1
customers=2
```
