## Завдання

Побудуйте крихітну версію `ArrayPool<byte>`, щоб зрозуміти, що насправді означає позичати й повертати буфери.

Буфери згруповано в **кошики** за розміром-степенем двійки (16, 32, 64, ...); `BucketSize(n)` (уже написаний) дає кошик для запиту.

1. **`Rent(minimumLength)`**: знайдіть розмір кошика; якщо в цьому кошику є повернутий буфер, вийміть і поверніть його (повторне використання!); інакше виділіть новий `byte[bucketSize]` і збільште `Allocations`. Зверніть увагу: буфер може бути **більшим**, ніж просили.
2. **`Return(buffer, clear)`**: буфер, довжина якого не дорівнює точно розміру кошика, не міг прийти з цього пулу: киньте `ArgumentException("Buffer is not from this pool")`. Якщо `clear` істинний, спершу обнуліть його через `Array.Clear`. Потім покладіть його в стек свого кошика.

Подивіться на рядок «dirty reuse»: без очищення наступний позичальник бачить дані попереднього. Саме тому `ArrayPool.Return` має параметр `clearArray` для чутливих буферів.

Очікуваний результат:

```
1000 rents of 100 bytes -> allocations: 1
sizes: 16, 32, 1024
distinct while both rented: True
dirty reuse: 42
cleared reuse: 0
Buffer is not from this pool
allocations: 6
```
