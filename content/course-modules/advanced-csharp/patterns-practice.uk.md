## Завдання

Реалізуйте **`Pricing.Price(Item item)`** через інструкцію `switch` з **патернами типів** (`case Book b:`), як у C# 7.0:

| Товар | Ціна |
| --- | --- |
| `Book` з `IsEbook` | знижка 10% |
| `Book` (паперова) | повна ціна |
| `Food` з `DaysToExpiry <= 0` | безкоштовно |
| `Food`, коли лишилося 1–2 дні | півціни |
| інша `Food` | повна ціна |
| `Gadget` бренду `"Acme"` | базова ціна + 15 |
| усе інше (інші гаджети, подарункові картки) | повна ціна |
| `null` | кинути `ArgumentNullException` |

Усередині кожного `case` визначайте ціну за зіставленою змінною (`b.IsEbook`, `f.DaysToExpiry`, `g.Brand`). Вхід null обробляє `case null:`, а все інше — `default:`. (Компілятор практики — C# 7.0, де немає умов `when` у мітках `case`; починаючи з C# 7.1 можна писати `case Food f when f.DaysToExpiry <= 0:`.)

У сучасному C# те саме написали б switch-виразом з патернами властивостей: `Food { DaysToExpiry: <= 0 } => 0m`. Тут потренуйтеся у формі C# 7.0.

Очікуваний результат:

```
Book: 18.00
Book: 20.00
Food: 0.00
Food: 4.00
Food: 8.00
Gadget: 115.00
Gadget: 100.00
GiftCard: 50.00
null rejected
```
