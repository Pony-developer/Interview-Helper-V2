## Завдання

Реалізуйте **`Pricing.Price(Item item)`** через інструкцію `switch` з **патернами типів та умовами `when`** (стиль C# 7.3):

| Товар | Ціна |
| --- | --- |
| `Book` з `IsEbook` | знижка 10% |
| `Book` (паперова) | повна ціна |
| `Food` з `DaysToExpiry <= 0` | безкоштовно |
| `Food`, коли лишилося 1–2 дні | півціни |
| інша `Food` | повна ціна |
| `Gadget` бренду `"Acme"` | базова ціна + 15 |
| усе інше (інші гаджети, подарункові картки) | повна ціна |
| `null` | кинути `ArgumentNullException` |

Уважно впорядкуйте мітки `case`: перемагає перший збіг, тож конкретніші умови `when` мають стояти перед загальними. Вхід null обробляє `case null:`.

У сучасному C# те саме написали б switch-виразом з патернами властивостей: `Food { DaysToExpiry: <= 0 } => 0m`. Тут потренуйтеся у формі 7.3.

Очікуваний результат:

```
Book: 18.00
Book: 20.00
Food: 0.00
Food: 4.00
Food: 8.00
Gadget: 115.00
Gadget: 100.00
GiftCard: 50.00
null rejected
```
