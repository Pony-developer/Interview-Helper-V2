## Навіщо знати історію

На співбесідах часто питають «у якій версії з'явилося X?», але здебільшого щоб перевірити, чи ви знаєте, *для чого X*, а не дати. Порядок появи також пояснює, чому в мові є кілька способів зробити одне й те саме.

## Головні віхи

| Версія | Рік | Ключові можливості |
| --- | --- | --- |
| C# 1 | 2002 | Класи, структури, інтерфейси, делегати, події, властивості |
| C# 2 | 2005 | **Узагальнення (generics)**, nullable-типи значень (`int?`), ітератори (`yield return`), анонімні методи, partial-класи |
| C# 3 | 2007 | **LINQ**, лямбда-вирази, методи розширення, `var`, анонімні типи, ініціалізатори об'єктів і колекцій, дерева виразів |
| C# 4 | 2010 | `dynamic`, необов'язкові та іменовані параметри, варіантність узагальнень (`in`/`out`) |
| C# 5 | 2012 | **`async` / `await`**, атрибути інформації про викликача |
| C# 6 | 2015 | Null-умовний `?.`, інтерполяція рядків `$"..."`, `nameof`, члени з тілом-виразом, `using static`, фільтри винятків |
| C# 7.x | 2017 | **Кортежі** та деконструкція, зіставлення зі зразком (`is`, `switch` за типами), `out var`, локальні функції, `ref`-локальні змінні й повернення, підтримка `Span<T>`, параметри `in` |
| C# 8 | 2019 | **Nullable-типи посилань**, `switch`-вирази, діапазони та індекси (`^1`, `1..3`), члени інтерфейсів за замовчуванням, асинхронні потоки, `using`-оголошення |
| C# 9 | 2020 | **Record**, аксесори `init`, інструкції верхнього рівня, реляційні й логічні патерни, `new()` з цільовим типом |
| C# 10 | 2021 | Простори імен на рівні файлу, `global using`, record struct, розширені патерни властивостей, лямбди з природним типом, константні інтерпольовані рядки |

## C# 10 ближче

```csharp
// простір імен на рівні файлу: без дужок, увесь файл у ньому
namespace Shop.Orders;

// global using: діє в кожному файлі проєкту (часто в GlobalUsings.cs)
global using System.Text.Json;

// record struct: record-тип значення з рівністю за значенням і зручним ToString
public readonly record struct Money(decimal Amount, string Currency);

// розширений патерн властивостей
if (order is { Customer.Address.Country: "UA" }) { /* ... */ }

// лямбди мають природний тип, тож працює 'var'
var parse = (string s) => int.Parse(s);   // Func<string, int>
```

## Хронологія як історія

- **C# 2–3** зробили мову *виразною*: узагальнення та LINQ.
- **C# 5** зробив її *асинхронною*.
- **C# 7–10** зробили її *лаконічною й безпечною*: кортежі, патерни, record, nullable-типи посилань і менше церемоній.

## Що сказати на співбесіді

- Узагальнення (C# 2), LINQ (C# 3), async (C# 5), nullable-типи посилань (C# 8) і record (C# 9) — п'ять орієнтирів, які варто пам'ятати.
- C# 10 вийшов разом із .NET 6 і був про прибирання шаблонного коду: простори імен на рівні файлу та глобальні using.
