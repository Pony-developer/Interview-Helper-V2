## Завдання

Виклик API для 10 000 елементів через `Task.WhenAll(items.Select(CallApiAsync))` надсилає 10 000 запитів одночасно. Напишіть **`Throttle.ForEachAsync(items, maxParallel, work)`**, що виконує `work` для кожного елемента так, щоб **одночасно виконувалося не більше `maxParallel`**, і повертає результати **в порядку вхідних даних**.

Підхід:

1. Створіть `SemaphoreSlim(maxParallel)`.
2. Для кожного елемента запустіть допоміжну задачу, що робить `await gate.WaitAsync()`, потім `await work(item)` у `try` і `gate.Release()` у `finally` (щоб елемент, що впав, не «з'їв» слот).
3. Тримайте задачі в масиві в порядку вхідних даних і `return await Task.WhenAll(tasks);` — він повертає результати в тому самому порядку, що й задачі, незалежно від того, яка завершилася першою.

`Main` відстежує, скільки викликів виконується одночасно, і перевіряє, що їх ніколи не більше 3.

Очікуваний результат:

```
25,9,64,1,81,4,49
max parallel <= 3: True
ran in parallel: True
empty: 0
```
