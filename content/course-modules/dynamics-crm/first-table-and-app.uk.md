Найшвидший спосіб зрозуміти Dataverse — збудувати щось маленьке. Ця покрокова інструкція створює таблицю «Project» і model-driven застосунок навколо неї приблизно за пів години, без коду. Вам потрібне середовище розробки (підійде безкоштовне середовище Power Apps Developer Plan).

## 1. Створіть рішення

1. Відкрийте **make.powerapps.com** і виберіть середовище вгорі праворуч.
2. Перейдіть у **Solutions** → **New solution**. Назвіть його «Projects».
3. У полі **Publisher** виберіть **New publisher**: відображуване ім'я «Contoso», префікс `contoso`. Збережіть і виберіть його.
4. Створіть рішення й відкрийте його. Усе далі створюється **всередині цього рішення**.

## 2. Створіть таблицю

1. **New** → **Table** → **Table**. Відображуване ім'я «Project», множина «Projects».
2. Основний стовпець за замовчуванням називається «Name»; залиште його.
3. В **Advanced options** залиште тип володіння **User or team**, щоб проєкти мали власників.
4. Збережіть. Dataverse створить `contoso_project` з id, назвою, власником, станом і стовпцями аудиту.

## 3. Додайте стовпці

Відкрийте таблицю й додайте (**New** → **Column**):

| Відображуване ім'я | Тип даних | Примітки |
| --- | --- | --- |
| Start Date | Date only | Дата без часу |
| Budget | Currency | Сума з валютою |
| Priority | Choice | Новий локальний choice з варіантами Low, Normal, High; за замовчуванням Normal |
| Customer | Lookup | Пов'язана таблиця: Account |
| Description | Multiple lines of text | |

Подивіться **логічне ім'я** кожного стовпця в *Advanced options*: `contoso_startdate`, `contoso_budget`, `contoso_priority`, `contoso_customer`. Саме його використовуватиме код.

## 4. Налаштуйте форму й подання

1. **Forms** → відкрийте форму **Main**. Перетягніть нові стовпці на неї, Customer і Priority — ближче до верху. **Save and publish**.
2. **Views** → відкрийте **Active Projects**. Додайте стовпці Customer, Priority і Budget, сортування за Start Date. **Save and publish**.

## 5. Додайте бізнес-правило

На таблиці відкрийте **Business rules** → **New**. Умова: *Priority equals High*. Дія: *Set Business Required* для **Budget**. Збережіть і **активуйте**. Тепер проєкт із високим пріоритетом не можна зберегти без бюджету.

## 6. Зберіть застосунок

1. У рішенні: **New** → **App** → **Model-driven app**, назва «Project Hub».
2. **Add page** → **Dataverse table** → Project, а також додайте Account.
3. **Save** і **Publish**, потім **Play**.

Створіть два проєкти, відкрийте акаунт і зверніть увагу на пов'язану вкладку **Projects**: lookup автоматично створив зв'язок 1:N.

## 7. Зазирніть за лаштунки

- Відкрийте в браузері `https://<your-org>.crm.dynamics.com/api/data/v9.2/contoso_projects`: ваші рядки у форматі JSON з Web API, з логічними іменами.
- У рішенні зробіть **Export** як некероване: zip-архів містить XML, що описує все, що ви збудували. Саме цей файл переносять у тест і продакшн.

## Чого ви навчилися

Ви використали ті самі будівельні блоки, що й Dynamics 365 Sales: видавця й рішення, таблицю з типізованими стовпцями, lookup, що створив зв'язок, форму, подання, бізнес-правило й застосунок. Кожен наступний урок додає код саме до цих частин.
