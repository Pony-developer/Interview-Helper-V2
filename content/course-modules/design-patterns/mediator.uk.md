**Простими словами:** посередник — це **центральний координатор**. Замість того щоб об'єкти говорили один з одним напряму (усі знають усіх), вони говорять лише з посередником, і він вирішує, хто має відреагувати.

## Картинка з життя

Диспетчерська вежа аеропорту. Літаки не домовляються між собою, хто сідає першим; кожен говорить лише з вежею, а вежа координує всіх.

## Проблема

Форма реєстрації: коли позначено «Компанія», з'являється поле «Назва компанії» і стає обов'язковим; коли країна «Україна», змінюється маска телефону; «Надіслати» активна лише тоді, коли все правильно. Якщо кожен елемент посилається на інші, виходить павутиння зв'язків, де зміна одного поля ламає три інші.

## На C#

```csharp
interface IFormMediator
{
    void Changed(string field);
}

class RegistrationForm : IFormMediator
{
    public Checkbox IsCompany = new Checkbox();
    public TextBox CompanyName = new TextBox();
    public Button Submit = new Button();

    // Усі правила «якщо змінилося це, онови те» живуть в ОДНОМУ місці
    public void Changed(string field)
    {
        if (field == "IsCompany")
        {
            CompanyName.Visible = IsCompany.Checked;
            CompanyName.Required = IsCompany.Checked;
        }
        Submit.Enabled = !CompanyName.Required || CompanyName.Text.Length > 0;
    }
}
```

Прапорець лише каже посереднику «я змінився»; він не знає, що існують текстове поле чи кнопка.

## Де ви вже це бачите

- **MediatR** у .NET: контролери надсилають `mediator.Send(new CreateOrderCommand(...))` і не знають, який обробник його опрацює.
- Чат-кімната: користувачі надсилають повідомлення в кімнату, кімната їх доставляє.
- **Скрипти форм Dynamics:** скрипт `OnLoad` / `OnChange`, що координує поля форми, — це посередник для її елементів.

## Коли застосовувати, а коли ні

- **Пасує:** багато об'єктів взаємодіють заплутано, і хочеться, щоб кожен можна було використати окремо.
- **Обережно:** сам посередник може розростися в **God object**, що знає все. Розділіть його за областями, коли він стане великим.

## Запам'ятайте

Mediator = «**говоріть із вежею, а не один з одним**». Він перетворює зв'язки «багато до багатьох» на «один до багатьох».
