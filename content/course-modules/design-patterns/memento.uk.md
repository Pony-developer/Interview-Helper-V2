**Простими словами:** Memento **зберігає знімок стану об'єкта**, щоб його можна було **відновити пізніше**, не відкриваючи приватних подробиць об'єкта тому, хто зберігає знімок.

## Картинка з життя

Збереження гри перед битвою з босом. Якщо все піде погано, ви завантажуєте збереження й опиняєтеся точно там, де були. Файл збереження — запечатана коробка: ви його зберігаєте, але не редагуєте вміст.

## Проблема

Користувач редагує довгу форму й натискає «Скасувати зміни». Або редактору потрібне скасування дій. Щоб відновити старий стан, хтось має його пам'ятати. Якщо зовнішній код копіює поля об'єкта по одному, він мусить знати їх усі, зокрема приватні, і ламається щоразу, коли додається поле.

## На C#

```csharp
class Document
{
    private string text = "";
    private int cursor;

    public void Type(string words) { text += words; cursor = text.Length; }

    // Об'єкт сам робить і читає свої знімки, тож приватні поля лишаються приватними
    public Snapshot Save() { return new Snapshot(text, cursor); }
    public void Restore(Snapshot s) { text = s.Text; cursor = s.Cursor; }

    public class Snapshot                      // знімок: незмінний, редагувати нічого
    {
        internal string Text { get; private set; }
        internal int Cursor { get; private set; }
        internal Snapshot(string text, int cursor) { Text = text; Cursor = cursor; }
    }
}

var doc = new Document();
var history = new Stack<Document.Snapshot>();   // «опікун» лише зберігає знімки

history.Push(doc.Save());
doc.Type("Hello");
history.Push(doc.Save());
doc.Type(", world");

doc.Restore(history.Pop());                     // назад до "Hello"
```

## Memento чи Command для скасування

- Скасування через **Command**: кожна команда знає, як *відкотити себе* («перейменувати назад»). Компактно, але кожній команді потрібна власна логіка скасування.
- Скасування через **Memento**: зберегти *весь стан* перед зміною й повернути його. Просто й надійно, але для великих об'єктів коштує пам'яті.

## Де ви вже це бачите

- «Скасувати зміни» у формах, чернетки, транзакції, що відкочуються.
- Збереження початкових значень сутності перед оновленням, щоб їх порівняти чи відновити (як **PreImage** у плагіні Dynamics, тобто знімок запису до операції).

## Запам'ятайте

Memento = «**збережи запечатаний знімок, віднови пізніше**». Об'єкт сам робить і читає свої знімки; інші лише їх зберігають.
